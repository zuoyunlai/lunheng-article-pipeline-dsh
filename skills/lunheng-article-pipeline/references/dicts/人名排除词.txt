# 人名排除词表（v18.60.0）——抑制「姓氏 + 1~2 字」的常见误报
#
# 为什么需要：中文人名检测用「姓氏 + 1~2 汉字」作候选式，而大量普通词恰好同形——
#   王朝（朝代）／李子（水果）／马路（道路）／白天（时段）。不设本表时这些会被替换成
#   「受访者A」，把正文改得不可读。
#
# 边界（**如实**）：本表**不可能穷举**。未收录的同形词仍会被替换，但会同时进
#   `reviewFlags`（kind=person-low-confidence）供人工复核——设计取舍是「宁多报、不静默漏报」。
#
# 维护：实战中发现误替换时把该词加进来即可（工具每次调用读表，无需改代码）。
