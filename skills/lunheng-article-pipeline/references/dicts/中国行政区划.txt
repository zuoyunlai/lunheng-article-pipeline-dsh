# 中国行政区划表（v18.60.0）——论衡伦理脱敏工具的地名泛化基础
#
# 格式：`<地名>\t<上级（省/直辖市/自治区）>`；`#` 开头为注释；空行忽略。
# 作用：basic 模式下替换为 `[地名-REDACTED]`；strict 模式下**泛化到上级**
#   （「东莞市」→「广东某地」），兼顾「去掉可识别精度」与「保留地域分析价值」。
# 边界（**如实**）：
#   · 本表是**地名候选集**，不追求收录全部区县——未收录的地名不会被替换（会漏检）；
#   · 省级条目映射到自身：strict 下**保持原样**（省级粒度不足以识别个体，
#     替换成「广东某地」是制造假精度）；
#   · 同名地名的上级取最常见者（如「朝阳」取北京），歧义由人复核。
# 维护：实战中按需增补；工具每次调用读表。
