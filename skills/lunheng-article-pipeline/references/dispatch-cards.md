# 派发开工卡（dispatch-cards）

> **历史叙事已外移**：正文只留现行规则；历史成因 / 逐版明细 / 教训编号见 CHANGELOG.md 对应版本段与 `memory/lessons.md`。

> 用途：主控 spawn 子代理时的**最小 prompt 模板**（配合读取纪律，禁长篇复制）。每卡 ≤12 行；角色卡全文按需 `read` 指定小节。版本：v18.68.0。
>
> **派发前置**：Phase 2 / 3.6 / 4 / 4.5 / 5 各闸门派发前，主控先跑 `node scripts/build-evidence-bundle.mjs <项目> --summary`（源自动取 `final/定稿.md` → `drafts/` 最高版本正文；要锁定某轮稿用 `--source <路径>`）生成/刷新 `audits/审计视图-v0.md`，再按各卡「读」清单把它列入派发话术。**视图缺失时该优化不成立**——不要声称「已用视图省 token」。
>
> **格式样例指针**：每卡末行给出该类产物的**模板路径**——**派发时把该路径写进 prompt，让子代理按需 `read` 模板**（本卡不复述字段清单，避免与模板「一事实两处」）。卡类产物的**排版契约**（索引段标题逐字 / 方括号编号 / 信任级别行形态 …）单一真源 = [`_shared/机检硬格式.md`](_shared/机检硬格式.md)；**不带模板的产物**（如批判/审计/审稿报告）在本卡末行如实标注「无独立模板」，其结构以角色卡为准。

## 上下文经济（主控与全角色共守）

1. **阈值显式化（B1）**：回报正文 **>10 行** → 只留六要素**每项 1 行** + 产物路径；细节一律落盘，回报内只写**指针**（角色 + 路径 + 行号）。**禁止**以「尽量简短」「只回要点」这类无可执行判据的措辞替代本条；`handoff-check.mjs` 对其有软检。
2. **一次调用问全部（B2）**：`read` / `grep` / 检索式的往返，**一次读多文件、一次查多关键词**；**不得**逐文件 / 逐关键词往返——同一信息多次往返，等于同一份内容被重复读入**后续每一步**的上下文。
3. **转述仍算计费（A4）**：**同一事实在一轮内只完整写一次**；其余位置——**含主控三播报的「完成转播」**——写**指针**，**不得**把子代理原文再贴一遍。已落盘的内容再进一次上下文，是本轮第二笔支出。
4. **收窄归下游（A2 的卡层部分）**：捕获层（T1/T2/T3 落盘、T7 采集实据）**不做静默收窄**；收窄一律在下游（T4/T5 按索引段定位）做。**在捕获层丢掉的内容，下游永远拿不到**。**若因条数上限未落卡，须留痕 `已核验未落卡 N 条 + 理由`**（无则显式写「无」）——**不得静默丢弃，也不得为凑数而填充**（两边界详见 [`_shared/检索注入防御.md`](_shared/检索注入防御.md) §「落盘不得预筛」）。

## T1 文献检索员
- 读：`01-任务简报.md`；格式/铁律不熟才 read 角色卡小节。
- 输出：`literature/文献卡.md`（8-12 条，卡头「索引段」；每条 GB/T 7714 + 可信度 + 信任级别 + 关联论点 + 核验记录）；`literature/先行者清单.md`。
- 铁律：发布即核验（DOI/arXiv/URL 在线核验；占位/未核验不落卡）；同 query 连失 2 次换词；检索失败熔断；**首轮 ≤40 步、连续 2 轮无新增卡即判饱和停**（饱和照实报，不补占位）。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）：路径/条数/核验概况/缺口/下一步。
- 格式样例：`references/templates/文献卡-template-lite.md`（实战用；字段详解用 `-template.md`）+ `references/templates/先行者清单-template.md`。

## T2 数据检索员
- 读：任务简报；输出 `data/数据卡.md`（15-25 条，索引段；每条含 数值+来源+年份+URL+信任级别+时效+口径）。
- 铁律：行内禁结论性解读；缺口 🔴 单列不计条；来源可核优先；连失 2 次换词；**连续 2 轮无新增卡即判饱和停**。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）：路径/条数与 🟢🟡🔴/缺口/问题/下一步。
- 格式样例：`references/templates/数据卡-template-lite.md`（实战用；字段详解用 `-template.md`）。

## T3 案例检索员
- 读：任务简报；输出 `cases/案例卡.md`（3-5 条，索引段）。
- 每条：事件结构/独立来源（标注官方自源 vs 独立媒体，官方站不计独立计数）/多方说法/时间锚点/检索截止日期/信任级别/事件状态/关联论点。
- 落盘前自检六项；禁编造 URL/事件；单源降级标注；**连续 2 轮无新增卡即判饱和停**。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）。
- 格式样例：`references/templates/案例卡-template-lite.md`（实战用；字段详解用 `-template.md`）。

## T3.5 文献补标注检索员（可选，默认关）
- **仅在任务简报勾选「启用 T3.5 auto_cite 预标注 = ✓」时派发**（Phase 0 主人显式开启）；未勾选**不派卡**。
- 读：任务简报 + `analysis/分析大纲.md`；输出 `literature/auto_cite-补充.md`；格式样例 `references/templates/auto_cite-补充-template.md`。
- 完整派发话术见 [`pipeline-readme.md#文献补标注检索员t35`](pipeline-readme.md)（本卡只给入口，不复述话术——v18.67.0 审计 P2-6：此前该角色有派发话术却无开工卡，启用后主控按 SKILL 锚点速查找不到入口）。
- 口径与集成细节见 [`_shared/auto_cite-integration.md`](_shared/auto_cite-integration.md)；回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）。

## T4 分析员
- 读：审计视图（`audits/审计视图-v0.md`，素材阶段视图：卡数+信任分布+报告存在性）+ 任务简报 + 三卡索引段（按论点定位条目）；输出 `analysis/分析大纲.md`（11 节，末附 §11 写手精简段 ≈60 行）。
- 铁律：论据只来自真实编号；缺角降级为观点并标 Permanent Gap/Phase1.5；承重墙 top1 不超载；反方 5a/5b/5c 齐备；数据信任分级进映射。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）：路径/论点数/薄弱环/承重墙自检/下一步。
- 格式样例：§11 写手精简段的字段结构见 `references/templates/任务简报-template-lite.md`（该结构即 M-Exist-10 的检查对象）。

## T5 写手
- 只读：任务简报 + `analysis/分析大纲.md` 的 **§11 精简段**（同一文件 §11 节，位于 F3 检查 / 缺口表之前，非独立文件；§4 行号按需回读）；**修订轮（v2+）先读审计视图**（上一轮草稿快照，定位缺陷段）；输出 `drafts/初稿-v1.md`（及修订轮 vN 走段级 diff）**＋ `analysis/素材加载清单.md`**（覆盖写「## 已加载」= 本轮实际读过的编号；正文引用须 ⊆ 它，机检 M-Form-11）。
- 要求：字数**按任务简报篇幅档 + 大纲 §11 预算执行**（档值单一真源 = `SKILL.md` §何时使用的四档分层，本卡**不写死数值**——旧版写死「3500-4500」与四档冲突，v18.67.0 审计 P1-1 修正）；引用标 [Lxx]/[Dxx]/[Cxx] 闭环；数值纪律（🟡厂方/二手只写口径、推算标「本文推算」）；反方落正文；文末五节 + AI 声明占位；AI 去味自检。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）。
- 格式样例：`references/templates/素材加载清单-template.md`（「## 已加载」结构）+ 修订说明用 `references/templates/修订说明-template-full.md`；文末声明用 `references/templates/AI-使用声明-template.md`。

## T6 批判伙伴
- 读：审计视图（源须 = 被攻击的草稿版本）+ 大纲 §11 + 初稿（对象，可通读）；输出 `analysis/批判报告-vN.md`（C1-C7，条数封顶 论点×3；C6/C7 专项不占额）。
- 只出报告不改稿；每条含编号定位+漏洞+强度+处置建议+验收。
- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）：P0/P1 计数/最大裂缝/修订重点。
- 格式样例：**无独立模板**——条目结构（C1-C7 维度名与字段）以 `references/agents/06-批判-critical-companion.md` 为准。

## T7 审计员
- 读：审计视图（源须 = 被审版本）/**批判报告-vN（N = 被审初稿轮次）**/§11/修订说明/初稿（可通读）/**素材加载清单（核 M-Form-11：引了没读 = P1）**；输出 `audits/审计报告-vN.md` + `反哺报告-vN.md`（两文件缺一不可；**修订轮另产 `audits/复核报告-vN.md`**）。

- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）。
- 格式样例：**无独立模板**——G 项实据最小样板与判定口径以 `references/agents/07-审计-auditor.md` 为准（§「G 项实据最小样板」）。

## T9 同行评审
- 读：审计视图（源须 = 被审版本）+ 初稿 vN + 大纲 §11 + 审计报告（已关闭项不重复点名）；输出 `audits/审稿报告-vN.md`：六维评分(30)/判定/Top3 期刊/投稿前必改项。

- 回报 ≤10 行 + 六要素（收报侧 handoff-check 机检）。
