# 派发开工卡（dispatch-cards）

> 用途：主控 spawn 子代理时的**最小 prompt 模板**（配合读取纪律，禁长篇复制）。每卡 ≤12 行；角色卡全文按需 `read` 指定小节。版本：dsh.10+（token 优化）。
>
> **派发前置（v2.5.2-dsh.15）**：Phase 2 / 3.6 / 4 / 4.5 / 5 各闸门派发前，主控先跑 `node scripts/build-evidence-bundle.mjs <项目> --summary`（源自动取 `final/定稿.md` → `drafts/` 最高版本正文；要锁定某轮稿用 `--source <路径>`）生成/刷新 `audits/审计视图-v0.md`，再按各卡「读」清单把它列入派发话术。**视图缺失时该优化不成立**——不要声称「已用视图省 token」。

## T1 文献检索员
- 读：`01-任务简报.md`；格式/铁律不熟才 read 角色卡小节。
- 输出：`literature/文献卡.md`（8-12 条，卡头「索引段」；每条 GB/T 7714 + 可信度 + 信任级别 + 关联论点 + 核验记录）；`literature/先行者清单.md`。
- 铁律：发布即核验（DOI/arXiv/URL 在线核验；占位/未核验不落卡）；同 query 连失 2 次换词；检索失败熔断；**首轮 ≤40 步、连续 2 轮无新增卡即判饱和停**（饱和照实报，不补占位）。
- 回报 ≤10 行：路径/条数/核验概况/缺口/下一步。

## T2 数据检索员
- 读：任务简报；输出 `data/数据卡.md`（15-25 条，索引段；每条含 数值+来源+年份+URL+信任级别+时效+口径）。
- 铁律：行内禁结论性解读；缺口 🔴 单列不计条；来源可核优先；连失 2 次换词；**连续 2 轮无新增卡即判饱和停**。
- 回报 ≤10 行：路径/条数与 🟢🟡🔴/缺口/问题/下一步。

## T3 案例检索员
- 读：任务简报；输出 `cases/案例卡.md`（3-5 条，索引段）。
- 每条：事件结构/独立来源（标注官方自源 vs 独立媒体，官方站不计独立计数）/多方说法/时间锚点/检索截止日期/信任级别/事件状态/关联论点。
- 落盘前自检六项；禁编造 URL/事件；单源降级标注；**连续 2 轮无新增卡即判饱和停**。
- 回报 ≤10 行。

## T4 分析员
- 读：审计视图（`audits/审计视图-v0.md`，素材阶段视图：卡数+信任分布+报告存在性）+ 任务简报 + 三卡索引段（按论点定位条目）；输出 `analysis/分析大纲.md`（11 节，末附 §11 写手精简段 ≈60 行）。
- 铁律：论据只来自真实编号；缺角降级为观点并标 Permanent Gap/Phase1.5；承重墙 top1 不超载；反方 5a/5b/5c 齐备；数据信任分级进映射。
- 回报 ≤10 行：路径/论点数/薄弱环/承重墙自检/下一步。

## T5 写手
- 只读：任务简报 + `analysis/分析大纲.md` 的 **§11 精简段**（同一文件末尾，非独立文件；§4 行号按需回读）；**修订轮（v2+）先读审计视图**（上一轮草稿快照，定位缺陷段）；输出 `drafts/初稿-v1.md`（及修订轮 vN 走段级 diff）。
- 要求：3500-4500 字按预算；引用标 [Lxx]/[Dxx]/[Cxx] 闭环；数值纪律（🟡厂方/二手只写口径、推算标「本文推算」）；反方落正文；文末五节 + AI 声明占位；AI 去味自检。
- 回报 ≤10 行。

## T6 批判伙伴
- 读：审计视图（源须 = 被攻击的草稿版本）+ 大纲 §11 + 初稿（对象，可通读）；输出 `analysis/批判报告-vN.md`（C1-C7，条数封顶 论点×3；C6/C7 专项不占额）。
- 只出报告不改稿；每条含编号定位+漏洞+强度+处置建议+验收。
- 回报 ≤10 行：P0/P1 计数/最大裂缝/修订重点。

## T7 审计员
- 读：审计视图（源须 = 被审版本）/**批判报告-vN（N = 被审初稿轮次）**/§11/修订说明/初稿（可通读）；输出 `audits/审计报告-vN.md` + `反哺报告-vN.md`（两文件缺一不可；**修订轮另产 `audits/复核报告-vN.md`**）。
- G0-G14 全项 + 数值自洽验算 + T6 条目关闭复核；结论：通过/打回（打回只给段级任务书）。
- 回报 ≤10 行。

## T9 同行评审
- 读：审计视图（源须 = 被审版本）+ 初稿 vN + 大纲 §11 + 审计报告（已关闭项不重复点名）；输出 `audits/审稿报告-vN.md`：六维评分(30)/判定/Top3 期刊/投稿前必改项。
- 回报 ≤10 行。

## G14 中文 AI 痕迹检测器
- 读：正文（文末五节与 AI 声明不参与）；输出 `audits/G14-检测报告-vN.md`：8 类逐类判定 + 总判定(Pass/Warning/Fail) + 报告声明档位。
- 回报 ≤10 行。
