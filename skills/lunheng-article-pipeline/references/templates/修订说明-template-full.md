# 修订说明 v{N}（写手被打回时附在修订稿头部）

> **用途**：标准化修订说明格式，每条修订 = 来源条目 + 处理方式 + 字数变化 + 引用增删。避免 v2 详细、v3 简短的格式漂移。
> **教训来源**：2026-08-24 实战——T5 v2 修订说明表很实用（每条=T6 条目+处理+字数+引用），但 v3 修订说明短了，格式不统一。

## 一、元信息

- **修订版本**：v{N}（基于 v{N-1}）
- **轮次类别（v2.5.2-dsh 双轨制，必填）**：审计打回轮（≤2 轮硬约束）/ 主控触发轮（主人洞察/T6 批判/T9 审稿/G14 净化，不限额但计入版本号）
- **触发来源**：T6 批判报告 / T7 审计打回 / 主人洞察 / T9 审稿 / G14 净化
- **主人洞察**：已投喂 / **未投喂（Phase 3.5 跳过）**（未投喂时显式标注，见 [`../_shared/degraded-scenarios.md`](../_shared/degraded-scenarios.md)）
- **总字数变化**：从 XX 字 → XX 字（±X 字，按 [`../_shared/字数判定表.md`](../_shared/字数判定表.md) 双口径）
