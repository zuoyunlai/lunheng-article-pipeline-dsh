## ⚠️ 文献卡信任级别（v2.2.1 新增，教训 #77）

**每条文献必须标注信任级别（2 档之一）**——v2.2.1 起 M-Form-6 强制校验：

| 级别 | 定义 | 论衡能否主动采集 | 标注格式 |
|------|------|---------------|---------|
| **已发布** | CNKI / Google Scholar / 期刊官网 / 学术数据库 / DOI 公开可核验的文献 | ✅ T1 主动采集 | `[Lxx] ... 信任级别：已发布` |
| **主人投喂** | 主人提供的内部白皮书 / 未公开研究报告 / 客户内部资料 | ❌ 主人投喂 | `[Lxx] ... 信任级别：主人投喂` |
| **二手转引** | 转译网页 / 综述转述等二手载体，原文暂不可直接核验 | ✅ T1 采集 | `[Lxx] ... 信任级别：二手转引` |

**默认 = 已发布**——文献天然是已发布的（T1 用 web_search / web_search 主动检索）。只有「主人提供的内部资料」才标「主人投喂」。

## 方法学字段块（仅「方法论文」条目填）

> **触发**：该条目被 `[L00]` 索引行指向（即方法论文本身）时**必填**；其余文献可整块省略。
> **用途**：T9-m 的 M3「因果推断合法性」以它为数据源（见 [`../agents/09-审稿-peer-reviewer.md`](../agents/09-审稿-peer-reviewer.md)）。**边界**：`[L00]` 仍是**索引段独有行**（不产生正文条目、不计入「总条数」声明），四字段落在**本条目的字段块**里。

- **方法学适用条件**：该方法的识别假设
- **本文是否满足**：满足 / 不满足（+ 依据；**不满足须在正文降格表述**，见 05 卡）
- **已知失效情形**：替代解释 / 边界条件
- **敏感性检验**：计划或已做

## 概念字段块（仅「核心构念」条目填）

> **触发**：本文的**核心术语（构念）**需统一定义时填——触发真源 = 任务简报 / 大纲标出的核心术语。**不看条目类型、只看是否为承重构念**；非承重构念的文献条目可整块省略。
> **为什么寄生在文献卡**：概念的定义**来自文献**，而编号形态 `[Lxx]` 已带全套机械覆盖（索引段对账 / 信任级别 / 正文↔文末双向闭环 / 证据包 / 素材池 L 类）。**新立 `[Kxx]` 族反而零覆盖**——`_lib/refs.mjs` 的 `REF_ID_TOKEN`（编号形态唯一真源）不认它；要让它被认就得扩该真源，并**被迫新增第 6 个文末节**（`M-Form-7` 锁死五节）。故取「`[Lxx]` + 概念字段块」，与 §方法学字段块 同构。
> **用途**：T9-d 的 **D6**（核心术语首现是否给定义）与 T9-m 的 **M2**（变量操作化）以它为数据源。

- **概念术语**：本文使用的那个词
- **本文采用的定义**：一句话，**可判定**
- **并存竞争性定义及分歧点**：有则逐条列（无则写「无」）
- **本文操作化指标**：→ 对应哪条 `[Dxx]`（无量化则写「无，属概念论证」）
- **边界条件**：明确**不包含**什么（防外延漂移）

## 法规字段块（仅「法规 / 标准」条目填）

> **触发**：该条目的**类型**为法律法规 / 行政法规 / 部门规章 / 国家标准 / 行业标准时**必填**。形态与 §概念字段块 一致——**类型标记 + 字段块**，编号仍是 `[Lxx]`，不新立 `[L-法NN]`。
> **判据（**T7 人工，刻意不挂机检门**）**：正文把它当**现行依据**引用而本块 `现行有效性` ≠ `现行有效` → **T7 判 P0**。理由：字段**真伪**（该法规是否真的现有效）是语义判断；机械门只能查「字段填没填」，那会造出「填了就算核过」的假绿（登记见 [`../_shared/规范-机械门对照表.md`](../_shared/规范-机械门对照表.md) §三）。

- **文书名与条款号**：如《食品安全国家标准 食品添加剂使用标准》GB 2760-2014 第 3.1 条
- **效力层级**：法律 / 行政法规 / 部门规章 / 国家标准 / 行业标准 / 地方性法规
- **发布-生效日**：YYYY-MM-DD（**发布日与生效日各一，两个都要**）
- **现行有效性**：现行有效 / 已修订（写明替代文书）/ **已废止**（写明废止文书与日期）

## 铁律

> 版本差异表（v2.2.0→v2.2.1/1.1 逐版明细，教训 #78）已外移 CHANGELOG；本模板只留现行契约。

- **每一条都必须真实存在**：标题、作者、年份、来源全部可核验
- **可信度分级要诚实**：C 级（公众号、媒体报道、二手转引）必须标 C，不许伪装成学术来源
- **每条文献标「信任级别」（v2.2.1 新增）**：默认 = 已发布；主人提供的内部资料标「主人投喂」+ 数据包路径
- **检索不到 → 写「未检索到」**，不许凑数、不许编造、不许「据可靠来源」
- **优先一手文献和权威期刊**；综述类文献标注清楚
- **全文不可及（付费墙）** → 标注「付费墙：仅核验摘要」，用摘要信息，不假装读过全文
- **参考文献条目按任务简报指定格式输出**（默认 GB/T 7714：期刊[J]/专著[M]/电子文献[EB/OL] 标识区分），写手可直接粘贴
- **作者必填且禁「待核」占位**（v2.2.10 新增，教训 #107）：作者字段是必填项，**不允许「待核」「暂无」「unknown」等占位符**。处理流程：
  - 能查到作者 → 填作者全名
  - 查不到作者（如匿名预印本 / 机构发布）→ 填「机构名」+ 标记 `[匿名发布，非个人作者]`
  - 实在查不到 + 不可代替 → **不入库**（**T7** 之前该条作废，v2.3.0 改 T5→T7，不进 [Lxx] 列表）
  - **质量缺口**：原设计“允许『待核』后补”导致 L08 作者名待核 → **T7** 才修（v2.3.0 改 T5→T7，主人在 ECS 实战发现）
