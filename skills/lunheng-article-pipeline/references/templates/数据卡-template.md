## 数据卡格式（每条）

```
[D01] 数值 + 单位 | 来源机构 | 年份 | URL
      ├ 信任级别：已发布 / 主人投喂 / 二手转引（v2.2.1 必填）
      ├ 时效评级：🟢 ≤2年 / 🟡 2-5年 / 🔴 >5年
      ├ 口径说明（如：城镇 vs 农村、调查样本量、统计范围）
      └ 冲突并列：同指标多来源矛盾时，并列呈现所有来源+口径差异，不擅自二选一

[D02 测算值] 数值（计算说明：基于 D01 × D03）
      ├ 信任级别：二手转引（v2.2.1 必填）——）
      ├ 测算依据：D01 与 D03 相乘，如实标注「测算值（基于 D01 × D03）」
      ├ 时效评级：随原始数据时效
      └ 测算者：**T4** 分析员（v2.3.0 改 T3→T4）/ T2 检索员 / 主人投喂

[D03 二手转引] 数值（转引自 L05 论文第 N 页）
      ├ 信任级别：二手转引（v2.2.1 必填）—— v2.2.1 防 F8.3 转引未标注
      ├ 原始出处：[L05] 作者. 标题[J]. 期刊, 年份.
      ├ 时效评级：随原始数据时效
      └ 二手说明：本文通过 L05 引用，原始数据由 X 机构 Y 年发布
```

## 三档信任级别使用规则

### 已发布（论衡主动采集）
- 数据源：教育部 / 统计局 / 世界银行 / CEIC / 联合国 / 皮书系列 / 权威机构报告 / 已发表论文实证结果
- **论衡主动采集**，T2 用 web_search / web_search 直接检索
- 数据卡格式：（命令已剥离·DSH 用 read 推理）

### 主人投喂（论衡不主动采集，需主人提供原始数据）
- 数据源：主人一手调研 / 实验 / 访谈 / 田野调查 / 公司内部数据 / 客户问卷
- **论衡不可主动采集**，主人必须投喂原始数据 + 数据卡
- 数据卡格式：（命令已剥离·DSH 用 read 推理）
- 数据包文件路径：`主人投喂数据存放路径`

### 二手转引（论文中转引其他文献的数据）
- 数据源：其他文献 / 论文 / 报告中转引的数据
- **论衡不可主动采集**，需主人明示「这是二手转引」+ 原始出处
- 数据卡格式：（命令已剥离·DSH 用 read 推理）
- **v2.2.1 防 F8.3 转引未标注**——任何 [Dxx] 数据若引用其他文献，必须标注「二手转引」+ 原始出处 [Lxx]

## 铁律

- **每条数据必须真实存在 + 来源可核验**
- **每条数据必须有信任级别标注（v2.2.1 强制）**
- **找不到精确数据 → 标注「缺口：建议人工查 XX 数据库」**，不许估一个"约"
- **区分：官方统计 / 学术研究数据 / 媒体转引**（媒体转引要回查原始来源，标「二手转引」）
- **数据冲突强制并列**：两个来源数值矛盾 → 两条都写，说明口径差异
- **🔴 红级数据（>5 年）必须显著标注**
- **测算值如实标注**：测算公式 + 原始数据出处，不伪称有第三方来源
- **二手转引必须标 Lxx 原始出处**（v2.2.1 防 F8.3）

## 表格格式数据卡（v2.2.1.2 新增，教训 #83 + #84）

**适用场景**：v2.1.4 之前的项目常用「1.x / 2.x」表格格式（如实战 4 品牌一致性数据卡），不是 [Dxx] 编号格式。

**v2.2.1.2 起 M-Form-6 + M-Exist-3 双格式支持**——表格格式必须有「信任级别」列。

### 表格格式模板

```markdown
| # | 数据点 | 数值 | 来源机构 | 年份 | 时效 | **信任级别** | 出处 |
|---|--------|------|----------|------|------|-------------|------|
| 1.1 | 全渠道一致呈现品牌，收入增幅 | 均值 10-20% | Lucidpress / Marq | 2016/2019 | 🟡 | **已发布** | URL |
| 1.6 | 为信任的品牌支付更高价格 | 87% | Capital One Shopping | 2024 | 🟢 | **二手转引** | URL |
| 2.1 | DMI Design Value Index 219% | 219% | DMI / Design Value Index | 2014 | 🔴 | **已发布** | URL |
| 3.3 | 71% 品牌决策性印象 | 71% | Renderforest | 2024 汇编 | 🟡 | **二手转引** | URL |
```

### 表格格式字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| **#** | 必填 | 编号（1.1 / 1.2 / 2.1 / 5A.1 等），用于正文交叉引用 |
| **数据点** | 必填 | 一句话数据描述 |
| **数值** | 必填 | 具体数值（避免模糊表述如「约 XX」「大致 XX」）|
| **来源机构** | 必填 | 数据发布机构（教育部/统计局/公司年报/学术期刊等）|
| **年份** | 必填 | 数据年份（不是检索年份）|
| **时效** | 必填 | 🟢 ≤2年 / 🟡 2-5年 / 🔴 >5年 |
| **信任级别** | **v2.2.1.2 必填** | **已发布 / 主人投喂 / 二手转引**（用 `**...**` 加粗）|
| **出处** | 必填 | URL 或论文标题 |

### 表格 fallback vs 标准格式混合使用

实战 4（品牌一致性）数据卡是**纯表格格式**；实战 5（教师场域孤岛）数据卡是**纯标准格式**。两种格式可以**同时存在于一个项目**：

- 主表用表格格式（适合大量数据点）
- 子表用 [Dxx] 编号格式（适合核心引用）

**v2.2.1.2 M-Form-6 + M-Exist-3 同时校验两种格式**。
