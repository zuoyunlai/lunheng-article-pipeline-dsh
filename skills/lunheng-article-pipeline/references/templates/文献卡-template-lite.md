# 文献卡模板（精简版，v2.2.14）

> **精简版**：只保留骨架 + 必填字段，详细说明见 [`文献卡-template.md`](文献卡-template.md)

## ⚠️ 机检硬格式（v18.0.0 新增 —— 这几条不照做，下游 M 门必失败）

> **为什么单列**：模板此前是「人读的」、而 `m-gate-check.mjs` 是「机读的」，两者从未对照勾稽 → 子代理按各自排版自由度产出，主控被迫逐条返工（实战：单个项目 5 类格式返工、约 40 次 edit，**全部不改变内容质量**）。
> 以下为脚本会扫的**确切字面**，请逐字照写：

| 机检项 | 必须的确切形态 | 违反后果 |
|--------|--------------|---------|
| 索引段标题 | `## 📇 索引段`（emoji 📇 + 空格，**逐字**） | M-Form-10 判「缺索引段」→ 下游按索引定位会漏卡 |
| 条目标题 | `### [L01] 主题`（**方括号**包裹编号） | M-Form-11 判「编号在卡片中无对应条目」 |
| 索引段编号 | 索引表内亦须用 `[L01]`（**带方括号**） | M-Form-10 判「索引缺 N 条」 |
| 头部条数声明 | 只声明 `[Lxx]` 正文条目数（如「总条数：18 条」）；先行者/基线等他类条数**另列**，勿混入同一「总条数」 | M-Form-10 判「头部声明 ≠ 正文条目」 |
| 收录范围 | 文献卡只收 `[Lxx]`；先行者另立 `literature/先行者清单.md`（`[先NN]`） | M-Form-11 ghost 判定误报 |

````markdown
# 文献卡（Lxx 系列）

> **位置**: （检查 literature/文献卡.md）
> **检索员**: T1 文献侦查员（启动时间 + 模型）

- **信任级别声明**: 已发布 N1 / 二手转引 N2（N1+N2 = N）

|---|---|---|---|---|

## 文献卡格式（每条）

```markdown
### [L01] 文献标题
- **作者**: xxx
- **年份**: YYYY
- **来源**: 期刊/会议/出版社
- **URL/DOI**: 必填（M-Exist-1 校验）
- **信任级别**: 🟢 已发布 / 🔴 二手转引
- **核心观点**: 一句话说人话
- **支撑论点**: 论点 X（详见分析大纲.md）
- **引用位置**: 第 X 章第 X 节
```

## 交付前自检

<!-- 人类验证命令（agent 零 exec，由主控 LLM 推理完成） -->
- 统计实际条目数：`^### [L` 开头行数
- 统计声明总条数：基本信息段声明的 N
- 两数必须一致 → T2.5 闸门不拦截

**关键约束**：

| 字段 | 说明 |
|------|------|
| **URL/DOI 必填** | M-Exist-1 校验 |
| **信任级别必填** | M-Form-6 + M-Exist-3 |
| **核心观点** | 一句话说人话，不是摘抄 |
| **支撑论点** | 必填（F1 论证依据匹配） |
````
