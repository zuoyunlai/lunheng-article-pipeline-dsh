# 文献卡模板（精简版，v2.2.14）

> **精简版**：只保留骨架 + 必填字段，详细说明见 [`文献卡-template.md`](文献卡-template.md)

````markdown
# 文献卡（Lxx 系列）

> **位置**: `run/<项目名>/literature/文献卡.md`
> **检索员**: T1 文献侦查员（启动时间 + 模型）
> **截止**: YYYY-MM-DD

## 基本信息

- **总条数**: N
- **信任级别声明**: 已发布 N1 / 二手转引 N2（N1+N2 = N）

## 子问题分组结构

### 子问题 1: [描述]
- [L01] 文献标题
- [L02] 文献标题

### 子问题 2: [描述]
- [L03] ...

## 文献卡格式（每条）

```markdown
### [L01] 文献标题
- **作者**: xxx
- **年份**: YYYY
- **来源**: 期刊/会议/出版社
- **URL/DOI**: 必填（M-Exist-1 校验）
- **信任级别**: 🟢 已发布 / 🔴 二手转引
- **核心观点**: 一句话说人话
- **支撑论点**: 论点 X（详见分析大纲.md）
- **引用位置**: 第 X 章第 X 节
```

## 交付前自检

```bash
grep -c "^### \[L" 文献卡.md           # 实际条目数
grep "^## 基本信息" -A 3 文献卡.md    # 总条数
# 两个数字必须一致 → T2.5 闸门不拦截
```

**关键约束**：

| 字段 | 说明 |
|------|------|
| **URL/DOI 必填** | M-Exist-1 校验 |
| **信任级别必填** | M-Form-6 + M-Exist-3 |
| **核心观点** | 一句话说人话，不是摘抄 |
| **支撑论点** | 必填（F1 论证依据匹配） |

---

**精简版结束**

> 完整版见 [`文献卡-template.md`](文献卡-template.md)
````
