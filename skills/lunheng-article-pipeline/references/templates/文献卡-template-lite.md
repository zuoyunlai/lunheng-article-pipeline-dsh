## 文献卡格式（每条）

```markdown
### [L01] 文献标题
- **作者**: xxx
- **年份**: YYYY
- **来源**: 期刊/会议/出版社
- **URL/DOI**: 必填（M-Exist-1 校验）
- **信任级别**：已发布 / 主人投喂 / 二手转引（三档，全角冒号直跟档位词；**禁 emoji 前缀、禁加粗档位词**，形态同数据卡 §硬约束）
- **关联强度**: 强 / 中 / 弱 / 装饰性（v18.10.0 战略反哺 P1-1 新增；强 = 该文献为本文核心证据 / 中 = 支撑型 / 弱 = 辅助型 / 装饰性 = 仅列于文末未在正文引用）
- **核心观点**: 一句话说人话
- **支撑论点**: 论点 X（详见分析大纲.md）
- **引用位置**: 第 X 章第 X 节
- **方法学字段块**（**仅当该条目是方法论文时填**，即被 `[L00]` 索引行指向者；其余文献整块省略）:
  - **方法学适用条件**: 该方法的识别假设
  - **本文是否满足**: 满足 / 不满足（+ 依据；不满足须在正文降格表述）
  - **已知失效情形**: 替代解释 / 边界条件
  - **敏感性检验**: 计划或已做
- **概念字段块**（**仅当该条目是本文的「核心构念」时填**，其余条目整块省略）:
  - **概念术语** / **本文采用的定义**（可判定）/ **并存竞争性定义及分歧点** / **本文操作化指标**（→ 对应 `[Dxx]`）/ **边界条件**（明确不包含什么）
- **法规字段块**（**仅当条目「类型」为法律法规 / 国家标准 / 部门规章时填**）:
  - **文书名与条款号** / **效力层级** / **发布-生效日**（两个都要）/ **现行有效性**（现行有效 / 已修订 / 已废止）——正文当**现行依据**引用而此处非「现行有效」→ **T7 判 P0**
```

## 交付前自检

<!-- 自检命令：能跑就跑并贴实测值；跑不了就按可复算形态写实据（DSH 下子代理继承会话工具面，含 pwsh） -->
- 统计实际条目数：`^### [L` 开头行数
- 统计声明总条数：基本信息段声明的 N（须与索引段「总条数」一致；`[L00]` / `[L99]` / `[L-cross]` **不计入**）
- **信任级别分类计数（v19.5.0）**：`信任级别声明：已发布 N1 / 主人投喂 N2 / 二手转引 N3` 须**由逐条独立行自动统计生成**（禁手写）——三档值 + 双标数 + 未声明数**分别**等于逐条独立行统计（双标 = 同一行并列两种来源成分，**单列不并入**）
- **缺口条目单列（v19.5.0）**：检索不到的项以 `[Gnn]` **单列一节**，**不计入「总条数」**（契约见 [`../_shared/机检硬格式.md`](../_shared/机检硬格式.md) §十一）
- 两数必须一致 → T2.5 闸门不拦截

**关键约束**：

| 字段 | 说明 |
|------|------|
| **URL/DOI 必填** | M-Exist-1 校验 |
| **信任级别必填** | M-Form-6 + M-Exist-3 |
| **核心观点** | 一句话说人话，不是摘抄 |
| **支撑论点** | 必填（F1 论证依据匹配） |
