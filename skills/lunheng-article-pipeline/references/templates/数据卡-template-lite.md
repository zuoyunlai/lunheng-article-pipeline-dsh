**关键约束（v2.2.1 起强制）**：

| 字段 | 说明 |
|------|------|
| **信任级别必填** | 每条 [Dxx] 必须标 🟢/🟡/🔴（M-Form-6 + M-Exist-3 校验） |
| **URL 必填** | M-Exist-1 双向 对比 校验 |
| **时间窗口** | G11 时效告警 |
| **支撑论点** | F1 论证依据匹配 |

**字段命名约定**：
- 主题：一句说人话
- 数值：精确数字 + 单位
- 来源：机构 + 年份 + URL
- 支撑论点：链向分析大纲
