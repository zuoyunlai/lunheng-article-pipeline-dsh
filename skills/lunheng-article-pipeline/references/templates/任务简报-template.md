    # 或 Python（最准，含扩展区）
    python3 -c "import re,sys; print(len(re.findall(r'[\u4e00-\u9fff]', open('file.md').read())))"

## 配图需求（v2.3.7 实战升级，P1-1 必填段）

**重要**（v2.3.7 论文三实战升级）：本段必须明确填写图位数量 + 类型 + 数据源，不可空缺。

- **图位数量**：N 张（写明具体数字，如 0 / 1 / 3 / 5，写手 v1 必产 ≥N 个 `[图N：标题]` 图位）
- **类型**：

  - □ 封面视觉（DSH 无文生图：SVG 矢量风或主人投喂；可另配图像 MCP）
  - □ 概念图（无数据支撑的逻辑框架图，主控 SVG 手写）
- **数据源**：图表数据来自哪条数据卡/文献卡/案例卡？写明 `[Dxx]`/`[Lxx]`/`[Cxx]` 编号（如 `[D-基-R-01] [D-基-E-01]`）
- **示例**：
  - 「图位数量：3 张」「类型：数据图表」「数据源：[D-基-R-01] 一致性阈值 / [D-基-E-01] 资金流量 / [D-基-C-01] 案例事件」

  - 「图位数量：1 张」「类型：封面视觉」「数据源：-」（单封面项目）

## 主人深度洞察素材（v2.4 起，v2.1.4 明示化，v2.1.5 加类型分类）

主人在 Phase 3.5 提供的亲身经历/观察，可作为案例素材以 `[C-主xx]` 编号进入正文。每个洞察独占一行，注明出处 + **类型**（v2.1.5 新增，必须二选一）：

- **[C-主01]**：（主人原话/观察描述） ｜ **类型**：[观点来源 / 理论贡献]
- **[C-主02]**：（主人原话/观察描述） ｜ **类型**：[观点来源 / 理论贡献]
- ...

**两种类型的区别**（论衡 v2.1.5 明示化）：

| 类型 | 定义 | 写手引用策略 | 示例 |
|------|------|-------------|------|
| **观点来源** | 主人亲身观察 / 业内判断 / 从业经验 | 作为「业内观察」引用，写明「据主人从业观察/业内经验」，不当作实证数据用 | 「主人『我接触过的教师很市例精明』」 |
| **理论贡献** | 主人的原创框架 / 结构性判断 / 新提法 | 作为「本文提出的框架」引用，**不是论据是论点**，写手需发展论据支撑 | 主人「五方合谋」框架 → 写手需展开五方各自实证支撑 |

**注意**：① [C-主xx] 不进入 cases/案例卡.md（独立编号空间）；② 终稿文末「案例来源」节需为每个 [C-主xx] 留 1 条「主人深度洞察」说明（含任务简报第 X 行出处 + 类型）；③ 主控融合时需按写手卡「主体声音 ≠ 第一人称经历」铁律客观化处理（详见设计文档 v2.4 原创性保证 + 写手卡视角与精度铁律）；④ **类型必须在 Phase 3.5 由主人明确标注**——主控不可默认推断，因为「理论贡献」+「观点来源」的边界很微妙，主人最清楚。

**洞察-数据一致性预检（v2.3.2 新增，教训 #132）**：主人洞察里若引用了具体数据（如「中国 61% 监管信任」），主控在 Phase 1 检索后必须**回查该数据是否可被检索到**——若不可检索/不可验证 → 标 🔴，T4 分析员准备替换为可检索数据（或让主人补充数据出处）。**防止主人洞察里的「引文锚」是不可验证数据 → 写手误当硬数据引用 → T6 攻击「数据无源」**。

## DSH 执行约定（写到任务简报后由主控+角色同步执行）

每个角色启动后更新 `status.md` 对应行为 `🔄 In Progress` + 写明「启动时间 + 当前模型」。完成交**交接报告六要素**（做了什么/产物在哪/怎么验证/已知问题/下一步 + status.md 更新）。模型降级/主控介入/失败必须写明时间+原因。

**主控介入标准动作（DSH 精简版）**：
1. 查 status.md 该角色状态（缺失或停滞 = 异常 → 介入）
2. 用 `list_agents` 看子代理最近输出（判断真卡还是模型思考中）
3. 模型异常（静默无产出）→ 换档重派（如 `subagent_strong`→`subagent_retrieval`，或改 `LUNHENG_*_MODEL` 后重启）
4. 产生物到中途中断（partial output 存在）→ 接受现有产出，手动补齐缺失部分
5. 在 status.md 阶段行写明介入记录：`[介入 HH:MM] 主控介入, session-kill/换档重派, 说明=
6. 同场景重试 ≤2 次，仍卡 → 升级主人决定
