## ⚠️ 机检硬格式

> **单一真源**：[`../_shared/机检硬格式.md`](../_shared/机检硬格式.md)（**§五 任务简报**）——v18.0.3 起本文件不再复述表格（此前同一契约有 5 份副本且已互有差异）。四条要点：研究问题写「子问题 A/B/C…」、数据需求写「需找数据点 ≥N」、基线编号用 `[D-基-{R/T/C/E}-{NN}]`、Phase 1.5 必须显式 `trigger: true/false`。

````markdown
# 任务简报：<题目>

> **位置**: `run/<项目名>/01-任务简报.md`（项目根；主控 Phase 0 产出，全角色派发时引用）
> **类型**: 主控 Phase 0 必读
> **截止**: YYYY-MM-DD

## ⚡ 引用模式锁定（v2.2.10）

- 学术编号 `[Lxx]/[Dxx]` ☐ / 内联（机构，年份）☐

## 基本信息

- **主题**: 一句话说人话
- **类型**: 学术论文 / 商业评论 / 行业分析 / 公众号深度长文
- **篇幅**: 轻量 ≤4000 / 中段 4000-8000 / 重量 8000+
- **deadline**: YYYY-MM-DD
- **文风档位**: 克制（学术默认）/ 中性 / 鲜明

## 研究问题

> **机检要求**：编号须写成「子问题 A / B / C …」（见上「机检硬格式」表）。

- **子问题 A**：本文回答 [核心问题 1]
- **子问题 B**：本文回答 [核心问题 2]
- **子问题 C**：本文不回答 [边界]

## 数据/文献/案例需求

> **机检要求**：数据需求须写成「需找数据点 ≥N」（见上「机检硬格式」表）。

- **数据**（需找数据点 ≥N）: 需要什么口径的数据
- **文献**: ≥3 篇同行评审文献
- **案例**: ≥3 个具体企业/事件案例（**0 条场景须显式声明 cases=0**，T3 走空卡协议）

## Phase 1.5 补检索触发条件（v2.5.2-dsh.8）

- **trigger**: `false`（主控 Phase 2.5 与主人确认后回填；true 则列必补关键词）
- **必补关键词**: 无

## 主人深度洞察（如有）

- **[C-主01] 类型**: 观点来源 / 理论贡献
  - 内容: 一句话

## 防哪些 F 模式

- F1 幻觉引用 / F2 幻觉数据 / F3 早期框架锁定 / F5 拼凑式断裂 / F7 主人风格失真

## Phase 0 同意关卡

- ① 全部同意（默认）
- ② 脱敏+SVG 封面+本地 Ollama
- ③ 部分同意（指定外发项）
- ④ 全部拒绝（改纯本地）

## 主人侧输入与待办（v2.5.2-dsh.17）

- **主人确认往返**：共 **4 次**（Phase 0 现在 / 2.5 大纲 / 3.5 洞察 / 5 终稿），每次读确认单 1-3 小段
- **需要准备的材料**：□ 一手数据（走 `主人投喂清单-template.md`）□ 旧作 1-2 篇（风格基线）□ 案例素材 □ 图片/封面 □ 期刊要求 □ 署名
- **投喂入口只有一处**：`run/<项目>/主人投喂清单.md`（主控按 4 项校验：路径存在 / 口径时间 / 可引用性 / 脱敏与同意；缺一当场退回）
- **Phase 0 不必定死的**：具体图位（Phase 2.5 拍板）、具体期刊（T9 后 Top 3）、各段论点（Phase 2）

**精简版结束**
````
