## Phase 0 同意关卡

**主控 Phase 0 写入简报头部（机器可读；三段缺任一即硬失败 = `handoff-check.mjs` A11）**：

`外部服务授权：检索=<全网检索|仅本地素材|仅项目素材|仅素材池> / 推理=<远程 provider 名|本地 Ollama> / 脱敏=<basic|strict>`

- **检索**：`全网检索`（默认）／`仅本地素材`（池 + 投喂）／`仅项目素材`（仅投喂）／`仅素材池`（仅池）；本地三档均**不外网 ≠ 零外发**
- **推理**：写**实际**位置；**大模型推理始终读到全文**，选「仅本地素材」也不关闭（除非真走本地 Ollama）
- **脱敏**：`basic`（默认）／`strict`；也可用独立的 `ETHICS=basic|strict` 行（二者同源，**不得都缺**）
- 串里留 `<…>` 视为**未填**；旧式单标签（①全部同意 ②脱敏+SVG ③部分同意 ④全部拒绝）**存量仍被接受**，新项目用上面的串
- **证据素材池（v19.6.6 新增，机器可读）**：`POOL=新建|已存在 / 路径=<工作区根>/evidence-pool / 现有条数=N(L=.. D=.. C=.. DB=..) / 命中=<M> / 检索范围=<全网检索|仅本地素材|仅项目素材|仅素材池>`
