# 轮次账本模板（`drafts/轮次账本.md`）

> **用途**：修订回环的**轮次额度真源**（A 轨 ≤2 / B 轨 ≤1 / G 环 ≤2；相位轮无额度）。
> `apply-revision-cycle.mjs` 落账、`handoff-check` 的 A9/A14 读本表——**表头即契约**：
> 机器先认表头列名，再按列取值；**没有模板时人只能猜列序**（本项目把「轮次」放第一列 →
> 整表被判「未知轨名」，A 轨轮次不可信）。
>
> **格式真源**：`scripts/_lib/round-ledger.mjs` 的 `LEDGER_HEADER` + 本模板；格式变更必须同批改两处。

## 一、规范表头（二选一）

**最小表（6 列，`LEDGER_HEADER` 产出的形态）**

```markdown
| 轨 | 轮次 | 正文版本 | 触发来源 | 复核报告 | 时间 |
|---|---|---|---|---|---|
| A | 1/2 | drafts/初稿-v2.md | audits/审计报告-v1.md | audits/复核报告-v1.md | 2026-10-19 |
```

**扩展表（7 列，允许；列名必须逐字照写）**

```markdown
| 轨 | 轮次 | 来源 | 正文版本 | 被审正文 sha256 | 复核报告 | 关闭状态 |
|---|---|---|---|---|---|---|
| A | 1/2 | T7 审计打回（P0×2 / P1×5） | drafts/初稿-v5.md → drafts/初稿-v6.md | 9128b652…（可选） | audits/复核报告-v1.md | 关闭 |
```

> **列名硬约束**（`parseLedger` 按名匹配，不按位置）：`轨` / `轮次` 必须存在；其余列任意顺序。
> 认不出的列会被忽略（可保留「被审正文 sha256」「关闭状态」等自由列），但**不得改名**——
> 把「复核报告」写成「复核」仍可（别名），写成「报告 N」则 A9 读不到 → 判「缺复核报告」。

## 二、单元格硬格式

| 列 | 合法值 | 违反后果 |
|---|---|---|
| `轨` | 逐字 `A` / `B` / `G` / `相位` | 判「未知轨名」，该行不计入额度 |
| `轮次` | **`n/m`**（如 `1/2`），`m` = 生效额度（默认 A2/B1/G2；可被头部授权行上调） | 写成 `1` / `已用一轮` → 该行进 `malformed`（逐行降级，不牵连整表） |
| `正文版本` | 相对项目根的路径（`drafts/初稿-v5.md`；改后版本可写 `v5 → v6`） | 空 → A9 无法核对复核指纹（soft） |
| `复核报告` | 相对路径；或**显式豁免** `—（同轮无独立复核：<理由 ≥4 字>）` | 空 = 缺口（硬 21）；豁免 = soft 22 |
| `被审正文 sha256` | 可选；64 位 hex 或前缀 | 仅登记用，A9 以复核报告内的指纹为准 |
| `关闭状态` | 可选；`关闭` / `部分` / `未关闭` | 仅登记用 |
| `时间` | `YYYY-MM-DD` | 仅登记用 |

## 三、额度授权行（主人显式上调时）

写在表头之上、**以 `>` 开头**（逐字形态；只许上调、须含依据）：

```markdown
> 额度授权：A=3（依据：主人 2026-10-08，阶段确认-Phase0.md §6）
```

- 无「依据：」或未提「主人」→ **不生效**，并计入 `malformed`。
- 授权后追加行的分母自动写新额度（`appendLedgerRow` 读授权行）。

## 四、轮次 ≠ 草稿版本号

`v1..v5` 里可能只有 **1 个 A 轨轮**（其余是首稿 / Phase 3.5 / Phase 3.6 / B 轨）。
**轮次以本表为准**；`apply-revision-cycle.mjs --track A` 会在开轮时自动追加一行，
不要手填与脚本重复的行。

## 五、消费点

| 消费者 | 读什么 | 缺表/坏行的行为 |
|---|---|---|
| `handoff-check` A9 | 每行 `正文版本` + `复核报告` + 指纹 | 表不存在 → 不判（存量形态）；坏行 → 逐行降级 |
| `handoff-check` A14 | `正文版本` → 是否有可应用 diff 载体 | 无载体 → 硬 21（补清单即可，不改正文） |
| `apply-revision-cycle.mjs` | `counts` / `caps` / `over` | 无表 → 只提示不阻塞（新项目应建表） |

> 并确认 `LEDGER_HEADER` 与本模板的「最小表」逐字一致（`round-ledger.test.mjs` 会钉）。
