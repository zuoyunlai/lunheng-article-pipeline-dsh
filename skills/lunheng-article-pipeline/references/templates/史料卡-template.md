# 史料卡模板（完整版，v19.26.0）

> **用途**：一手史料 / 原始文本 / 档案 / 译本 / 报刊 / 日记 / 回忆录的**独立编号族 `[Sxx]`**。
> **与文献卡的分界**：研究对象**本身**（文本、档案、译本、报刊）→ `[Sxx]`；**他人研究该对象的论著** → `[Lxx]`。同一条目不得双列（双列 → M-Form-11 幽灵/孤儿双向误判）。
> **与案例卡的分界**：案例卡是**事件**（时间/地点/主体/经过/多方说法）；史料卡是**文本与实物**（版本/卷次/页码/馆藏）。一次事件留下的**报道与档案** → 史料；事件本身的分析 → 案例。
> **机检契约**：[`../_shared/机检硬格式.md`](../_shared/机检硬格式.md) §一 通用 + §四·二 史料卡专属。

## 一、字段语义（逐条必填）

| 字段 | 语义 | 常见错误 |
|---|---|---|
| **类型** | 档案 / 原始文本 / 译本 / 报刊 / 日记 / 回忆录（受控六类） | 写「一手资料」「文献」等泛称 → 无法判分界 |
| **作者 / 机构** | 成文者；档案写形成机关 | 把**收藏机关**当作者（如「某某档案馆」） |
| **年代** | **成文年** 与 **版本年** 分开写（译本尤其重要） | 只写一个年份，导致「理念流动」的时间锚点不可判 |
| **出处** | 可核形态**任一**：馆藏号 / 卷次期号 / 页码 / 版次 / URL / DOI | 只写「见某某书」——**T7 判 P1（史料不可核）** |
| **可信度** | 高 / 中 / 低 + 一句理由（原件/重印/译本/转录） | 只写档位不写理由 |
| **信任级别** | **三档受控词**：已发布 / 主人投喂 / 二手转引（真源 `_lib/trust.mjs`） | 自造「官方」「馆藏」等词 → M-Integrity-1 连锁 P0 |
| **关联论点** | 子问题 + 论据编号（与大纲映射表对齐） | 写「背景」类泛用理由 |
| **核验记录** | 核验日期 + 渠道（在线/馆藏书目/影印件） | 空着或写「已核」 |

## 二、出处颗粒度（按类型）

| 类型 | 最低颗粒度 |
|---|---|
| 期刊原始文本 | 刊名 + 卷 + 期 + 起止页（+ URL/DOI） |
| 专著 / 译本 | 出版社 + 版次 + 页码；译本另加**原作名 + 原作年 + 译者** |
| 档案 | 档案馆名 + **全宗/案卷号**（有则必填）+ 件号/页码 |
| 报刊 | 报名 + 日期 + 版次；社论/署名文章须标作者 |
| 日记 / 回忆录 | 版本 + 页码 + 成文年（与出版年区分） |

## 三、版本选择判据（v19.26.0 登记）

1. **优先原始发表版本**；用重印本/文集本时，必须在「出处」里写出**所用版本**，并在正文首次引用处注明「本文据 XX 版」。
2. **译本不是原件**：凡据译本立论，正文须允许「转译偏差」的讨论空间；关键概念词（如 administration / 行政）须回原文对勘。
3. **同一文本多版本**：只建**一张** `[Sxx]`，版本差异写在该条目内（不拆号）；确需分号时用 `[S01]` / `[S01b]` 式后缀**并在核验记录里说明**（后缀不进入机检编号族，须人工核）。

## 四、机检与审计责任

- **M-Exist-1**：正文 `[Sxx]` ↔ 文末 `## 数据来源` 内 `### 史料` 子节条目**双向闭环**（漏引/孤儿均判）。
- **M-Form-10**：索引段 ↔ 条目 ↔ 头部总条数三方对账（同其他卡）。
- **M-Form-8**：`[Sxx]` 计**第五类证据**；**不计入文献族**——纯史料段仍须与文献对话（或走 `ACCEPTED-GAPS:`）。
- **M-Form-7**：史料条目**只能住 `## 数据来源` 内 `### 史料` 子节**；新开 `## 史料来源` 节 = 第十个 H2 → 白名单 P0。
- **T7 人工**：出处不可核 → P1；版本未注明 → P1；把他人研究当一手史料 → P1（分界错误）。

## 五、0 条场景

无史料需求的议题**不必建该卡**（`literature/史料卡.md` 缺失合法，M-Form-10 只记 note）。若建了卡但为 0 条，索引段写「（无）」，并在 `final/局限性.md` 说明「本议题不以一手史料为证据单元」。
