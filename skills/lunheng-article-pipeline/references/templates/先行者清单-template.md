# 先行者清单模板（v2.2.1.1 新增，教训 #77 + #78）

> **位置**：`run/<项目名>/literature/先行者清单.md`
> **主控**：T1 文献检索员（在文献卡检索的同时产出）
> **必查项**（v2.2.1 M-Form-6 + v2.4 原创性保证）：每条先行者必须有「信任级别」标注 + 「与本文的差异点」声明
> **创建原因**：v2.4 原创性保证机制要求 T1 主动检索「该主题是否已有公开深度文/论文写过类似核心论点」+ 补独立 template 防「隐藏先行者 → 学术不端」

## ⚠️ 先行者清单信任级别（v2.2.1 新增，教训 #77）

**每条先行者必须标注信任级别（2 档之一）**——v2.2.1 起 M-Form-6 强制校验：

| 级别 | 定义 | 论衡能否主动采集 | 标注格式 |
|------|------|---------------|---------|
| **已发布** | 公开发表的论文 / 公开可访问的公众号深度文 / 公开演讲 / 公开出版的书籍 | ✅ T1 主动采集 | `[先xx] ... 信任级别：已发布` |
| **主人投喂** | 主人提供的「已发表但未公开」资料 / 客户提供的内部研究报告 | ❌ 主人投喂 | `[先xx] ... 信任级别：主人投喂` |

**默认 = 已发布**——先行者文献天然是已公开的（T1 用 web_search / web_search 主动检索「主题 + 核心论点 + 已有研究」）。

**实战价值**：
- 实战「原创性悖论」（2026-08-13）：主控发现已有公众号深度文写过类似核心论点 → 暴露「T1 没主动检索先行者」机制缺口 → v2.4 补救
- 隐藏先行者 = 学术不端风险 → T1 主动检索是论衡原创性保证的核心机制

## 基本信息

- **主题**：
- **检索员**：T1 文献检索员（启动时间 + 模型）
- **检索截止**：
- **核心论点**（本文）：本文的核心结论是什么（先写出来，便于对照先行者差异点）
- **检索关键词**：「主题 + 核心论点关键词」、「主题 + 已有研究」、「主题 + 综述」
- **信任级别声明**：本次先行者清单已发布 N 条 / 主人投喂 M 条（合计 N+M = 总条数）

## 先行者清单格式（每条）

```
[先01] 文章标题 | 作者/来源 | 年份 | URL
      ├ 核心论点：该文的核心结论是什么（必填，T1 主动检索时归纳）
      ├ 信任级别：已发布（v2.2.1 必填，先行者文献天然=已公开；教训 #77）
      ├ 可信度等级：A（学术期刊/权威机构）/ B（公众号深度文/行业报告）/ C（自媒体/短文）
      └ 与本文的差异点：本文与它的不同之处（新角度/新数据/新切口/新结论；v2.4 原创性保证核心）

[先02 主人投喂] 文章标题 | 作者/来源 | 年份
      ├ 核心论点：...
      ├ 信任级别：主人投喂（v2.2.1 必填，防 F8.1 来源混入；教训 #77）
      ├ 数据包路径：主人提供的内部资料存放路径
      └ 与本文的差异点：...
```

## 实战场景分类

### 场景 A：未发现先行者（cases = 0）
**触发条件**：T1 主动检索「主题 + 核心论点」后未发现任何公开先行者。

**操作**：
```
[先-空] 本次检索未发现公开先行者
      ├ 检索关键词：「主题 + 核心论点」、「主题 + 综述」、「主题 + 已有研究」
      ├ 检索范围：CNKI / Google Scholar / 公众号 / 知乎 / 微博 / 行业报告（v2.2.1 防「检索范围过窄」漏判）
      ├ 检索截止：YYYY-MM-DD
      ├ 显式声明：本次主动检索未发现与本文核心论点重叠的公开深度文章（不排除存在但未公开 / 在付费墙后 / 用不同关键词的文献）
      ├ T1 状态：spawn + 空清单 + 立即 Done
      └ T0 合并层处理：标记「本次检索未发现公开先行者」，但不阻塞主流程（仍需 G7 原创性审计）
```

### 场景 B：发现 1-3 条先行者（轻量）
**操作**：每条按标准格式 + 与本文差异点必填（v2.4 原创性保证核心）。

### 场景 C：发现 ≥4 条先行者（重量）
**操作**：
1. 每条按标准格式
2. **分类组织**：按「核心论点相似度」分组（高/中/低 3 档）
3. **汇总表**：本文末尾加「先行者差异汇总」段

```
## 先行者差异汇总（v2.4 原创性声明）

| 先行者 | 核心论点 | 相似度 | 本文差异点 |
|--------|---------|--------|-----------|
| [先01] | XXX | 高 | 新切口：XXX；新数据：Dxx；新结论：XXX |
| [先02] | XXX | 中 | 延伸：XXX；新角度：XXX |
| [先03] | XXX | 低 | 间接相关：XXX |
```

## 铁律

- **每一条都必须真实存在**：标题、作者、年份、来源全部可核验
- **核心论点必填**：T1 主动归纳该文核心结论，不许写「略」或「待补」
- **与本文差异点必填（v2.4 原创性保证核心）**：差异点模糊 / 无实质差异 → P1
- **每条标「信任级别」（v2.2.1 新增）**：默认 = 已发布；主人提供的「未公开但已发表」资料标「主人投喂」+ 数据包路径
- **检索范围必须广**：至少覆盖 CNKI + Google Scholar + 公众号 + 知乎/微博 + 行业报告 5 类
- **不隐藏先行者**：发现「已有公开文章写过类似核心论点」必须列入清单，不许隐瞒（隐藏 = 学术不端风险）

## 与 T3 分析员「原创性声明」的协同

T3 在 `analysis/分析大纲.md` 末尾必填「原创性声明」（v2.4 新增）：

```
## 原创性声明（v2.4）
- 本文核心论点：[简述核心论点]
- 已知先行者：[先01] / [先02] / ...（引用本清单的 [先xx] 编号）
- 与先行者的差异点：本文核心论点与 [先01] 的不同在于...（v2.2.1.1 与先行者清单模板对齐）
- 相似度评级：高 / 中 / 低（如高相似度，必须实质性新贡献：新数据/新切口/新结论/新方法）
```

**T1 先行者清单 + T3 原创性声明 + T5 G7 原创性审计** = 论衡原创性保证的 3 道防线。
