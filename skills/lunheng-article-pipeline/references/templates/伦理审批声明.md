# 伦理审批声明模板

> 版本：v18.18.3（DSH bundle 插件 / 学术伦理声明 P0-5 新增）
> 用途：学术论文投稿必附的伦理审批声明（Ethics Approval Statement）。
> 生成规则：分三档——**需伦理审批** / **豁免伦理审批** / **不适用**；<方括号> 处按实填实。
> 引用：Declaration of Helsinki（WMA, 2013 修订版）；ICH GCP E6(R2)；中国《涉及人的生物医学研究伦理审查办法》（2016）

## 伦理审批声明

本文研究过程涉及的伦理事项声明如下：

### 1. 档位声明（三选一）

- □ **本研究已获伦理审批**（适用本框请打勾 + 填写第 2 节）
- □ **本研究获伦理审查豁免**（适用本框请打勾 + 填写第 3 节）
- □ **本研究不适用伦理审批**（适用本框请打勾 + 填写第 4 节）

### 2. 伦理审批详情（已获审批时填写）

| 项目 | 详情 |
|------|------|
| 审批机构 / 委员会 | <如：XX 大学医学伦理委员会 / IRB 编号 XXXX> |
| 审批编号 | <如：IRB-2024-001> |
| 审批日期 | <YYYY-MM-DD> |
| 审批有效期 | <YYYY-MM-DD 或「长期有效」> |
| 知情同意书获取 | <全体参与者 / 法定代表人 / 豁免 / 不适用> |
| 弱势群体保护 | <儿童 / 孕妇 / 认知障碍者 / 无 / 其他> |
| 数据隐私保护 | <匿名化 / 去标识化 / 加密存储 / 不适用> |
| 利益冲突（与 COI 节呼应） | <如：审批机构无利益关系> |

### 3. 豁免伦理审批详情（豁免时填写）

| 项目 | 详情 |
|------|------|
| 豁免理由 | <如：使用公开匿名化二手数据 / 不涉及人类受试者 / 仅文献综述> |
| 豁免审批机构 | <如：XX 大学 IRB 豁免批文，编号 XXXX> |
| 豁免日期 | <YYYY-MM-DD> |
| 知情同意豁免 | <如：公开数据已由原始采集方获取知情同意> |

### 4. 不适用伦理审批详情（不适用时填写）

| 项目 | 详情 |
|------|------|
| 不适用理由 | <如：纯理论研究 / 数学证明 / 文献综述 / 历史档案研究 / 计算机仿真> |
| 涉及主体 | <无人类受试者 / 无动物受试者 / 仅公开发表数据> |

### 5. 动物实验伦理（适用时填写）

| 项目 | 详情 |
|------|------|
| 动物伦理审批 | <如：XX 动物伦理委员会，编号 XXXX> |
| 实验动物使用许可 | <如：SYXK(XX)2024-XXXX> |
| 3R 原则（Replacement / Reduction / Refinement）执行 | <填实> |
| 实验动物福利 | <饲养条件 / 安乐死方法 / 人道终点> |

---

**填表指引**：

- **第 1 节档位必选一档**——三档互斥
- **涉人研究**（含访谈 / 问卷 / 行为实验 / 临床数据 / 生物样本）→ 第 2 节（已获批）
- **使用他人已公开数据**（含已发表数据集）→ 第 3 节（豁免）
- **纯理论 / 数学 / 仿真研究**→ 第 4 节（不适用）
- **涉动物研究** → 第 5 节必填
- **审批编号**：必须是正式编号（IRB / IACUC / 动物伦理委员会编号），不可写「已获审批但无编号」
- **期刊差异**：医学期刊强制要求；社会学期刊通常要求访谈类研究披露；纯理论 / 数学期刊通常允许"不适用"；投稿前须按目标期刊模板调整
- **跨语言要求**：中国研究须声明「符合《涉及人的生物医学研究伦理审查办法》」；欧美研究须声明「符合 Declaration of Helsinki」

**机检判别**：本声明节是否勾选三档之一——**T7 人工核验**「档位必选」+「涉动物必填节（如适用）」（⚠️ v18.12.0 起明确：「M-Form-12 子门」是 methodology-check.mjs 命名空间内的称谓，与 M 门体系编号不共用；档位勾选**无任何脚本在核**，由 T7 人工核）
