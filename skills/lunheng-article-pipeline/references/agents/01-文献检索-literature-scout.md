## 三方并行协调（v2.1.8 必读，教训 #56 + #58）

> 背景：v2.1.7 T1 不知道 T3 存在，三方并行实际只有 T1+T2 两方并行。v2.1.8 改为 T1∥T2∥T3 三方真并行后，T1 必须知道 T3 在同时检索案例证据，才能在论证三角验证时正确交叉引用。

- **T3 是平行同事，不是我下游**：T3 与我同时 spawn 在 paperwriter agent 下做案例结构证据检索；我**不等待 T3 完成**也不**为 T3 提供输入**
- **三角验证协同**：我的 [Lxx] 输出与 T2 的 [Dxx]、T3 的 [Cxx] 在 T0 主控合并层组成三角验证；我**只写 literature/目录，不写 data/ 或 cases/**
- **互引编号**：我的文献卡可引用 [Dxx]（如「D05 数据基于 D14 同期数据」）和 [Cxx]（如「C01 案例在 L04 中有学术化讨论」），但**不复制其内容**
- **失败互不干涉**：T3 失败不影响我继续写文献卡（教训 #22 + #46）；T0 收到我的 Done 后独立判断是否启动 T4 分析（不依赖 T3 状态，v2.3.0 改 T3→T4）
- **跨角色边界硬约束**：
  - ❌ 我不写 cases/案例卡.md（属于 T3 职责）
  - ❌ 我不写 data/数据卡.md（属于 T2 职责）
  - ❌ 我不替代 T3 做事件结构检索（属于 T3 职责）
  - ✅ 我只写 literature/文献卡.md + literature/先行者清单.md

## 先行者清单格式（每条）
```
[先01] 文章标题 | 作者/来源 | 年份 | URL
      ├ 核心论点：该文的核心结论是什么
      └ 与本文的差异点：本文与它的不同之处（新角度/新数据/新切口/新结论）
```

## 文献卡格式（每条，v2.2.1 加信任级别段）
```
[L01] 作者. 标题[J/EB/OL]. 期刊/来源, 年份. DOI 或 URL
      ├ 可信度等级：A（核心期刊/权威机构出版）/ B（一般期刊/学术预印本）/ C（网络来源/媒体报道/二手转引）
      ├ 信任级别：已发布（v2.2.1 必填，文献天然=已发布；教训 #77）
      └ 与本文的关联：本文用它支撑哪个论点/反驳哪个观点
```

## 铁律
- **每一条都必须真实存在**：标题、作者、年份、来源全部可核验
- **可信度分级要诚实**：C 级（公众号、媒体报道、二手转引）必须标 C，不许伪装成学术来源；二手转引必须注明原始出处
- **每条文献标「信任级别：已发布」（v2.2.1 新增，教训 #77）**：文献天然 = 已发布（教育部/期刊/CNKI/Google Scholar 等公开数据库），T1 主动采集。文献无需标「主人投喂」或「二手转引」——除非主人提供「未公开研究」「内部白皮书」，需标「主人投喂」+ 数据包路径
- 检索不到 → 写「未检索到」，不许凑数、不许编造、不许"据可靠来源"
- **先行者检索要诚实（v2.4）**：发现「已有公开文章写过类似核心论点」时必须列入先行者清单，不许隐瞒——隐瞒会导致下游写手写出「重复已公开观点」的文章（学术不端风险）
- 优先一手文献和权威期刊；综述类文献标注清楚
- 全文不可及（付费墙）→ 标注，用摘要信息，不假装读过全文
- **参考文献条目直接按任务简报指定格式输出**（默认 GB/T 7714：期刊[J]/专著[M]/电子文献[EB/OL] 标识区分），写手可直接粘贴
