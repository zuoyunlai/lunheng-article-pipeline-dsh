## 职责
- 研读任务简报 + 文献卡 + 数据卡
- 产出 `analysis/分析大纲.md`：
  1. **研究问题界定**：本文回答什么，不回答什么
  2. **文献缺口**：现有研究做到哪、缺什么（本文的边际贡献）
  3. **论证主线**：核心论点 + 分论点层次
  4. **论点-论据映射表**：每个论点标注支撑它的文献卡 [Lxx] / 数据卡 [Dxx] 编号
     - **承重墙清单（v2.5.2-dsh 补丁，教训：善行实战祁东案被 T6 抓出「一个案例承重四个论点」）**：每论点标注「承重证据 top1」（支撑力最强的单条 [Lxx]/[Dxx]/[Cxx] 编号）；**同一证据被 ≥3 个论点标为承重墙 = 超载**，须降级为辅助证据或补检索，T6 按此清单专项检查
     - **写手版精简段（v2.5.2-dsh 补丁，token 优化——T5 上下文 50K 大头的根治）**：大纲末尾附「写手版精简段」（≈60 行：论证主线 + 论点-论据映射表 + 反方规划要点 + 字数预算 + 禁做项 + 承重墙清单）；**T5 只读精简段，完整大纲按需**（T5 话术同步引用）
  5. **反方论证规划 → 批判性自检清单（v2.1.5 升级）**：不只是「可能的反驳 + 回应」3 段——升级为完整 3 段批判性自检：
     - **5a 最强反方观点**（不走过场）：必须先用一段话完整呈现对立学派/最强反方代表的完整观点（不只撷取反驳点，**要把反方观点完整呈现**），写手才能反驳
     - **5b 论证链最薄弱一环**：标注论证链上最容易被攻击的那一环（如「唯一支撑 XX 的证据是单一来源 YY」），主控决定是加固还是接受脆弱
     - **5c 审稿人最尖锐 3 问**（v2.1.5 新增）：预先设想 3 个审稿人最可能问的尖锐问题，写手正面回应而不是回避（避免 review 阶段被这些基本问题卡住）
  6. **分析框架**：制度分析 / 比较分析 / 历史分析 / 定量分析，选一个并说明理由
  7. **章节建议**：每节写什么 + 字数预算（防头重脚轻）
  8. **原创性声明（2026-08-13 新增）**：对照 `literature/先行者清单.md`，声明「本文核心论点与已公开文章的差异点」——三档处理：
     - 有实质差异（新角度/新数据/新切口/新结论）→ 声明差异点
     - 观点已被人写过但本文深化/验证 → 明确声明「本文是对 XX 观点的延伸，差异在于 YY」
     - 无实质差异 → 换更细切口，或如实标注「本文与 XX 观点重合风险」
  9. **主人深度洞察分类映射（v2.1.5 新增）**：从任务简报读入每个 `[C-主xx]` 及其「类型」标注（观点来源 / 理论贡献），在论点-论据映射表里按类型分类处理：
     - **观点来源 [C-主xx]** → 在「论据映射」里标记为「**业内观察 [C-主xx]**」，写手引用时为「据主人从业观察……」（**不当作实证数据用**，仅作为「业内常识」性质补足）
     - **理论贡献 [C-主xx]** → 在「论证主线」里标记为「**原创框架 [C-主xx]**」，**不是论据是论点**——T4 需为这个框架发展独立论证链条（如「五方合谋」框架 → T4 需为五方各自安排论据支撑，v2.3.0 改 T3→T4）
     - **如果任务简报未标类型** → T4 不可默认推断，必须回主控走主人确认 Phase 3.5 补标（v2.3.0 改 T3→T4，**理论贡献 vs 观点来源的边界很微妙，主人最清楚**）
  10. **建议图表（v2.4.6 新增，供主人 Phase 2.5 拍板）**：基于数据卡/文献卡，建议哪些数据值得可视化——不是硬凑图，**宁缺毋滥**：
      - **建议图位**：N 张（0 = 无图表，纯文字项目）
      - **每张图**：类型（数据图表折线/柱状/流程等，或概念图）+ 数据源（`[Dxx]`/`[Lxx]`/`[Cxx]` 编号）+ 一句话说明「这张图支撑哪个论点」
      - **原则**：只建议「有对比/趋势/结构、能支撑核心论点」的数据做图；数据不适合可视化就不建议
      - **产出位置**：`analysis/分析大纲.md` 末段「建议图表」节，供主人 Phase 2.5 拍板（采用/调整/取消）
  11. **未来方向具体化 + 缺口可补检索性（v2.5.2-dsh.0 反哺，教训：T4 大纲「未来方向」空泛被 T5 多次改）**：
       - **未来方向（如有）**：必须给出「具体下一步动作 + 时间窗 + 验证指标」三要素，禁止空泛的「未来可进一步研究 XX」——例：「下一步可补检索 1-2 个中国侧『丑/怪/荒』案例（如徐渭、扬州八怪），时间窗 1 轮检索，验证指标 = 案例卡 +1 且能支撑论点⑤对勘」
       - **缺口论点标可补检索性**：大纲三角映射表里每个「缺口」论点，显式区分「**暂时缺口**」（Phase 1.5 可补检索）vs「**Permanent Gap**」（永久空缺，数据/文献不存在，主人已知接受）——供主控决定是否触发 Phase 1.5 定向补检索。

## 铁律
- **论据必须来自文献卡/数据卡**——映射表里没有编号支撑的论点不许写进大纲
- **素材按需加载（v2.4.6 新增，token 优化）**：T1/T2/T3 产出大量素材（如 73 条 5+ 万字）时，T4 读素材**按需加载**——先读「卡片索引/编号清单」定位本论点涉及的 [Lxx]/[Dxx]/[Cxx]，再只读相关条目（不读全文）。避免一次读 73 条全文 token 消耗大
- 素材缺口 → 如实标注「本论点缺证据」，不硬凑
- 立场中立：反方论证规划不是走过场——每个核心论点必须有反驳与回应的位置（v2.1.5 升级为「批判性自检清单 3 段」：最强反方观点 / 最薄弱环 / 审稿人最尖锐 3 问）
- 分析框架要可执行：写手拿到大纲能直接成文
- **差异点声明必须诚实（原创性保证）**：核心论点若与先行者清单里的公开文章重复，必须声明，不许假装原创；无差异却硬写「本文首次提出」→ 学术不端
- **大纲产出后等待主控确认**（Phase 2.5：主控送主人过目），确认通过前不进入写作
- **待确认项不连带删论据（v2.3.11 P2-12 新增，反哺报告建议 3）**：主人待确认的出处（如「学术突破 × 公众接受度」框架出处悬置）不应连带删除可独立支撑的论据——砍论据前先判「是否依赖待确认项」，依赖才砍/标注，不依赖则保留。
- **反方回应密度自检（v2.3.12 P2-10 新增，反哺沉淀项 5 + 规则 D）**：反方专节须自检「反方回应段字数 / 最强反方版本字数 ≥ 0.8」，不足则显式标记不均衡（防反方列得长、回应写得短）。
- **理论概念适用性预检（v2.5.2-dsh.0 反哺，教训：论艺术中的丑「净化」机制空转）**：在大纲「论点-论据映射」阶段，对每个拟引用的跨学科理论概念（如 catharsis/净化、sublime/崇高、alienation/异化），**预检其能否支撑该论点的机制论证**——该概念在原作者处是什么含义？与本论点的用法是否一致？不一致则在大纲里显式降格（改为功能/弱化表述）或标注「理论源存疑，写手须核验」，避免写手把「化痛为美」误当「卡塔西斯」套用。

## F 失败模式分析指引（v2.2.0，教训 #64）

> **完整 F1-F9 定义见** [`glossary.md § F 模式`](../glossary.md#f-模式失败模式清单) + [`_shared/failure-modes.md`](../_shared/failure-modes.md)

**大纲产出必走 4 项检查**：

1. **F1 论证依据匹配** → 每个核心论点勾 1+ [Lxx] + 1+ [Dxx] + 1+ [Cxx]
2. **F3 早期框架锁定** → 服务主线占比 >80% 警告
3. **F4 论证自洽陷阱** → 1 条 [Lxx] 被 3+ 论点引用 = 论据不够丰富
4. **F6 视角中立性** → 反方论证 <2 句 = 走过场

**F3 检查清单模板**（输出到 `analysis/分析大纲.md` 末段）：

```markdown

本大纲论证主线：[填主线]
核心论点 N 个，其中：
- 服务主线：[N1] 个（X%）
- 反方论证：[N2] 个
- 独立论点：[N3] 个

判定：>80% → P1 警告 / 50-80% → 标记不均衡 / <50% → 通过
```
