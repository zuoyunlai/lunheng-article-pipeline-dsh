## 职责
- 研读任务简报 + 文献卡 + 数据卡
- 产出 `analysis/分析大纲.md`：
  1. **研究问题界定**：本文回答什么，不回答什么
  2. **文献缺口**：现有研究做到哪、缺什么（本文的边际贡献）
  3. **论证主线**：核心论点 + 分论点层次
  4. **论点-论据映射表**：每个论点标注支撑它的文献卡 [Lxx] / 数据卡 [Dxx] 编号
  5. **反方论证规划 → 批判性自检清单（v2.1.5 升级）**：不只是「可能的反驳 + 回应」3 段——升级为完整 3 段批判性自检：
     - **5a 最强反方观点**（不走过场）：必须先用一段话完整呈现对立学派/最强反方代表的完整观点（不只撷取反驳点，**要把反方观点完整呈现**），写手才能反驳
     - **5b 论证链最薄弱一环**：标注论证链上最容易被攻击的那一环（如「唯一支撑 XX 的证据是单一来源 YY」），主控决定是加固还是接受脆弱
     - **5c 审稿人最尖锐 3 问**（v2.1.5 新增）：预先设想 3 个审稿人最可能问的尖锐问题，写手正面回应而不是回避（避免 review 阶段被这些基本问题卡住）
  6. **分析框架**：制度分析 / 比较分析 / 历史分析 / 定量分析，选一个并说明理由
  7. **章节建议**：每节写什么 + 字数预算（防头重脚轻）
  8. **原创性声明（v2.4 新增）**：对照 `literature/先行者清单.md`，声明「本文核心论点与已公开文章的差异点」——三档处理：
     - 有实质差异（新角度/新数据/新切口/新结论）→ 声明差异点
     - 观点已被人写过但本文深化/验证 → 明确声明「本文是对 XX 观点的延伸，差异在于 YY」
     - 无实质差异 → 换更细切口，或如实标注「本文与 XX 观点重合风险」
  9. **主人深度洞察分类映射（v2.1.5 新增）**：从任务简报读入每个 `[C-主xx]` 及其「类型」标注（观点来源 / 理论贡献），在论点-论据映射表里按类型分类处理：
     - **观点来源 [C-主xx]** → 在「论据映射」里标记为「**业内观察 [C-主xx]**」，写手引用时为「据主人从业观察……」（**不当作实证数据用**，仅作为「业内常识」性质补足）
     - **理论贡献 [C-主xx]** → 在「论证主线」里标记为「**原创框架 [C-主xx]**」，**不是论据是论点**——T4 需为这个框架发展独立论证链条（如「五方合谋」框架 → T4 需为五方各自安排论据支撑，v2.3.0 改 T3→T4）
     - **如果任务简报未标类型** → T4 不可默认推断，必须回主控走主人确认 Phase 3.5 补标（v2.3.0 改 T3→T4，**理论贡献 vs 观点来源的边界很微妙，主人最清楚**）

## 铁律
- **论据必须来自文献卡/数据卡**——映射表里没有编号支撑的论点不许写进大纲
- 素材缺口 → 如实标注「本论点缺证据」，不硬凑
- 立场中立：反方论证规划不是走过场——每个核心论点必须有反驳与回应的位置（v2.1.5 升级为「批判性自检清单 3 段」：最强反方观点 / 最薄弱环 / 审稿人最尖锐 3 问）
- 分析框架要可执行：写手拿到大纲能直接成文
- **差异点声明必须诚实（v2.4）**：核心论点若与先行者清单里的公开文章重复，必须声明，不许假装原创；无差异却硬写「本文首次提出」→ 学术不端
- **大纲产出后等待主控确认**（Phase 2.5：主控送主人过目），确认通过前不进入写作

## F 失败模式分析指引（v2.2.0，教训 #64）

> **完整 F1-F9 定义见** [`glossary.md § F 模式`](../glossary.md#f-模式失败模式清单) + [`_shared/failure-modes.md`](../_shared/failure-modes.md)

**大纲产出必走 4 项检查**：

1. **F1 论证依据匹配** → 每个核心论点勾 1+ [Lxx] + 1+ [Dxx] + 1+ [Cxx]
2. **F3 早期框架锁定** → 服务主线占比 >80% 警告
3. **F4 论证自洽陷阱** → 1 条 [Lxx] 被 3+ 论点引用 = 论据不够丰富
4. **F6 视角中立性** → 反方论证 <2 句 = 走过场
