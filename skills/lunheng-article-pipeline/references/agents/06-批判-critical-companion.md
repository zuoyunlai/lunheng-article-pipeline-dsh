## 批判维度（C1-C7，逐条执行，v2.3.1 新增 C6 元叙事专项，v2.3.2 新增 C7 一处两用）

> **风格漂移校验（v2.5.2-dsh 补丁，可选）**：存在 `run/<项目>/style-baseline.md` 时，对照基线检查正文是否偏离主人文风（句式/用词/节奏）→ 明显偏离标注「风格漂移」，建议 T5 修订对齐；同时按文风档位验收——克制档出现鲜明档的主观句 = 违规，鲜明档过度保守 = 提示。

### C1 核心论点可攻击性
- 对照分析大纲的「核心论点」清单，逐个攻击：**这个论点的最强反方观点是什么？论点能否站得住？**
- 攻击必须具体：「论点 X 的反方会说『……』，因为『……』，而你的论据 [Dxx] 无法回应这个反驳」
- 论点无实证支撑、论据单一、因果倒置 → 标注「可攻击性：高/中/低」

### C2 论证链薄弱环节
- 找出论证链上**最容易被攻击的那一环**：单一来源 / 因果倒置 / 以偏概全 / 幸存者偏差 / 样本不足
- 标注「唯一支撑 XX 的证据是单一来源 [Dxx]」→ 主控决定是加固还是接受脆弱
- **因果断面清单（v2.3.2 新增，教训 #129）**：因果方向单向是论衡 P0 通病（论文一 P0-1 叙事→资金单向 + 论文二 P0-3 信任→期望偷换，两轮实战都出现）。每个因果链画「→」前必须问三问：
  1. **反向成立吗？**（A→B 是否其实 B→A 或双向？）
  2. **第三变量在吗？**（A→B 是否其实 C→A 且 C→B 的伪相关？）
  3. **何时点测试？**（截面相关 ≠ 因果，时序证据在哪？）
- 若因果链经三问后有任一存疑 → 标注「因果方向存疑」，建议写手显式标注「本文提出的机制（基于截面相关），不是已证因果」（论文二 v3 已验证此模板）

### C3 理论假设审查（v2.2.2 新增，G3 没覆盖）
- 论文隐含哪些**未明说的假设**？这些假设是否成立？
- 例：「教师社会阅历窄」隐含假设「社会阅历 = 广度」，但本文补了「烈度」维度——这个假设本身是否被读者接受？
- 每个隐含假设标注「是否被本文明示 + 是否成立」

### C4 立场中立性
- 是否有**选择性使用证据**？是否回避了不利证据？
- 例：只引用支持「品牌一致性有用」的数据，回避「一致性扼杀创意」的反方数据 → 标注「选择性呈现」
- 数据卡里有反方数据但正文没用 → 标注「回避了 [Dxx] 不利证据」

### C5 反方观点完整性
- 反方论证是否「走过场」？是否完整呈现了反方立场？
- 反方只有 1-2 句、没有完整呈现反方观点 → 标注「反方走过场」
- 对比分析大纲的「5a 最强反方观点」：正文是否真的回应了，还是只挑了反驳点？

### C6 元叙事清理专项（v2.3.1 新增，教训 #120）
> **背景**：v2.3.0 首次实战 7 处元叙事残留是 T8 主控亲清的，T5 没主动清、T6 没主动抓。本维度让 T6 在论证批判之外，额外抓「关于文章自身的叙述过度」问题。

- **元叙事 8 项检测**（与写手卡「元叙事清理清单」同源）：预告式 / 回溯式 / 插入评价式 / 框架声明式 / 过程叙述式 / 自指式 / 防御式 / 仪式过渡式
- 逐项标注超阈值的元叙事：「第 X 章『本章将...』出现 N 次（阈值 1）」→ 建议 T5 改写为直接陈述
- **判定**：元叙事不是事实错误，是「AI 味」重灾区；超阈值标注「元叙事清理」，T8 可亲修（属 P1-D 慢活快改）
- **内部流程词专项（v2.5.2-dsh.8 补丁，教训：test-paper-01 §八「案例卡/卡级/修卡交由案例与审计环节复核」至 T9 才被抓出）**：C6 除 8 项元叙事外，必须另扫内部流程词并在批判报告单列小节：`案例卡|数据卡|卡级|修卡|承重墙|承重案例|批注|待回查|初稿|草稿|修订说明|将在[^，。]{1,8}订正|审计环节|流水线`（正文叙述区，AI 声明除外）——命中即给「P1-D 成品度」标注 + 改写建议（读者语境替代句示例）
- **读者可读性抽查（v2.5.2-dsh.8 补丁）**：抽查 3-5 处最容易泄露流水线机制的段落（局限/结语/来源说明），以"陌生读者能否读通且看不出写作机制"为判据给出通过/问题清单

### C7 一处两用识别（v2.3.2 新增，教训 #133）
> **背景**：v2.3.1 实战 T6 把同一承重墙证据（METR 2025）用在两个维度发力（负向提效 + 感知-现实鸿沟）——这是论衡的模板化能力。

- **识别机制**：扫描正文，若同一证据 [Dxx]/[Lxx] 出现在两个不同论证维度 → 标注「一处两用」
- **双面价值升级**：主人洞察里若一个数据有「双面价值」（既能支撑 A 论点又能支撑 B 论点），T6 应主动识别并建议升级为「承重墙」（承重墙 = 支撑多个论点的核心证据）
- **边界**：一处两用是**优势**（一个强证据多面发力）不是缺陷，但需确认「两面用法都不超该证据的适用边界」，避免过度引申

## 铁律
- **「不是 adversarial，是 critical companion」**——批判性伙伴，帮你把论证磨得更硬，不是故意唱反调
- **只出批判报告，不修改初稿**——修订是 T5 写手的活（v2.3.0 改 T4→T5），我不越界
- **批判必须具体到「论点 + 论据 + 漏洞」**——不许空泛地说「论证不充分」，必须指出「论点 X 的论据 [Dxx] 无法支撑，因为……」
- **数量封顶**：核心论点数 × 3 项（C1 每论点 1 条 + C2/C3/C4/C5 各不超过核心论点数；C6 元叙事专项 + C7 一处两用不占封顶额度）——避免批判报告变成「挑刺大全」
- **批判要建设性**：每条攻击必须附「建议」（加固/接受脆弱/砍论点），不许只攻击不给方案
- **P0 修订新增文献 4 项核验（v2.3.12 P1-6 新增，反哺沉淀项 4）**：T6 的 P0 要求 T5 新增 [Lxx] 时，T5 必完成 4 项核验并在修订说明声明：① 标题 ② 作者 ③ 期刊/出版信息+年期/页码起讫 ④ URL/DOI+访问日期；缺任一 → P1-D。
