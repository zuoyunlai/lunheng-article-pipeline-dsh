# G14 中文 AI 痕迹深度检测闸（v2.4.0 新增）

> **版本**：v2.5.1（2026-08-24）
> **性质**：闸门（Gate），机械化 + LLM 推理双驱动
> **触发阶段**：Phase 4.5（终稿前 + T6 批判伙伴同步跑）
> **失败后果**：命中 ≥3 类触发 T5 回环（≤2 轮），第 2 轮仍命中 → 报告主人

## 一、设计哲学

论衡从 v2.3.13 的「AI 使用披露」（透明）+「G13 AI 使用披露」（审计）演进到 v2.4.0 的「G14 中文 AI 痕迹深度检测」——**不是检测器（GPTZero 类），是论衡自己的「中文学术话语风格指南」+ 检测算法**。

**核心承诺**：
- **风格净化，非隐瞒**：G14 的目标是「去 AI 腔 + 提升中文学术话语可读性 + 贴近主人个人风格」，**不是「让 AI 痕迹不被检测到」**——G13 AI 使用披露照常在交付说明声明「本文由 AI 辅助生成」，**不隐瞒 AI 身份**
- **诚实透明**：G13 AI 使用披露照常在交付说明声明（不试图隐瞒 AI 痕迹）；G14 与 G13 互补不重叠（前者声明 + 后者净化）
- **中文特化**：所有检测维度针对**中文学术话语**，不是英文模式直接套用
- **可关闭**：主人可在 Phase 0 选择「关闭 G14」（不强制）

## 二、检测维度（8 类）

| 类别 | 检测点 | 阈值 | 借鉴来源 |
|------|-------|-----|---------|
| **G14-A 学术模板语** | 「综上所述/笔者认为/本文认为/值得关注的是/不容忽视/在新时代背景下/具有重要的理论与现实意义」 | 任一模板出现 ≥3 次 | chinese-writing 7.4 |
| **G14-B 句式同质化** | 连续 3 段同句式起头（如「首先...其次...最后...」「不仅...而且...」） | 同模板 ≥2 次连续段 | 论衡自有 |
| **G14-C 学术套话高频** | 「赋能/抓手/底层逻辑/范式/迭代/路径」每段 ≥1 次 | 全文 ≥5 处 | humanizer-zh |
| **G14-D 破折号滥用** | 每段破折号 ≥2 处，或破折号总字数占比 >3% | 全文 ≥5 段 | humanizer-zh |
| **G14-E 三项排比** | 全文 ≥3 处「A/B/C」式排比 | 全文 ≥3 处 | humanizer-zh |
| **G14-F 人称错位** | 学术论文滥用第一人称「我」超过全文1% | 「我」字频 > 1% | 论衡自有（中文规范）|
| **G14-G 个人辨识度缺失** | LLM 判定：本文与10 篇同主题论文风格相似度 >80% | LLM 自评判定 | 论衡自有 |
| **G14-H 党报话语堆砌** | 政治学科特化：「重要讲话精神/重要指示/根本遵循」过多 | 全文 ≥3 处 | 论衡自有 |

## 三、判定规则

**单条命中**：每类单独计算，每类内部阈值独立判定。

**整体判定**：
- 命中 0-2 类 → ✅ Pass（轻微 AI 味，可接受）
- 命中 3-4 类 → ⚠️ Warning（触发 T5 回环，1 轮修订）
- 命中 5+ 类 → ❌ Fail（触发 T5 回环，2 轮强制修订；第 2 轮仍不通过 → 报告主人手工润色）

**例外豁免**（主人可在 Phase 0 关闭）：
- 「本文认为」/「笔者认为」等学术模板语在**引言/结论**段可豁免（学术规范要求）
- 破折号在**正文叙述**段豁免（仅检查论点段）

```
Phase 4.5 终稿前
  ↓
T0 主控并行调用 T6 批判伙伴 + G14 checker
  ↓
G14 checker 输出 8 类判定结果
  ↓
┌─────────────────────────────────────┐
│ 命中 0-2 类 → ✅ Pass │
│ → status.md 标「G14 ✅」 │
│ → 继续 Phase 5 │
└─────────────────────────────────────┘
  ↓ 否则
┌─────────────────────────────────────┐
│ 命中 3-4 类 → ⚠️ Warning │
│ → status.md 标「G14 ⚠️ 触发 T5 修订」│
│ → spawn T5 写手修订（计入修订回环 ≤2 轮）│
│ → T5 出 v(N+1) + G14 检测报告（修订版）│
└─────────────────────────────────────┘
  ↓ 否则
┌─────────────────────────────────────┐
│ 命中 5+ 类 → ❌ Fail │
│ → status.md 标「G14 ❌」│
│ → spawn T5 写手修订（计入修订回环 ≤2 轮）│
│ → 第 2 轮仍命中 → 报告主人「论衡修订能力上限」│
│ → 主人决定：接受交付 / 手工润色 / 重走流水线 │
└─────────────────────────────────────┘
```
