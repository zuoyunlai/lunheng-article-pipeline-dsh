## 一、设计哲学

论衡的「G14 中文 AI 痕迹深度检测」——**不是检测器（GPTZero 类），是论衡自己的「中文学术话语风格指南」+ 检测算法**。

**核心承诺**：
- **风格净化，非隐瞒**：G14 的目标是「去 AI 腔 + 提升中文学术话语可读性 + 贴近主人个人风格」，**不是「让 AI 痕迹不被检测到」**——G13 AI 使用披露照常在交付说明声明「本文由 AI 辅助生成」，**不隐瞒 AI 身份**
- **诚实透明**：G13 AI 使用披露照常在交付说明声明（不试图隐瞒 AI 痕迹）；G14 与 G13 互补不重叠（前者声明 + 后者净化）
- **中文特化**：所有检测维度针对**中文学术话语**，不是英文模式直接套用
- **可关闭**：主人可在 Phase 0 选择「关闭 G14」（不强制）

## 三、判定规则

**单条命中**：每类单独计算，每类内部阈值独立判定。

**整体判定**：
- 命中 0-2 类 → ✅ Pass（轻微 AI 味，可接受）→ **冻结一份正文（尚不是 `final/`）**
- 命中 3-4 类 → ⚠️ Warning（走 **G 环**，**1 轮**修订，**不占 B 轨额度**）
- 命中 5+ 类 → ❌ Fail（走 **G 环**，**2 轮**修订；第 2 轮仍不通过 → 报告主人手工润色，**不得以 Acknowledged Limitations 放行**）
- **G 环收敛条件 = 改完重跑本闸至 Pass**（唯一一次 spawn 的额度**随重跑重置**——闸门不过即不交付，故它不与该闸自己的轮数上限冲突）

**例外豁免**（主人可在 Phase 0 关闭）：
- 「本文认为」/「笔者认为」等学术模板语在**引言/结论**段可豁免（学术规范要求）
- 破折号在**正文叙述**段豁免（仅检查论点段）

### D 类判定口径（全库唯一口径）

**唯一口径（单一判据，无歧义）**：

```
破折号      = 连续两个 U+2014（即「——」）；单个 U+2014 不计
占比分母    = 全文汉字数（口径 = scripts/_lib/han.mjs 的 countHan，U+4E00–9FFF，与 count-chars 同源）
占比分子    = 破折号个数 × 2（每个破折号占 2 个字符位）
命中 ⟺ 分子 / 分母 > 3%
```

### B 类判定口径（全库唯一口径，v18.62.7 新增）

**为什么要有这一节**：B 类此前**只有检测点 + 阈值两格**，而两格互相矛盾（见 §二 表下注）；更严重的是
本闸自己的处方式补救 `R1` 的机械验收写成「≤2 上限」，与「≥2 即命中」对立——**照处方改完仍红**。
下列三条是与 `R1` **同源**的常量，改任一条必须同时改 `R1` 的验收写法。

```
「同模板」判据（唯一）  = 相邻段的段首 **前 6 个汉字内的实词骨架**相同
                          （去掉虚词/标点/编号后逐字相同，或同为同一枚举模板：首先/其次/最后、第一/第二/第三、
                            不仅…而且…、从…到…）；样例：连续段首「第一线…」「第二线…」「第三线…」= 同模板
命中 ⟺ 同一模板**连续 ≥3 段**（= 允许 ≤2 段，与 R1 的验收上限「≤2」同源）
单段复现不算命中；非连续的复现不算命中（那是「重复用词」，归 C 类）
判定步：① 取每段首 6 字 → ② 骨架归一 → ③ 找最长连续同骨架游程 → ④ 游程 ≥3 即命中（记行号 + 模板）
```

### C 类判定口径（v18.62.7 新增：自建构念术语的豁免）

**为什么要有**：C 类词表以**通用商业语料**校准；而实测项目里「**路径**」39 处是本文四条重构路径的
**构念术语**（学理必需的名词复现），却被计入套话（占 C 类命中 43 处的绝大部分）。检测器**不得自行豁免**
（见 `../checkers/中文AI痕迹-checker.md` §C），但「**不许自行豁免**」不该等于「**机制上不存在合法豁免**」。

**两条豁免通道（都必须逐处留痕）**：

1. **T4 声明的构念术语表**（唯一机读形态）：`analysis/分析大纲.md` 或 `01-任务简报.md` 里一行
   `CONCEPT-TERMS: 路径 | 裁定源 | 三节点`
   （与 M-Form-8 的 `ACCEPTED-GAPS:` 同族的**机读声明**形态；竖线分隔，逐词一句理由）。
   命中该表的词**整体豁免**，报告须列出「词 × 出现处数 × 声明来源」。
2. **同一概念义位的复现**：同一术语在全文承担**同一个概念义位**（如「路径」一律指「重构路径」而非
   「方法/捷径」）时，复现不计套话；**义位漂移**（同词在别处用作通用套话）仍逐处计入。

**边界（如实）**：① 两条豁免都**不改变阈值**（仍是全文 ≥5 处，只是分子口径变清楚）；② 无声明、
义位也不确定时**按现行边界逐处计入并列出**（宁可多报，由主控裁定）；③ 本闸**不新建**
`run/<项目>/g14-terms-whitelist.md`——豁免走声明通道，避免第三个配置面引入新的口径冲突。

### E 类判定口径（v18.62.7 新增：论证体例不计）

**为什么要有**：E 类「全文 ≥3 处三项排比」对**万字论说文近乎恒真**——实测 7 处里 5 处是**论证体例**
（承重论点的排序陈述、局限条目枚举、方法步骤枚举），而**改写无法降计数**（要降就得拆论证骨架 =
内容降级）。这与**已废止**的 D 类旧口径同型（正是因「近乎恒真」才被换成占比判据）。

**唯一口径**：

```
计入（= AI 味候选）：非论证位置的修辞性排比——过渡/铺陈/总结句里的「A、B、C」三连，
                    且三者的语义角色相同（都为形容词/都为口号式短语）
不计入（= 论证体例）：① 承重论点的排序/分支陈述（「第一…第二…第三…」的论证推进）；
                    ② 局限、条件、条目、参数、步骤的**枚举**；
                    ③ 引文标题、术语三分（如「主体—媒介—接受」）等**学理必需**的三元结构
命中 ⟺ **计入项** ≥3 处（报告须逐处给出「行号 + 位置 + 计入/不计入 + 一句理由」）
```

> **判据（本报告 §A17 的原话）**：**机制假阳性的裁定应与「是否影响判级」解耦**——本次实测主控
> **拒不为过门而裁定**（命中 2 类已 Pass，裁它等于「为过门而改」），只登记为反哺候选。这一处理方式
> 本身即规范：**门的义务是把话说清楚，不是必须把档位刷绿**（同 §四「配额耗尽时的降级路径」判据）。

### ⚠️ G 环额度用尽时的处置（v18.75.0 改写自 F-AT；机制根因已解除，**但「不为过门而改」的判据保留**）

**v18.75.0 的机制修正（如实登记改写来源）**：本节原题「配额耗尽时的降级路径」，记的是 **F-AT 实测的机制时序缺口**——旧文把本闸的触发轮记在 **B 轨**（「B 轨主控触发轮」），而 B 轨的真源是 [`../glossary.md`](../glossary.md) 的「**至多 +1 深化轮**（全周期累计）」、`pipeline-readme.md` 明写「**B 轨累计已达 1 → 不再开**」，且旧文的 B 轨判定时点在 **Phase 4.5 之前**。而本闸的 Warning **产生于终闸时点** → **额度在先、告警在后**：B 轨配额若已用掉（T6 批判 / 主人洞察任一触发过深化轮），**本闸的 Warning 便无轮可开**（QLT-5 实测命中率 **2/4 项目**）。

**现机制（v18.75.0，主人 2026-10-04 裁定）**：本闸的修订走 **G 环**——**与 A 轨 / B 轨并列的第三条环**，额度独立（**3-4 类 → 1 轮；5+ 类 → 2 轮**），**不占 B 轨至多 +1**，故「额度在先、告警在后」这一类**不再成立**。

**但换了一处兜底（与原判据同源）**：**G 环 2 轮用尽而仍判 Fail** 时——

1. **如实判定「中不中」**：逐类列出命中项（**含行号**），并**逐项回答「这一处能不能在不损伤术语精度/论证结构的前提下改掉」**；
2. **能改但会损伤论证/术语** → **不得为过门而改**。判据：**术语精度 / 论证结构 > 门口径达标**（QLT-5 实测：为降 C 类计数而替换核心机制术语属于**损害**，写手应**如实报告「未达成降门目标」**）；
3. **报告主人手工润色**（**不得以 Acknowledged Limitations 放行**——闸门不过即不交付，见 §触发阶段「失败后果」）；主人若选择接受现状，须走 `AGENTS.md` §机制文件写保护 的**主人授权例外**（**辨名 → 记例外 → 读数冻结 + 投递读数并列**，见 [`../maintainers.md`](../maintainers.md)）；
4. **结论表不得引用本闸档位作为交付质量证据**——须写明「本闸档位在跨臂/跨项目间**不可比**」（豁免口径分歧见反哺 F-AS），**QLT-1 等分数亦不得用来支撑"论证质量"结论**（见反哺 **F-BC**）。

> **判据（保留原话）**：**门的义务是"把话说清楚"，不是"必须把档位刷绿"。** 无轮可开时，正确产出是**一条可核查的已披露风险**，而不是一个被改写掉的词。

**报告必含字段**：

- 详细命中位置（章节 + 段落 + 行号）

  > **判据（可迁移）**：**报告的建议与报告的判据互斥时，以判据为准；建议须先通过其自身判据的自检。**
