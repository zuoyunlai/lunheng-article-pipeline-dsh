## 一、设计哲学

论衡从 v2.3.13 的「AI 使用披露」（透明）+「G13 AI 使用披露」（审计）演进到 v2.4.0 的「G14 中文 AI 痕迹深度检测」——**不是检测器（GPTZero 类），是论衡自己的「中文学术话语风格指南」+ 检测算法**。

**核心承诺**：
- **风格净化，非隐瞒**：G14 的目标是「去 AI 腔 + 提升中文学术话语可读性 + 贴近主人个人风格」，**不是「让 AI 痕迹不被检测到」**——G13 AI 使用披露照常在交付说明声明「本文由 AI 辅助生成」，**不隐瞒 AI 身份**
- **诚实透明**：G13 AI 使用披露照常在交付说明声明（不试图隐瞒 AI 痕迹）；G14 与 G13 互补不重叠（前者声明 + 后者净化）
- **中文特化**：所有检测维度针对**中文学术话语**，不是英文模式直接套用
- **可关闭**：主人可在 Phase 0 选择「关闭 G14」（不强制）

## 二、检测维度（8 类）

| 类别 | 检测点 | 阈值 | 借鉴来源 |
|------|-------|-----|---------|
| **G14-A 学术模板语** | 「综上所述/笔者认为/本文认为/值得关注的是/不容忽视/在新时代背景下/具有重要的理论与现实意义」 | 任一模板出现 ≥3 次 | chinese-writing 7.4 |
| **G14-B 句式同质化** | 连续 3 段同句式起头（如「首先...其次...最后...」「不仅...而且...」） | 同模板 ≥2 次连续段 | 论衡自有 |
| **G14-C 学术套话高频** | 「赋能/抓手/底层逻辑/范式/迭代/路径」每段 ≥1 次 | 全文 ≥5 处 | humanizer-zh |
| **G14-D 破折号滥用** | **占比 > 3%**（单一判据，口径见 §三「D 类判定口径」） | 占比 > 3% | humanizer-zh |
| **G14-E 三项排比** | 全文 ≥3 处「A/B/C」式排比 | 全文 ≥3 处 | humanizer-zh |
| **G14-F 人称错位** | 学术论文滥用第一人称「我」超过全文1% | 「我」字频 > 1% | 论衡自有（中文规范）|
| **G14-G 个人辨识度缺失** | LLM 判定：本文与10 篇同主题论文风格相似度 >80% | LLM 自评判定 | 论衡自有 |
| **G14-H 党报话语堆砌** | 政治学科特化：「重要讲话精神/重要指示/根本遵循」过多 | 全文 ≥3 处 | 论衡自有 |

## 三、判定规则

**单条命中**：每类单独计算，每类内部阈值独立判定。

**整体判定**：
- 命中 0-2 类 → ✅ Pass（轻微 AI 味，可接受）
- 命中 3-4 类 → ⚠️ Warning（触发 T5 回环，1 轮修订）
- 命中 5+ 类 → ❌ Fail（触发 T5 回环，2 轮强制修订；第 2 轮仍不通过 → 报告主人手工润色）

**例外豁免**（主人可在 Phase 0 关闭）：
- 「本文认为」/「笔者认为」等学术模板语在**引言/结论**段可豁免（学术规范要求）
- 破折号在**正文叙述**段豁免（仅检查论点段）

### D 类判定口径（v18.2.7 收敛，全库唯一口径）

> **背景（2026-09-20 全流程实战反哺）**：修订前 D 类有 **3 条并列判据**（`checkers/中文AI痕迹-checker.md` §D 明写「满足任一 → 命中」）：
> ① 全文破折号总数 > 8 处；② 每段 ≥2 处的 ≥5 段；③ 占比 > 3%。
> **① 与 ② 对长文档恒真**——实测项目（16,805 汉字论文）破折号 **183–200 处**、含 ≥2 处的段 **52 段**，
> 两条件**无条件满足** → D 类成为**必然命中项**：恒占 8 类分母中的 1 类，无判别力，
> 且使「0-2 类 Pass」的余量被无谓压缩 1/3。同时四份文档（本文件 / checker / `SKILL.md` 派发话术 / `pipeline-readme.md`）
> 对 D 类的措辞各不相同 → **在旧的双闸设计下**，两次运行（早闸 / 终闸）对**同一指标更高**的文本给出**相反判定**（实测量 183 处判 HIT、200 处判 0 命中）。

**唯一口径（单一判据，无歧义）**：

```
破折号      = 连续两个 U+2014（即「——」）；单个 U+2014 不计
占比分母    = 全文汉字数（口径 = scripts/_lib/han.mjs 的 countHan，U+4E00–9FFF，与 count-chars 同源）
占比分子    = 破折号个数 × 2（每个破折号占 2 个字符位）
命中 ⟺ 分子 / 分母 > 3%
```

**为何去掉「每段 ≥2 处的段数」与「总数 > 8 处」**：二者对任何万字号中文论文恒真（见上「背景」），
不构成判别信息；保留它们只会让 D 类变成恒命中项。**占比 >3%** 是唯一具备判别力的判据——
实测本项目 183 处 / 18,349 汉字 = **2.0%**（未达 3%）→ D 类**不命中**，与「0/8 类」的终闸结论一致。

**与旧口径的可比性**：本项为**收紧**（旧口径下 D 类恒命中，新口径下需真超 3% 才命中），
故历史项目的「D 类命中」记录**不可直接与新口径比较**；重跑旧稿会得到更宽松的结果。

## 四、触发流程（v18.2.8：三层防御、仅一次 spawn）

```
【第 1 层】T5 v1 自检（写作时，零 spawn）
  T5 写手产出 drafts/初稿-v1.md 时，自跑 8 类扫描
    ↓
  结论写入 drafts/修订说明-v1.md 的「G14 v1 自检」段（不写独立报告、不 spawn）
    ↓
  命中 → T5 当场修（措辞层问题在写作阶段修成本最低）


【第 2 层】修订轮收尾自查（v18.2.5 已有，零 spawn）
  每一轮 T5 修订（v2/v3/v4…）落盘后
    ↓
  主控对**新增/修改段落**做轻量 8 类扫描（grep 破折号 / C 类套话表 / 排比形态 / 连续段同句式）
    ↓
  命中 → 当轮修掉；结论记入 drafts/修订说明-v{N}.md 的「G14 修订轮自查」段
  > 为什么必须有这一层：修订段是**新的 AI 痕迹注入点**——实测破折号轨迹
  > 26 → 8（v2 净化）→ 11（v3/v4 因回应 T6 批判与 T7 打回而**反弹**）→ 6（v5）


【第 3 层】终闸（Phase 4.5，唯一一次 spawn，与 T9 同行评审并行）
  T0 主控 spawn G14 checker 审**最终版**
    ↓
  audits/G14-检测报告-v{N}.md（最终版本真源；N = 被审正文轮次）
    ↓
┌─────────────────────────────────────┐
│ 命中 0-2 类 → ✅ Pass │
│ → status.md 标「G14 ✅」 │
│ → 继续 Phase 5 │
└─────────────────────────────────────┘
  ↓ 否则
┌─────────────────────────────────────┐
│ 命中 3-4 类 → ⚠️ Warning │
│ → status.md 标「G14 ⚠️ 触发 T5 修订」│
│ → spawn T5 写手修订（**B 轨主控触发轮**，不计入 A 轨 ≤2 轮）│
│ → 修订采**等量置换**；必要时可临时突破字数软档 ±2%（质量项优先）│
└─────────────────────────────────────┘
  ↓ 否则
┌─────────────────────────────────────┐
│ 命中 5+ 类 → ❌ Fail │
│ → status.md 标「G14 ❌」│
│ → spawn T5 写手修订；仍不通过 → 报告主人「论衡修订能力上限」│
│ → 主人决定：接受交付 / 手工润色 / 重走流水线 │
└─────────────────────────────────────┘
```
