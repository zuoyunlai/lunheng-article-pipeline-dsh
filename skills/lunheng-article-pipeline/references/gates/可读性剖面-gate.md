## 一、这一闸管什么

**文风是否走形**（不碰正确性）。它**不是**新的交付硬门，而是**度量链上的一维**：

| 项 | 值 |
|---|---|
| 检测器 | [`checkers/可读性-checker.md`](../checkers/可读性-checker.md)（四个分布式指标的完整口径与边界） |
| 实现 | `scripts/_lib/readability.mjs`（`profile()` 出四值 / `evaluate()` 按标定阈值判档） |
| **消费者** | `scripts/quality-score.mjs` 的**第 8 分量（权重 10）**——四指标原值写进评分 JSON 的 `evidence.metrics` |
| **最高严重度** | **P2**（软提示）。**永不判 P0/P1**——见下 §三 |
| 触发时机 | 与 `quality-score` 同频：**机制改动前后各跑一次**（`maintainers.md` §七 的固定动作），以及 T7/T8 需要判断「是否机械」时人工读取该分量 |
| 阈值真源 | `readability.mjs` 的 `THRESHOLDS` + checker 文档的标定表（**另三维 = 21 份真实定稿标定，2026-09-27；长句占比维 = v18.73.0 重测 27 份、23 份参与标定**） |

## 二、四个指标与取定界（一屏速查）

| 指标 | 取定界 | 命中含义 |
|---|---|---|
| 句长标准差 | **< 13**（真实稿最低 14.56） | 句式同质化——**机械感的最强信号** |
| >60 字长句占比 | **> 30%**（真实稿最高 27.6%） | 长句堆叠难读 |
| 每 300 汉字新术语数 | **> 50**（真实稿最高 44.4） | 术语密度异常 / 定义轰炸 |
| 被动句占比 | **> 22%**（真实稿最高 18.7%） | 翻译腔 / 官方腔 |

**标定原则**：界取「明显异常」上界（略高于真实稿极值），**不取中位数**——按中位数划线会把一半合格稿判为异常（同批 C-Redundancy 的核心教训）。
**实测**：原 21 份 + v18.73.0 重测 27 份（23 份参与标定）真实稿**全部在界内（0 误报）**；合成等长句文本标准差 0 必红、80 字句堆叠文本三项同撞必红。

## 三、为什么最高只到 P2（设计约束，不是保守）

G14 的**禁用式**链路（禁词/禁式）与这一闸的**分布式**链路，都在防同一件事的另一面：
**禁用式**防「写了不该写的」，**分布式**防「**为过门而写得机械**」。
若把可读性挂成硬失败（P0/P1），会**立刻制造出它想检测的那种激励**——写手会去凑标准差、拆长句、删被动句，
最终产出一种**为指标而写**的新机械文本。故：

- 判定**只到 P2**，且**不参与 `quality-score` 的扣分**（与其余分量的 P2 同口径：分数只反映硬失败）；
- **不做总分**——四值一起给，看剖面形状；单篇命中说明「这一维偏了」，不等于文章质量差；
- **句数 < 20 不判**（短稿的标准差与占比无统计意义）；
- **主要用途是趋势**：跨版本 / 跨项目的比对才是它的主场。
