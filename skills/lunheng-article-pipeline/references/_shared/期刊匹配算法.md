# 期刊匹配算法（v2.5.0 新增）

> **用途**：T9 同行评审后的「期刊匹配」算法。基于 T9 评分 + 主题关键词，从 [`期刊数据库.md`](期刊数据库.md) 中推荐 Top 3 期刊 + 匹配度。
> **触发**：Phase 0 学术论文模式 + 主人勾选「启用期刊匹配」才激活。

## 一、输入

| 输入 | 来源 | 说明 |
|------|------|------|
| **主题关键词** | 任务简报 §研究问题 + 关键词 | 论文主题（5-10 个关键词） |
| **文章类型** | 任务简报 §论文类型 | 学术论文 / 商业评论 / 公众号 |
| **6 维度评分** | T9 同行评审报告 | 原创性 / 方法论 / 证据强度 / 论证结构 / 写作质量 / 引文规范 |
| **总评分** | T9 同行评审报告 | 26-30 accept / 21-25 minor / 16-20 major / <16 reject |
| **语言** | 任务简报 §语言 | 中文 / 英文 / 双语 |

## 二、算法（LLM 推理模拟，零 exec）

### 步骤 1：语言匹配
- 中文 → 中文期刊数据库（25 个）
- 英文 → 英文期刊数据库（12 个）
- 双语 → 两个数据库各取 Top 3

### 步骤 2：类别匹配
- 根据主题关键词匹配期刊类别
- 例：「家具设计」→ 设计学类（装饰、家具与室内装饰）
- 例：「组织行为」→ 管理学类（管理世界、南开管理评论）

### 步骤 3：主题契合度评分（每刊 0-100%，可复现细则）
- 主题关键词与「主题偏好」字段的**逐词命中率**：命中数 ÷ 关键词总数 × 100%，再按类别是否一致 ±10% 微调
- 例：「实证研究 + 产业政策」→ 中国工业经济 90%

### 步骤 4：风格匹配度评分（每刊 0-100%，可复现细则）
- 「风格偏好」字段与文章方法风格（实证/理论/案例/综述）逐项对照：完全一致 100% / 部分一致 60% / 不一致 20%
- T9 评分作置信加权：minor 及以上（≥21）保持；major 及以下（<21）整体 ×0.8（文章尚未成熟，匹配可信度下调）
- 例：T9 = 25/30（minor revision）+ 实证风格 → 实证类期刊 80%

### 步骤 5：综合匹配度
```
综合匹配度 = 0.5 × 主题契合度 + 0.3 × 风格匹配度 + 0.2 × 总评分归一化
```
- 总评分归一化 = (T9 评分 - 16) / (30 - 16)

### 步骤 6：输出 Top 3
- 按综合匹配度降序
- 输出 Top 3（含期刊名 / 综合匹配度 / 主题契合 / 风格契合 / 审稿周期）

## 三、输出格式

| 目标方向 | 综合匹配度 | 主题契合 | 风格契合 | 审稿周期 | 推荐理由 |
|---------|-----------|---------|---------|---------|---------|
| 《期刊 1》 | 90% | 95% | 85% | 4-8 月 | <主题契合 + 风格契合 + 审稿周期> |
| 《期刊 2》 | 80% | 85% | 75% | 3-6 月 | ... |
| 《期刊 3》 | 70% | 75% | 70% | 6-12 月 | ... |

## 四、与 T9 评审的关系

- **T9 = 同行评审**（6 维度评分 + 投稿建议占位）
- **期刊匹配助手 v2.5.0 = T9 后处理**（基于 T9 评分 + 主题，匹配期刊数据库）
- 期刊匹配助手在 T9 评审通过后自动跑（默认关闭，需主人勾选）

## 五、限制

- **零 exec**：匹配算法由 LLM 推理完成，不实际跑外部推荐系统
- **数据库维护**：期刊数量和字段质量决定匹配准确性；主人按需扩展
- **不替代真审稿**：仅作投稿建议，最终投稿由主人决定
