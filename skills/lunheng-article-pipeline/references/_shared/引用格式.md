# 引用格式：GB/T 7714-2015 ⇄ APA 7th（正向生成契约）

> **状态**：v18.66.0 落地（主人 2026-10-03 指令：「A 档但先只做 GB/T ↔ APA，IEEE 暂缓」）。
> **生成器**：`scripts/cite-format.mjs`（只读式：默认只打印草稿；`--report` 才落一份 JSON）。
> **真源地位**：本文件是**著录模板与转换判据的唯一真源**；`01 卡` / `任务简报-template` / `05 卡` 引用格式口径时指向此处，不另抄模板。

## 零、边界（先读，防误期待）

1. **只做「字段 → 目标格式」的正向生成**，**不做「串 → 串」的智能重排**。
   为什么：后者必须先反向解析作者/刊名——正则猜作者与刊名会**静默改错**（本仓最反对的形态）。实测文献卡是字段结构化的（`- **作者**: Robert Nozick`），故正向拼装既可行又不猜。
2. **只出草稿**：产物是**参考文献节草稿**；粘贴、改名、核对由 T5（写作期）或 T8（`P1-D` 亲修）做。**生成器不改定稿正文**。
3. **不重排顺序**：输出顺序 = 文献卡顺序。GB/T 顺序编码制与 `M-Exist-1` 的双向闭环都依赖它；重排会同时破坏编号与闭环。
4. **不判级**：缺字段的判级归 `g-audit-check.mjs` 的 **`G15-VolIssue`**（候选 P2、模式相关）。本契约与生成器只**列清单**。
5. **补齐的字段不编造**：判不出就落 `⟨缺 …⟩` 占位（见 §四），并在清单里逐条点名。

## 一、著录模板（按类型；`类型` 栏的 `[X]` 标识是唯一类型真源）

| 类型 | GB/T 7714-2015 | APA 7th |
|---|---|---|
| 期刊 `[J]` | `作者. 题名[J]. 刊名, 年, 卷(期): 起-止页. DOI: … URL: …` | `作者. (年). 题名. *刊名*, 卷(期), 起-止页. https://doi.org/…` |
| 专著 `[M]` | `作者. 题名[M]. 出版地: 出版者, 年. ISBN: …. DOI: …` | `作者. (年). *书名*. 出版者. URL`（APA **只写出版者**，不写出版地） |
| 电子资源 `[EB/OL]` | `作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.` | `作者. (年). 题名. URL` |
| 学位论文 `[D]` | `作者. 题名[D]. 培养单位, 年.` | `作者. (年). *题名* [学位论文]. 培养单位.` |
| 报告 `[R]` | `作者. 题名[R]. 机构, 年.` | `作者. (年). *题名*. 机构.` |
| 报纸 `[N]` | `作者. 题名[N]. 报纸名, 年(版次).` | `作者. (年). 题名. *报纸名*.` |

**类型判不出 → 不生成该条**（进 `blocked` 清单，**绝不猜类型**）：猜类型会把 [M] 拼成 [J] 的卷期页形态，产出「看着像著录、其实是错著录」的最坏结果。

## 二、双标形态（**编号冲突的唯一解法**）

- **GB/T**：`[1] [L01] 作者. 题名[J]. …` —— **顺序号 + 论衡编号并列双标**（先例 = `deliverables.md:85`）。
- **APA**：`[L01] 作者. (年). …` —— APA 本身不用顺序号，但**论衡编号必须保留**。
- **为什么必须保留 `[Lxx]`**：`M-Exist-1` 的编号正则要求**字母前缀**；写成 `[1]`/`[2]` 会让文末字母编号集为空 → **正文全部引用被判漏引（P0）**。GB/T 7714 只约束**著录格式**，不约束**标签形态**（`机检硬格式.md` 同口径）。

## 三、作者名规则（APA 的唯一高风险面）

| 情形 | 处理 | 为什么 |
|---|---|---|
| 中文姓名（`王文军`） | **原样，不反转** | APA 中文变体不反转姓名；反转会产出 `军, 王文` 这类错名 |
| 英文 `Given Surname`（`Robert Nozick`） | → `Nozick, R.` | APA 的姓前置 + 名首字母 |
| **仅姓**（`Nozick`） | 原样，**不补首字母** | 首字母无从得知，编造即伪造著录 |
| 姓与**索引段**不符 | **不反转**，落注记请人工核 | 索引段是卡片内唯一的第二来源，它不认可就不动 |
| 作者栏带括注（`王文军（博士、教授）`） | 括注**不进著录串**，落注记 | 括注是卡片给读者看的，不是著录要素（实测：不摘括注会把「，」拆成假作者） |

## 四、缺字段与「占位值」（**本节是硬铁律**）

1. 字段缺失 → 落 `⟨缺 <字段名>⟩`，进 `placeholders` 清单，**该条仍生成**（让缺什么一眼可见）。
2. **「待核 / 待补 / 未知 / 不详 / 未检索到 / TBD / N/A」类占位值一律当缺字段处理**——不得原样进著录串。
   依据：本仓既有铁律「作者字段不允许『待核』占位」（`文献卡-template.md:110`，教训 #107）。实测卡片里确有 `期刊版本待核验`；若原样输出，等于把**未核验**当成**已著录**。
3. 该清单与 `G15-VolIssue` 的关系：**同一批缺口的两种视图**——本器按「目标格式能不能拼出来」列，`G15-VolIssue` 按「契约要件（DOI/卷期页/ISBN/URL+访问日期）在不在」列。**不互相替代**，也**都不设阈值**。
4. 是否「可判定」以**形态**为准：能确定性拆出的才拆（`出版地: 出版者` 取最后一个 `:` 之后为出版者、`Vol./No./pp.` 提卷期页），判不出就落占位。

## 五、IEEE：**暂缓（如实登记，不假装支持）**

- **现状**：本契约**没有 IEEE 模板**；生成器 `--style ieee` 会以 **exit 10** 明确拒绝（不静默降级到 GA/T 或 APA）。
- **为什么暂缓**：`SKILL.md:144` 的定位是**中文学术/深度长文**（GB/T 7714-2015 / Top 3 中文期刊）；IEEE 只在投稿场景出现，而按本仓纪律，支持一种格式 = **模板 + 类型映射 + 作者规则 + 成对测试**四件齐备，缺一即「文档写了、脚本没装」（本块的历史伤疤 = 幻影门 `M-Form-2 v2`，五处活引用、三层皆空）。
- **要支持时**：按 §一 表格补一行 + §二 编号形态（IEEE 用 `[1]` 数字制，仍须保留 `[Lxx]`）+ §三 作者规则（`D. Lazer`）+ 生成器一个 `case` + 用例 ≥3 条。**在那之前，任何文档不得声称支持 IEEE。**

## 六、与既有机制的分工（改本块前必读）

| 机制 | 管什么 | 与本契约的关系 |
|---|---|---|
| `cite-format.mjs`（本块） | 目标格式**能不能拼出来** → 草稿 + 缺什么清单 | 生成侧；只读式，**不改定稿** |
| `G15-VolIssue` | **契约要件**在不在（DOI/卷(期)起止页 / ISBN+DOI 双写 / URL+访问日期） | 判级侧（候选 P2、模式相关需 `--qlt`）；**不核著录格式对不对** |
| `M-Exist-1` + `cite-coverage-check.mjs` | 文末条目 ↔ 正文引用的**双向闭环** | 依赖**编号形态**（§二）与**顺序不重排** |
| T7 `G1/G4` + T9 六维之「引文规范」 | 格式**正确性**的**人文判断** | 本块给出模板 → 让人的判断有共同基准 |
| `P1-D`（引用格式/元数据） | 定稿里格式错误的**处置通道** | 格式修正走 T8 亲修；生成器**不代改** |

## 七、未做 / 边界（如实）

1. **不做「串 → 串」转换**（§零 1）。
2. **不做 CNKI / BibTeX / RIS 导入**——那是摄取问题，归 `_shared/材料摄取.md` 的档位阶梯。
3. **不做投稿系统的版面级排版**（期刊模板的字号/行距/双栏）——论衡管**著录格式**，不管**版面**。
4. **逐条核验仍是人工**：本器只保证「按字段拼得对」，不保证「字段本身是真的」（真伪归 T1 落卡自检 + T7 G1 抽查）。
5. **字段值取到行末**：`- **字段**: 值` 的取值止于该行末（多行字段只取首行）。文献卡的著录类字段（作者/年份/类型/出处/DOI）本就是单行；若某卡片把出处写成多行，请先并成一行。
6. **索引段对账是「提示」不是「判错」**：条目字段与 `📇 索引段` 表格不一致时进 `crossCheck` 清单——**可能两边都对**（如条目记原作者、索引段记译者），须人工核；机器不做姓名/责任者判定。
