# auto_cite 集成约定

> **本文件不再单独变更发布。**
> **本文件性质**：机制文件（references/_shared/ 下），默认禁写；改进动议只写 `audits/反哺报告-vN.md`。

## 何时调用

- **T5 写手 v1 完成后**：对每段引用做完整性检查，缺卷期页码 → 触发 Phase 1.5 补检索
- **G14 终闸 Pass 并冻结正文之后、Phase 5 的 T8 终检之内**（**v18.75.0 定案**；旧文为「Phase 4.5 终稿前」）：跑一次 auto_cite 全量校验，确保所有 [Lxx]/[Dxx] 通过 100% 真实性核验
  > **为什么锚在冻结之后（三处同源一致）**：① **相位**（本节）／② **动作**（冻结点 = **G14 Pass 那一刻**，见 `../pipeline-readme.md` §流水线全景 Phase 4.6）／③ **对象**（`command-routing.md:38` 写的是 **`final/定稿.md`**，由 T8 复制落盘）。旧时点「**终稿前**」意味着正文**尚未冻结**，而 T9（Phase 4.7）与 **G 环**修订都还在其后 → 该时点评的不是交付的那一份，「100% 通过」会沦为**无对象的背书**。**现存两处矛盾一并消除**：① `final/定稿.md` 在 4.5 不存在（该命令在旧时点**无对象可跑**）；② 冻结前后的正文不是同一份（判据同 T9：`checkers/中文AI痕迹-checker.md` 「终闸不得早于 Phase 4.6——须在**内容冻结稿**上判，否则结论会被后续修订推翻」）。
  > **精确落点**：落在 T8 的**终检顺序契约**内 = **③ 冻结定稿并记 sha256** 之后、**⑥ 跑 M 门** 与 **⑦ 裁定** 之前（该契约见 `../agents/08-终检-finalizer.md` §终检顺序契约，判据「**正文冻结必须早于指纹与裁定**」）。落在 ⑥⑦ 之后会**破坏该契约**——裁定值须与它当轮所引的正文同源。
  > **⚠️ 顺序契约（不可交换）**：**本校验之后正文不得再变。** 若它报出的缺项确需改正文（如补卷期页码）→ **必须走 G 环**（改冻结正文 → **重跑 G14 至 Pass 才重定冻结**）→ **再重跑本校验**，其「100% 真实性核验」方成立；**不得**改完正文却不重跑 G14、不重新冻结、不重跑本校验（那正是终检顺序契约禁止的「指纹早于冻结」形态）。
- **主人通过 `/lunheng -cite` 命令触发**（详见反哺报告 v4 + 论衡 SKILL.md description + lunheng-commands 技能包）
- **T3.5 auto_cite 预标注阶段**（可选，详见反哺报告 v2）

## 调用参数（与 DSH 原生 auto_cite 工具对齐）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| field | "computer science" | 学术领域倾向（从任务简报 §论文类型 自动映射） |
| min_citations | 5 | 最小引用数（仅 auto 模式有效） |
| citation_style | 任务简报 §引用格式 默认值 | APA / IEEE / Vancouver / Nature / numbered |
| exclude_preprints | true | 排除预印本（投稿论文场景） |
| exclude_conferences | false | 不排除会议论文 |
| year_preference | (无) | 优先年份（如 2024） |

## 失败处理

- **API 积分不足** → 自动降级到自维护 [Dxx]/[Lxx] 库，不抛错；在交接报告标「⚠ auto_cite 降级」
- **找不到匹配文献** → 输出「⚠ 该论点无匹配真实文献」，T7 标 P1
- **部分引用有卷期页码，部分无** → 报告「差异覆盖率 X%」，T8 终检记录偏差
- **auto_cite 推荐的引用与已有 [Lxx] 重复** → 提示「已有相同文献 Lxx」，避免重复入卡

## 与论衡已有机制的对齐

- **引用模式锁定**：auto_cite 输出必须遵循任务简报 §引用模式（编号 / 内联）
- **数据信任级别**：auto_cite 推荐文献的信任级别由其数据源决定（Semantic Scholar = 已发布 / 二手转引 = 需回溯）
- **三角验证**：auto_cite 不替代 T1 文献检索；仅在 T5 v1 后做"补强"扫描
