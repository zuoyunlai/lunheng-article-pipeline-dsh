# 中文数据源集成（v2.5.1 修订：基于主人 2026-08-24 国内文献平台 API 实测）

> **定位**：**中文特化补充层**，不是替代 web_search/tavily 的多语言检索——并行检索、合并去重。
> **触发**：Phase 0 定题时，主人选择「启用中文数据源集成」才激活。
> **不启用**：不影响论衡主要功能（仍用 web_search/tavily 检索中英文公开数据）。
> **v2.5.1 关键修订**：原文档列「知网 API / 万方 API / CSSCI」不够准确——**知网无公开 API**、**万方需付费申请**、**CSSCI 实际无独立 API**（CSSCI 是期刊目录，不是数据库）。本修订基于主人实测分 3 梯队。

## 一、检索架构（v2.5.1 修订：3 梯队中文层）

```
T1 文献检索（并行调用）
├── 默认层（始终启用）：web_search（DSH 内置，中英文）+ web_search（全球化）
└── 中文层（可选启用，按主人能力勾选）
    ├── 第一梯队（真开放、无 Key、立刻能用）⭐
    │   ├── OpenAlex API（全球免费学术元数据，4.7 亿+ 成果，含大量中文学术期刊，无需 Key）
    │   └── Crossref API（DOI 注册机构，免费，无 Key，DOI 元数据）
    ├── 第二梯队（需 API key + 申请/付费/机构门槛）
    │   ├── 万方开放平台（apps.wanfangdata.com.cn，需 X-Ca-AppKey + APPCODE，申请付费）
    │   ├── 科情数据（smartdata.las.ac.cn，中科院文献情报中心，需机构申请）
    │   └── NSTL 国家科技图书文献中心（面向机构图书馆服务）
    └── 第三梯队（无 API，靠抓取）
        └── 中国科技论文在线 paper.edu.cn（教育部主办，110 万+ OA 论文，Firecrawl 抓取）
    └── 合并策略：默认层 + 中文层结果合并 → 去重（同 URL/同 DOI/同标题） → 产出文献卡

T2 数据检索（并行调用）
├── 默认层：web_search（统计数据/行业报告/新闻数据，中英文）
└── 中文层：同 T1（按主人勾选）
    └── 合并策略同上

T3 案例检索（并行调用）
├── 默认层：web_search（事件/企业/司法案件，中英文）
└── 中文层：同 T1（按主人勾选）
    └── 合并策略同上
```

## 二、3 梯队详解（v2.5.1 修订）

### 🥇 第一梯队：真开放、无需申请、直接用

#### OpenAlex ⭐（强烈推荐）
- **性质**：全球最大免费学术元数据平台（[openalex.org](https://openalex.org)），标引 4.7 亿+ 成果
- **API**：完全免费、**无需 API Key**、REST 接口
- **中文文献覆盖**：收录大量中文学术期刊/学位论文（通过 Crossref/DOI 及中文出版商数据源）
- **能力**：按标题/作者/机构/主题/引用检索，支持全文搜索、过滤、分页
- **用法**：`GET https://api.openalex.org/works?search=人工智能&per-page=20`
- **适合**：文献计量、开题调研、引用分析

#### Crossref ⭐
- **性质**：DOI 注册机构（[api.crossref.org](https://api.crossref.org)），全球文献元数据
- **API**：免费、无 Key、REST 接口
- **能力**：按 DOI/标题/作者检索论文元数据
- **用法**：`GET https://api.crossref.org/works?query=深度学习&rows=20`
- **适合**：查 DOI、找英文文献元数据、引用格式

### 🥈 第二梯队：有 API 但需申请/机构门槛

#### 万方开放平台
- [apps.wanfangdata.com.cn](https://apps.wanfangdata.com.cn/open)
- 含：文献检索、详情、全文下载、智搜（自然语言转检索语法）
- 认证：`X-Ca-AppKey` + `APPCODE`，**需付费/申请应用**
- 适合：商业级中文库

#### 科情数据（中科院文献情报中心）
- [smartdata.las.ac.cn](https://smartdata.las.ac.cn)
- 面向科研场景，数据资产级授权（非公开免费），**需机构申请审批**
- 适合：中科院体系、机构用户

#### NSTL 国家科技图书文献中心
- [nstl.gov.cn](https://www.nstl.gov.cn)
- 中文+外文文献，**面向机构/图书馆服务**，部分 OA 资源开放，API 需对接申请
- 适合：机构图书馆接入

#### 超星/读秀（备选）
- [duxiu.com](https://www.duxiu.com) — 学术搜索+原文传递，主要面向图书馆，无公开个人 API
- 适合：通过学校图书馆间接使用

### 🥉 第三梯队：无 API，靠抓取/手动

#### 中国科技论文在线（paper.edu.cn）
- 教育部主办，**开放存取（OA）** 平台，[paper.edu.cn](https://www.paper.edu.cn)，110 万+ 首发/期刊论文
- **没有公开 REST API**——可走网页抓取（Firecrawl）
- **适合**：中文论文全文获取（检索摘要可抓，全文 PDF 直链）

#### 知网（CNKI）
- **无公开 API**、反爬最强 → 只能浏览器自动化（之前实战验证过） 或机构渠道

#### 维普
- 类似知网，无公开 API，机构订阅为主

> **v2.5.0 → v2.5.1 关键修正**：原文档写「知网/万方/CSSCI」——知网无公开 API（需浏览器自动化）、CSSCI 不是数据库（是期刊目录）、万方需付费申请。v2.5.1 改为 **OpenAlex + Crossref 第一梯队（默认推荐）** + 万方/科情/NSTL 第二梯队（需申请）+ paper.edu.cn 第三梯队（抓取）。

## 三、启用条件（Phase 0 同意关卡）

- **触发**：主人在 Phase 0 任务简报勾选「启用中文数据源集成」
- **默认推荐（无需配置）**：OpenAlex + Crossref（第一梯队，自动启用）
- **需 API key 配置**（主人 Phase 0 选二梯队时）：
  - 万方：`WANFANG_APP_KEY` + `WANFANG_APPCODE` 环境变量
  - 科情数据：`KQING_APP_KEY` 环境变量（机构申请后）
  - NSTL：`NSTL_APP_KEY` 环境变量（机构申请后）
- **抓取层**：paper.edu.cn 走 Firecrawl 抓取（DSH 环境配置 firecrawl_api_key），无需额外配置
- **不启用**：默认层（web_search/tavily）继续跑，证据底座不变

## 四、合并策略（去重）

| 字段 | 匹配规则 |
|------|---------|
| URL | 完全相同 |
| DOI | 完全相同（OpenAlex/Crossref 都有 DOI） |
| 标题 | 编辑距离 < 10%（防止不同来源抓的同一论文略有差异） |
| 作者+年份+期刊 | 三元组相同 |

## 五、输出格式（合并后的卡片）

文献卡/数据卡/案例卡的格式不变（v2.1.x 已定义），但在「数据源」字段标注：
```
- 来源：web_search + OpenAlex（合并去重，第一梯队）
- 来源：web_search + Crossref（合并去重，第一梯队）
- 来源：web_search + 万方（合并去重，第二梯队，需主人提供 API key）
- 来源：paper.edu.cn（第三梯队，Firecrawl 抓取）
```

## 六、化弊为利

- **弊端**：「证据底座局限于中文」→ **不存在**，因为中文数据源是「补充」不是「替代」
- **利好**：启用后中文文献更全（OpenAlex/Crossref 覆盖 4.7 亿+ 元数据 + 万方商业库付费墙内学术论文）+ 多语言证据不受影响
- **v2.5.1 关键**：第一梯队（OpenAlex/Crossref）**无需 API key**，启用门槛极低，主人「启用中文数据源集成」即默认开第一梯队

## 七、Phase 0 同意关卡措辞（v2.5.1 修订）

```
□ 启用中文数据源集成（并行补充 web_search/tavily）
  ├─ ✅ 第一梯队（默认推荐，无需 Key）：OpenAlex + Crossref（4.7 亿+ 元数据，中文学术期刊覆盖好）
  ├─ □ 第二梯队（需 API key + 申请/付费）：
  │    ├─ 万方开放平台（X-Ca-AppKey + APPCODE，需申请）
  │    ├─ 科情数据（需机构申请）
  │    └─ NSTL（需机构申请）
  └─ □ 第三梯队（Firecrawl 抓取）：中国科技论文在线 paper.edu.cn
  ⚠️ 不启用时仍用 web_search/tavily 检索中英文公开数据，证据底座不变
```

## 八、限制

- **API key 边界**：中文数据源 API 由主人在 DSH 环境变量 / settings.yaml 配置（历史遗留表述已废弃）；论衡 agent **不读取也不直接调用**二梯队 API（万方/科情/NSTL），API 调用由主人完成，agent 只消费主人导入的检索结果
- **API key 安全**：主人自管 API key，论衡不存储
- **去重质量**：依赖 DOI/标题匹配，少数情况下可能误去重
- **第二梯队门槛**：万方/科情/NSTL 需机构付费/审批，第一梯队（OpenAlex/Crossref）足以覆盖大部分学术检索需求
