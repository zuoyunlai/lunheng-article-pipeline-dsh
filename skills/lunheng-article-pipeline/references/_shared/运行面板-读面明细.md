# 运行面板 · 读面明细（按需加载）

> **为什么单独放这里**：`SECURITY.md` 是本包的**安全声明**，长期贴上限（35 KB 硬预算）。
> 面板的**逐项派生读面**与**诊断状态文件**属「排查 / 审计时才查」的细节，按「常驻判据留声明、细节按需加载」的口径外移到本文件；
> **声明里的端点、读什么 / 不读什么、两道围栏、残余风险、默认关闭理由一律仍在 `SECURITY.md`**，此处只承接明细。

## 一、v18.91.0 起的派生读面（全部只在本项目目录之内）

**v18.91.0 派生读面（同样只在本目录内）**：`status.md` 的**题名 / 文类 / 目标篇幅 / 纠偏线 / G8 硬阈 / 阶段闭合链 / `[Failed` 失败记录 / `exit 22|20|21` 收报回执**计数；对 literature / data / cases / analysis / drafts / audits / final（含 `final/图件`、`final/证据包`）九目录做**递归枚举**（文件数 + 字节；深度 ≤4、条目 ≤3000）；用这些文件的 mtime 生成「近 48h、每 2h 一格」改动直方图；`drafts/*.md` 的**文件字节**序列（**不是**正文字数——汉字数有既有脚本口径，面板不自行重算）；**v18.93.0**：`/lunheng-panel/file`——**只读下载**项目内已存在的产物字节（定稿 / 交付说明 / 门报告 / 证据包清单 / 运行报告 / token 成本 / 图件 SVG）；围栏同级并收紧：`rel` 必须是项目内相对路径（禁绝对路径、反斜杠、空段、`..`；解析后须仍在项目目录内）、**仅 GET**、上限 8 MB（超出 413）、带 `Content-Disposition: attachment` 与 `nosniff`；仍不写盘、不 spawn、不联网（下载即外带，故登记）。**v18.91.1**：`final/token-cost.json`（权威脚本 `token-cost.mjs` 产出的用量与估算成本；面板只读展示、不自己算，保证口径唯一）。**不读**：凭据、会话内容、`run/` 之外的任何路径。**不写、不 spawn、不联网**。**围栏（两道，任一不过即 403）**：① `root` 必须是本进程已知工作区根（`ctx.workspaceRegistry.list()`；一个都给不出时**才**兜底 `process.cwd()`）；② `project` 必须过 `lib/run-path-fence.mjs` 的 `isSafeProjectArg` + `resolveProjectDir`（**单段**、解析后必须在 `run/` 内——防 `../` 穿越）。**残余风险**：能访问该回环地址者（默认 `127.0.0.1`）可读到上述运行产物摘要——这正是**默认关闭**的理由。

## 二、诊断状态文件

**诊断状态文件**（v18.90.1；v18.90.3 增第二落点）：把 apply 进入、开关来源、服务就绪、注册结果、错误原文、版本、pid 写进系统临时目录与 `$DSH_HOME` 两处的 lunheng-panel-status.json（不加反引号：仓库外运行期文件，会被 link-check 判断链）——不含项目内容与凭据，是宿主 `ctx.logger` 不落盘时的取证通道；可清理。
