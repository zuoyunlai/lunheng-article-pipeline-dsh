### 素材卡索引核验（M-Form-10 索引段完整性，v2.5.2-dsh.17 新增）

有素材卡时必须核（机械门由 `scripts/m-gate-check.mjs` 自动判，T7 只需**复核结论 + 抽查**）：

- **索引段 ↔ 正文条目一一对应**：`## 📇 索引段` 的编号集合必须等于正文二~四级标题的编号集合；**索引缺条 = 下游按索引定位会漏卡 → P1**（合计 >2 条 → P0）。
- **头部声明条数**：卡头「总条数 / 合计 N 条」须与正文条目数一致（best-effort 解析）。
- **索引行信息量**：每行须含「编号 + 主题 + 支撑论点」（去掉编号后 <6 字 → P2）。
- **关键词**：本项存在的意义是保证 T4/T5「先读索引段」的**读取纪律**不会以省 token 之名造成漏读——索引不完整时，读取纪律反而放大风险。

### 图件核验（M-Form-9 图件闭环，v2.5.2-dsh.16 新增）

有图位时必须逐项核（机械门由 `scripts/m-gate-check.mjs` 自动判，T7 只需**复核机械结论 + 补人工判断**）：

- **图位 ↔ 图件双向对应**：正文每个 `[图N：标题]` 在 `final/图件/` 有 `图N_标题.svg`；反向无孤儿图件。缺图 → P1（图件全缺或图位全缺 → **P0**，打回 Phase 4.5 补图）。
- **图位数量 ≥ 任务简报图位数量**：写手「必产 ≥ N 个图位」硬约束（旧版该条只写在 T5 卡、无落地路径）。
- **图上数字有出处**：SVG 可见文字里的数字必须能在数据卡/正文找到（启发式，命中给 P2 提示，人工确认是否刻度/坐标）。
- **SVG 良构**：标签配平 + `<svg>` 根 + `viewBox`（或宽高）+ 无 DTD/ENTITY；含 `<script>`/`on*`/`foreignObject`/`javascript:`/外部引用 → 必须剥离并记录（导出前 `md2html.mjs` 会拒绝结构不合格的 SVG）。
- **独占一行规范**：图位单独成行（行内写法会被导出为内联图、无图注，记 P2）。
