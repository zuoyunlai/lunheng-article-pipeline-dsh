## F3 反方论证覆盖必查（v2.2.0 新增）
- 对照 `analysis/分析大纲.md` 的「反方论证规划」段，grep 正文检查：**每个核心论点是否都有反驳 + 回应子段落？**
- 缺失反方 → P1（「不建构反驳的论证 ≠ 严谨论证」）

## F4 论点-论据一对一验证（v2.2.0 新增，与 M 门绑定）
```bash
# Step 1: 从分析大纲提取所有核心论点编号（依赖主控标记 [论点N]）
grep -oE '\[论点[0-9]+\]' analysis/分析大纲.md | sort -u > /tmp/lunheng-claims.txt
# Step 2: 从定稿提取所有 [Lxx]/[Dxx]/[Cxx] 编号
grep -oE '\[(L|D|C)[0-9]+\]' final/定稿.md | sort -u > /tmp/lunheng-evidence.txt
# Step 3: 检查每个 [论点N] 上下文是否有支撑证据（人工 grep）
# 自动化检查不到的是「论点与论据是否对应」—— 必须 LLM 手工检查（这是 G3 负责的）
```
论衡哲学化：「**M 门查形式，F4 查逻辑，G3 查内容**——三层验证」。

## F8 vs F1-F7 关系

F8 是「数据信任」专维度（信任级别/来源隔离），F1-F7 是「论证/格式」专维度（幻觉引用/数据/早期框架/论证自洽/拼凑式/过度防御/主人风格），**不重叠**。
