## 一、背景与动机

### 1.1 调研发现（Ai4Scholar 借鉴点）

Ai4Scholar v2.9.4 关键改进：
- 用户可设置"引用位置数"和"最大参考文献篇数"
- 可指定目标期刊，AI 优先引用该刊文献
- 每条引用旁"替换"按钮（候选文献免费 + 按标题/DOI 搜索新文献）

这些能力对应到论衡场景：**T5 写手常常"引用过多"或"该引未引该刊"**——若在任务简报显式锁定"目标引用数 [下限, 上限]" + "目标期刊 Top 3"，T7 审计可机械核验。

### 1.2 论衡现状盘点

| 维度 | 论衡现状 | 借鉴点 |
|------|---------|--------|
| T9 同行评审 + 期刊匹配 | v2.4.0 已支持；6 维度评分 + Top 3 推荐期刊 | 复用已有 |
| 引用数 | 无显式控制（T5 写手自由发挥） | **新增控制字段** |
| 期刊优先 | 无显式锁定 | **新增字段** |
| 引用匹配度审计 | 无 | **新增 G15 引用匹配度** |

### 1.3 改进目标

1. **任务简报 §引用数量与质量控制**（新字段）——主人可设目标引用数 [下限, 上限] + 目标期刊 + 影响因子门槛
2. **T9 审稿报告新增 §引用匹配度 段**——6 维度评分不重复，加入"引用匹配度"专段
3. **G15 引用匹配度审计**——T7 按 6 维度核验
4. **M-Exist-6 扩段**——任务简报 §目标期刊 vs T9 推荐 Top 3 一致性

## 四、风险与回滚

| 风险 | 缓解 | 回滚 |
|------|------|------|
| 引用数过严导致 T5 写手缩手缩脚 | 默认 = auto = 字数 ÷ 300，不强制 | 主人 Phase 0 不勾选 |
| 优先同刊命中率算法不准确 | 用 LLM 推理判定（不写死规则） | 删除 G15 段 |
| IF 数据来源不一致（不同数据库 IF 数值不同） | 取任务简报 §数据卡 已发布数据 | T7 审计 G15 时手动核对 |
| 任务简报 §目标期刊 误填 | Phase 0 显式问询 + 任务简报 v2.5.0 锁定 | 不勾选 = 「无」 |

### 回滚一行命令

```bash
git revert <commit-hash-of-v18.7.0-G15>
```
