## 一、改动清单（逐项：病灶 → 判据）

### P1-1 `lib/panel.mjs`：固定文件读取与 stat 全部收进围栏

新增 `readTextWithin(root, full)` 与 `statWithin(root, full)`（判据与既有 `safeEntry` 同源：
`lstat` 不跟链接 → `isPathInsideRunDir` 物理层 → 常规文件 + 单文件上限）。改写的读取点：
`status.md` / `01-任务简报.md`（×2）/ `agents-log.md` / `final/运行报告.json` / `final/token-cost.json` /
M 门复跑报告 / `drafts/初稿-vN.md` / `audits/审稿报告-vN.md` / `run/*/final/运行报告.json`，
以及 `status.md`、`token-cost.json`、`drafts/*`、图件的 `statSync`（`statSync` **跟随**链接，
会泄露界外 mtime/大小——同一条围栏的第五个漏口，本批一并收）。

### P1-2 `.github/workflows/publish.yml`：latest 断言 step 自包含 + 与防回退口径相容

- step 内自行 `VER="$(node -p "require('./package.json').version")"`（跨 step 只认 outputs/env，不认局部变量）。
- **第二半**（旧版即使定义了 VER 也会误红）：`npm view "$PKG@>$VER"` 有结果 ⇒ 本次是**补推历史 tag** ⇒
  按上一步的防回退口径**不**断言 `latest==VER`，只 notice。两条规则从此不再互斥。

### P1-3 `.github/workflows/publish.yml`：新增「同 SHA CI 绿闸」

`gates` 作业加 `actions: read`（仍无 `id-token` / 无 `NPM_TOKEN`）。新 step 查
`repos/<repo>/actions/workflows/ci.yml/runs?head_sha=<SHA>`：**有失败即红**；全 green 才放行；
无记录/仍在跑则 30s 轮询、最多 15 分钟，超时 **fail-closed**（发布是 npm 不可撤回动作）。
不覆盖 `workflow_dispatch` 手动补 dist-tag 的路（该路不发新版本）。

### P2-1 `lib/panel.mjs`：`ok / soft / retry` 三分

`ok` = `exit 0`（真通过）；新增 `soft` = `exit 22`（待复核）；`retry` = `exit 20/21`。
键名 `ok` 保留以免客户端断裂，**语义收窄**。

### P2-2 / P2-3 `scripts/_lib/mgate-gates/mfact-gate.mjs`：上下文与单位

- 分组键 `key` → `key + 单位`：异单位只跳过**该对**，不再整组 `continue`（修 P2-3，并让错误集合单调）。
- 新增 `ctxSig()`（命中句内四位年份集合）。**限定语确实不同** ⇒ 降 P2 候选（`reason: context-mismatch`），
  判级交 T7/T8；**全部缺失或全部相同** ⇒ 仍按原文口径判硬（刻意不做「无年份就降级」——那会把假阳性换成系统性漏检）。
- 门级 `worst` 改为**尊重逐条 severity**：旧写法「只要 conflicts 非空就升 P1」会把逐条降级整体抵消。

### P2-4 `skills/.../scripts/handoff-check.mjs`：按项目代际分流

无账本时先判代际证据：① `status.md` / `01-任务简报.md` 声明 `交付协议：v2`；② 任一 `阶段确认-*.md` 的 §6
写了 `回执 id`（v18.81.0 起的模板指纹）。命中即 **A7 硬 21**（补账本，或显式声明 `交付协议：v1`）。
两样都没有 → 只提示，并**如实标注 legacy / 未核验**。正则容忍 `**` 加粗（`- **交付协议**：v1` 是实际写法）。

### P2-5 `scripts/host-install-smoke.mjs`：先判进程状态再判文本

`dump.status !== 0 || dump.signal || dump.error` ⇒ 直接判负，**不再**因输出含自注册行而通过（fail-closed）。

### P2-6 `scripts/derive-facts.mjs`：穷举同类声明

`exec` → `matchAll`，逐处核对并给出命中序号；前段正确、后段写错（含逆序）都会报。
