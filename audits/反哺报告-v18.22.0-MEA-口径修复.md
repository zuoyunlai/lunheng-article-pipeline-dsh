## §三、实施步骤（顺序硬约束）

### 步骤 1：MEA-1 修 `token-budget.mjs`

**A · 加 `--include-main` 开关**
- 默认 `false`（**只聚合子代理**，主会话不进角色桶）
- `--include-main` 显式放开（兼容旧读数 + 便于调试主会话污染）

**B · 加 "未归类" 桶**
- 三个出口：① 子代理但 label/title 都匹配不上 ROLE；② 主会话（除非 `--include-main`）；③ 字段缺失
- 输出格式：`{ n, cacheRead, output, steps, sharePct }`（与其他桶同构）
- **末尾明确**："未归类 0 桶" / "未归类 N 桶（占比 X%）——本次读数受 X% 污染"

**C · 加 fallback 命中数**
- 匹配顺序：`label` 优先；`label` 不匹配则用 `title` 作为 fallback
- 末尾输出 `fallbackHits: N`（让用户知道"启发式承认为启发式"）

**D · 输出头加口径三要素**
- 现输出第 1 行：`# token 预算实测（2026-09-27）`
- 改为三行：
  ```
  # token 预算实测（2026-09-27）
  # 口径：subagent.identity.label 非空（默认）；主会话不计入（--include-main 显式放开）
  # 样本：N 会话（子代理 M / 可识别为论衡角色 K / 未归类 J）；分母 = 子代理 cacheRead 合计
  ```

**E · 关键代码改法**

当前 200 行：
```js
const sub = classified.filter((s) => s.role);   // ← 不过滤主会话
const total = sub.reduce((a, s) => a + s.cacheRead, 0);
```

改为：
```js
// v18.22.0 MEA-1：子代理过滤（默认）/ 主会话放开（--include-main）
const isSub = (s) => s.label && String(s.label).length > 0;   // subagent.identity.label 非空
const scoped = includeMain ? classified : classified.filter(isSub);
const sub = scoped.filter((s) => s.role);   // 角色归因
const fallbackHits = scoped.filter((s) => s.role && /* label 未命中但 title 命中 */).length;
// + 新桶
const unmatched = scoped.filter((s) => !s.role);
// + 输出头口径三要素
```
