## 二、改进目标（6 项反哺规则 + 1 项新增脚本）

### 反哺规则 1：**T6 批判伙伴豁免规则**（任务简报 trigger=false 项不攻击）

- **来源**：`06-批判-critical-companion.md`（v18.8.x 补丁）
- **痛点**：原 T6 在 trigger=false 项目中仍报 Permanent Gap 项为 P0，导致 T5 写「加固失败降级预案」等防御性文字，论文显弱且字数膨胀 1.4x
- **改动**：在 `06-批判-critical-companion.md` §触发条件读取后增加「### 豁免规则」节，明确：
  - T6 不主动攻击 trigger=false 标记的 Permanent Gap 项
  - 仅在 C5 时效与现实节末尾留「已知接受」记账（简短说明，不展开为攻击）
  - 例外触发：主人 Phase 2.5 大纲确认时删除相应 Permanent Gap 论点 / Phase 4.5 T9 后触发补检索 / 决策记录显式放弃接受脆弱
- **影响**：每个 trigger=false 项目减少 1-3 条无效攻击 + 主控不再做无效加固
- **验证**：本次项目跑过（不再报 4 项 Permanent Gap 为 P0）
- **commit 路径**：`references/agents/06-批判-critical-companion.md` 第 50 行后插入新节

### 反哺规则 2：**T5 写手字数估算 +20% buffer**

- **来源**：`05-写作-writer.md`（v18.8.x 补丁）
- **痛点**：T5 估算 +263 字 / 实测 +380 字（偏差 1.45x），主控被迫 4 次微压缩才能进 G5 阻塞线（实测场景：v2 → v3 一次压缩 4 次）
- **改动**：在 `05-写作-writer.md` §字数口径与权威核验后增加「### 字数估算 +20% buffer」节，明确：
  - 写手估算字数时自动 +20% buffer（5000 → 按 6000 字规划）
  - 边际加固段（方法学声明 / 局限性说明 / 反方回应）按 +30% buffer
  - 实测以 `count-chars.mjs` 为权威，buffer 超出量由主控微压缩处理
- **影响**：单轮修订主控微压缩次数从 4 → 1（实测场景预估）
- **验证**：本次项目未验证（v3 修订时本规则尚未应用）；T5 在 v4 项目应自动 +20%
- **commit 路径**：`references/agents/05-写作-writer.md` §字数口径与权威核验后插入新节

### 反哺规则 3：**M-Form-11 适配 `### 子段` 与「裸 [先NN] 行首」**

- **来源**：`scripts/_lib/mgate-helpers.mjs` (`idsByToken`) + `scripts/_lib/mgate-gates/mform-gates.mjs` (M-Form-11 函数)
- **痛点**：
  - 原 regex `^#{2,4}\s*已加载` + sectionRange boundary `^#{2,4}\s` 在 `## 已加载 + ### 一、文献卡` 结构下，被 `###` 一级子标题截断 → loadedSeg 仅含 `## 已加载` 与 `###` 之间的少量注释 → 「已加载 0 条」误判 P0
  - 先行者清单的条目是**行首裸编号** `[先01] 标题 | 作者 | 年份 | URL`（模板即如此，非 `### [先01]` 标题形态）→ `idsByToken` 的 `#{2,4}` 前缀要求一条都扫不到 → [先NN] 被判 ghost
- **改动**：
  - `mform-gates.mjs`：正则放宽为 `^#{1,4}\s*已加载`（不要求尾部 `(\s|$)`），sectionRange boundary 改为 `/^##\s/`（让 `###/####` 视为子节留在已加载段内）
  - `mgate-helpers.mjs`：`idsByToken` 正则前缀从 `#{2,4}` 改为 `#{0,4}`（允许先行者清单的行首裸编号）
- **影响**：M-Form-11 从 P0 → P2（仅剩"读了但正文未引用"合规留痕软提示）；ghost 数 0
- **验证**：本次项目跑过（p0=2 → p0=1）
- **commit 路径**：双文件改 `^#{2,4}` → `^#{0,4}` + sectionRange boundary

### 反哺规则 4：**M-Exist-1 先行者孤儿软处理 + 决策记录自动检测**

- **来源**：`scripts/_lib/mgate-gates/mexist-gates.mjs` (mExist1 函数)
- **痛点**：原 M-Exist-1 报「4 孤儿 [先01]-[先04] = P1」，但这些孤儿**实质是先行者清单与文献卡的同篇双列**（[先01]=[L07] 邱泽奇、[先02]=[L08] 边燕杰、[先03]=[L06] 项飙），T7 需人工记账「形态规范冲突」
- **改动**：
  - `mExist1` 加分流：`[先NN]` 孤儿恒 P2 + 提示同篇双列回查路径；`[L]/[D]/[C]` 孤儿仍 P0/P1
  - 决策记录（`决策记录-PhaseN-*.md`）中出现的 `[先NN]` 编号 → 视为经过主人显式决策流程处理（不再要求关键词匹配，文件名本身即"主人闸门"证据），命中时 hint 注明出处供 T8 复核
- **影响**：M-Exist-1 从 P1 → 通过（p1=4 → p1=3）
- **验证**：本次项目跑过
- **commit 路径**：`mexist-gates.mjs` mExist1 函数内 + 增加 `basename` 导入

### 反哺规则 5：**M-Exist-4 / M-Exist-6 解析精度**

- **来源**：`mexist-gates.mjs` (mExist4 / mExist6 函数)
- **痛点**：
  - M-Exist-4：`isReject` 扫**全文**找"打回"——复核轮（第 2 轮）报告在叙述第 1 轮历史时必提到"打回" → 误判
  - M-Exist-6：表头检测找"第一根**包含**『综合匹配度』的表格行"——前文校验表里一格写"期刊匹配表表头含综合匹配度"被误判为表头；修改建议仅认列表形态不认表格行
- **改动**：
  - M-Exist-4：`isReject` 改为只看**结论行**（含"结论/判定/verdict"的行）+ 优先匹配"通过"模式（`/复核通过|通过\s*[✅）)]|结论[：:]\s*[✅]?\s*通过/`），无结论行时回退前 30 行
  - M-Exist-6：
      1. 表头检测：`tableCells` 切列 + 单元格精确匹配（`/^[*\s]*综合匹配度[*\s]*$/`），不再粗扫
      2. 修改建议条目：表格行（`^\s*\|` 且首格匹配 `R?-?\d+|P[012]-\w+`）同样计入 + 定位检查沿用 §X/行\d/[Lxx] 正则
- **影响**：M-Exist-4 从 P1 → 通过；M-Exist-6 从 P1 → 通过
- **验证**：本次项目跑过
- **commit 路径**：`mexist-gates.mjs` mExist4 函数 `isReject` 局部 + mExist6 函数 `jHead` 检测 + `sugItems` 过滤

### 反哺规则 6：**新增 `apply-revision-cycle.mjs` 自动化编排**

- **来源**：实战主控每轮修订 8 步手工串联 → 1 条命令（v18.8.x 新增）
- **痛点**：v2/v3 两轮主控分别手工做了 4 次微压缩、8 次工具调用（cp/count/grep/edit/bundle/build-evidence-bundle/写修订说明），且 T5 估算字数不准使主控反复微压缩
- **改动**：新增 `scripts/apply-revision-cycle.mjs`，串起 7 步：
  1. cp `drafts/初稿-v(N-1).md → drafts/初稿-vN.md`（若 vN 不存在；dry-run 不复制）
  2. `countHan` 前置口径测量（body = 摘要后~文末节前 纯汉字，与 count-chars.mjs 同源 `_lib/han.mjs + _lib/sections.mjs`）
  3. 应用段级 diff 清单（`--diff-list` 时委托 `apply-diff.mjs --in-place`，自动带时间戳 .bak；汉字 delta 由其实测）
  4. 后置测量 + G5 阻塞线判定（目标字数从 `01-任务简报.md` §目标篇幅 提取；G5 = −10% / +5%）
  5. 内部流程词残留快扫（`Phase N.N` / `承重` / `一处两用` / `修订说明` / `初稿-v\d` / `审计环节` / `批判报告`——M-Form-4/5 前哨，只报数不判死）
  6. 刷新证据包 + 审计视图（委托 `build-evidence-bundle.mjs <项目> --summary`；`--skip-bundle` 跳过）
  7. 生成 `drafts/修订说明-vN.md` 骨架（已存在则不覆盖；字数表预填实测值，决策内容留占位给主控）
- **影响**：单轮修订主控手工操作从 8 步 → 1 步（实测场景）
- **验证**：本次项目 dry-run 实测通过（脚本运行 OK，dry-run 不落盘）；待 v4 项目正式跑一遍非 dry-run 验证
- **commit 路径**：`scripts/apply-revision-cycle.mjs` 新增 + SKILL.md 白名单 15→16 + SECURITY.md 安全面更新 + DSH-集成方案.md 计数 15→16
