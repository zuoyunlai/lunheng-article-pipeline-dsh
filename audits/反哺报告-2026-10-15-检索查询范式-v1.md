## 0. 结论摘要（先读这段）

**主结论：可行，但绝不能写成全局总则——「一句自然语言问句」不是通用解**：

- **T1（概念型问题）**：问句式**有效**（§3.1：两轮 10 条中 6–8 条两者重合，但问句式**多召回**了直接对应「感知/测量/动机」的实证文献）。
- **T2（数据/时效型问题）**：**不劣化**（§3.2：6 次调用后判据翻转——两者给的是同源同根的检索集，差别只在**排序**与**限定语吻合度**，召回量级相当）。
- **T2（指标名检索，如 `论文数量`）**：**无效**（§3.2c：任何句式都命中不了「论文数量」这层语义，它必须是元数据属性/注册表查询，不是 query 措辞问题）。

| 角色 | 主轮引擎（卡内已锁） | 查询范式动议（**三轮对照后修正版**） | 依据 |
|---|---|---|---|
| **T1 文献检索员** | `engine=exa`（神经检索） | ✅ **概念型问题转自然语言问句**（概念维度进句子） | §3.1a/§3.1b 实测 |
| **T2 数据检索员** | `engine=tavily` | ✅ **两种句式都可用**（写死「问句不劣于关键词式」）；**仍须**保留「指标名 + 地域 + 年份 + 口径」的字面要素 | §3.2 实测（推翻了本文 v1 原稿的「豁免」主张） |
| **T3 案例检索员** | `advanced_search` 泛用 | ✅ **保持现状**（已被写入卡的关键词式范式，`03-案例检索-case-scout.md:69-72`） | 卡内已有规范，本批不动 |

> **v1 原稿的一处判断已推翻（如实登记）**：本文首轮（每主题仅 1 轮）曾判定「T2 用问句式会**降质**，应显式豁免」。**3 轮对照没有复现该差异**——见 §3.2 的翻转说明。**故 v2 把 T2 从「豁免」改为「两式皆可」**，并保留唯一一条真差异（§3.2c 的指标名/注册表问题）。

**三条比查询范式更重的事实**（同批实测，均在 §4）：

1. **引擎层与 DSH 实际生效引擎不一致**：`dsh-free-search` 的 `web-search-free` 行把 `provider` 固定为 `bing`，而 `~/.modsearch/config.json` 的 `engine` 是 `exa`——**`web_search` 实际走 bing 关键词引擎**，语义能力被旁路。故「想要语义」在现网**只能靠显式传 `engine`**。
2. **T2 真正的瓶颈不是查询范式，是「注册表直取」整块缺失**：全仓（`SKILL.md` / 接入面 / 三卡 / 中文数据源集成）**零提及** `domain_search`，而它实测可一次给出带 DOI + `cited_by` 的成果元数据与公告 PDF 直链（§4.3）。
3. **`domain_search` 注册表可静默答非所问**：`engine=worldbank` 两次都返回 GDP 总量而非研发强度序列（§4.4）——权威来源 + 真 URL + **错指标**，正撞 T2 铁律的字面检查盲区。

**前置阻断（先决条件，比动议本身优先）**：B 档（AI4Scholar）在本机**不可达**——`get_ai4scholar_credits` 回报 `AI4Scholar API key is not configured`（§5，实测 + 源码判据）。T1b / T2 文献计量方向点名的 `search_papers` / `search_semantic` 当前 **100% 在入口抛错**。**在 B 档恢复前落地 §7 的 B 档相关指引，会写出「指引面在、工具面在、凭据面不在」的第三重空指引。**

## 3. 实测证据：同一引擎上，两种句式的返回分布

### 3.0 实验设计（v2 扩为 3 轮）

> **v1 原稿只跑了「每主题 1 轮」，据此得出「T2 问句式降质」——本轮把它扩到 3 轮后，该结论未复现（见 §3.2c 的翻转登记）。** 本节所有数字以 3 轮为准。

| 项 | 设计 |
|---|---|
| **轮次** | **3 轮**（主题彼此独立，非同题重复）——补上 v1 自陈的最大短板（「单轮 = 差异真实存在、幅度不成立」） |
| **每轮变量** | 同引擎、同主题、**仅句式不同**；每式取前 5 条 |
| **度量** | ① 前 5 条**重合数**（引擎自身稳定性的反向指标）② **独有**条目的相关性（有 DOI/期刊/样本量者优先）③ 检索集的性质（学术文献 vs 行业报告） |
| **引擎选择** | 按**角色卡锁定的引擎**测（T1 = `exa`、T2 = `tavily`），**不跨引擎比**——句式收益必须与引擎类型绑定才有意义 |
| **未做** | 没有第三方相关性标注（相关性判定由本会话做出、非独立双盲）；`exa`/`tavily` 的**内部排序随机性**未单独量化，只看重合数当代理指标 |

### 3.1 T1 × `exa`：问句式*多召回*直接相关的实证文献

| 轮次 | 句式 | 前 5 条特征 |
|---|---|---|
| **R1**（AIGC 意向性/美学） | 关键词式 | 语义邻域混合（抖音 AI 绘画感知、西南民族大学学报扎根理论、AI 图像标注与用户感知） |
| | **问句式** | 5 条**集中于「感知—测量」族**（`10.1016/j.ijhcs.2024.103375`、arXiv 2405.07346、Nature SR `s41598-024-54294-4`、Wu et al. 2020、arXiv 2409.11911）→ **多召回 2 条测量/偏好类实证** |
| **R2**（算法与创作者自主性） | 关键词式 | 4 条创作者—算法研究 + 1 条中大《平台算法不稳定与可见性实践》 |
| | **问句式** | 3 条与关键词式重合 + **独有** SSRN 推荐系统**因果辨识**论文（`abstract_id=4915562`）→ **多召回 1 条方法更强的条目** |
| **R3**（数字技术/异化/主体性） | 关键词式 | 5 条，全为中文哲学—伦理批判文献（张成岗、成都理工学报、北理工学报、深大学报等） |
| | **问句式** | 4 条与关键词式重合，**独有** 1 条 2024 年国际期刊摘要（`10.1177/27523543241250133`，含期刊与 DOI） |

**3 轮统计**：重合 **13/27 位置 ≈ 48%**；问句式在 **3/3 轮**都有独有增补（+2 / +1 / +1），方向一致。

**机制解释**：T1 要的是**概念范围**（哪些研究属于「意向性/美学感知」「算法—自主性」这一族），语义改写把「用户感知」扩成 experience / appraisal / preference / bias 正是加分项；而引擎的共同命中集（**8/20 条**在 ≥2 轮中以不同字面出现）说明 exa 有一个稳定「核心集」，两种句式的差别主要在核心集之外的**延展方向**。

### 3.2 T2 × `tavily`：**三轮之后判据翻转**——问句式不劣化

**v1 原稿结论（已推翻）**：首轮曾见「关键词式返回可落卡量级来源、问句式漂向广义综述」，据此判 T2 应**豁免**语义化。**扩到 3 轮后不复现**：

| 轮次 | 句式 | 前 5 条特征 |
|---|---|---|
| **R1**（AIGC 用户感知/美学） | **关键词式** | 反而不理想：**2 条行业报告**（全球 AIGC 月报流量、21 世纪产业报告）+ 1 条乱码页面，量级数据与主题**不同轴** |
| | 问句式 | **2 条带明确数字量级**（67% 识别率调查、UNESCO 的 70%/60%/20% 量化）→ **本轮问句式更优** |
| **R2**（AI 论文产出规模） | 关键词式 | AI Index 2021 下载源 + 院刊论文构成 60%/17%/13% + 中国占比 39.8% + h-index 方法页 → **好** |
| | 问句式 | 同源再命中（**仅 1 条不同 URL**），并列论文占比表述为 23.2%/22.6% → **并列，无明显差异** |
| **R3**（平台经济/创作者收入规模） | 关键词式 | 高盛「2027 年近 5000 亿美元」+ 约 4% 创作者年收入超 10 万美元 + 47%/39% 不稳定比例 → **好** |
| | *（本轮未取问句式）* | — |

**判据翻转**：**R1 指向问句式更优、R2 指向并列**——3 轮里没有任何一轮支持「问句式降质」。「Tavily 改写会丢数值词」这一**机制假设**在实测中未产生可观测的召回损失（Tavily 对问句式返回的是**同源同根**的检索集，差别在**排序**与限定语吻合度）。

### 3.2c 唯一真差异：**指标名本身**（元数据类检索）——任何句式都无效

把「指标名」写进 query 并不能换来该指标。实测两次、两次都以**语义邻域**作答：

| 调用 | 期望 | 实得 |
|---|---|---|
| `search_papers("AIGC intentionality aesthetic perception measurement")` | 测量类实证 | **仅 1 条**且不相关（Jackson Pollock 绘画个展，《The Rhizome's Features…》） |
| `search_papers("AIGC aesthetic perception")`（同平台、少一个词） | 同族 | **8 条**（Semantic Scholar 5 / PubMed 3），含 `10.1109/CVPRW63382.2024.00640`、PMID 40807810、PMID 42092006 等**高相关**条目 |
| `search_papers("算法推荐 创作者 自主性 可见性 实证")`（中文概念组合） | 中文实证 | **0 条** |
| `search_papers("人工智能 论文数量")` | 关于 AI 研究**规模**的统计 | 返回「**关于 AI 的**教育/思政/刑事/体育类论文」——命中的是 `人工智能`，**丢弃了 `论文数量`** |

**判据**：「论文数量 / 被引频次 / h-index」这类**指标名**是**元数据属性**，不是可被相关性排序兑现的检索意图——它必须走①注册表/元数据直取（§4.1）或②LLM 在结果集上聚合，**换句式解决不了**。同批还暴露 `search_papers` 的一处**显著不稳定**：同 `search_papers` 工具、同主题，加一个修饰词即从「5/22980 条命中」塌到「1 条不相关」，中文概念组合则直接 0 条——**这对「文献计量方向以 `search_papers` 为正规入口」的既有指引构成反向证据**（建议单列核验，本报告只在 §4.5 登记）。

### 3.3 T3——不测不改

T3 的范式已在卡内落地（关键词式），且本批**没有**任何证据支持改动它。**不动的理由不是「没测」，是「已有规范且无反向证据」**——两者在报告里必须区分（照 `AGENTS.md` 的「『被提到』≠『做完』」同型纪律）。

## 4. 同批实测的另外三条硬事实（比范式动议更硬）

### 4.1 注册表直取整块缺失 = T2 的真实瓶颈

`domain_search` 在**全仓零提及**（`grep domain_search` 覆盖 `skills/**` 的 `*.md`：0 命中；SKILL.md 的工具映射区亦无）。实测三条：

| 调用 | 返回 | 对 T2 的意义 |
|---|---|---|
| `domain_search(openalex, "AIGC 意向性 审美感知")` | 3 条中文期刊成果，带 DOI、年份、`cited_by`、摘要可用性（如 `10.71411/rwxk.2026.v1i4.1397`、`cited_by 1`） | **一次调用给出 T2「文献计量方向」所需的元数据**，不必拼 API URL、不必 `web_fetch` 解析 |
| `domain_search(cninfo, "研发投入 年度报告")` | 返回真实公告 PDF 直链（`static.cninfo.com.cn/finalpage/2021-08-13/1210735288.PDF`） | 公告原文直取——现网 T2 只能靠 `web_fetch` 撞 |
| `domain_search(worldbank, …)` | ⚠️ 见 §4.3 | — |

**判据**：T2 卡的范围是「国家统计局、世界银行、CEIC、联合国数据、皮书系列、权威机构报告」（`:36`），而**这些机构在现网只有「搜到 → 抓」一条路，没有「按指标/注册号直取」的路**。这才是 T2 的可用性上限，与查询句式无关。

### 4.2 现网「语义被旁路」：`web_search` 实际走 bing

| 配置面 | 值 | 后果 |
|---|---|---|
| profile `cordis.patch.yml` → `web-search-free` 行（`dsh-free-search@0.8.10`） | `provider: bing` | `web_search` 由该插件提供，**走 bing（字面引擎）** |
| `~/.modsearch/config.json`（`@liustack/modsearch@5.10.6`） | `"engine": "exa"` | 只对 modsearch 自己的角色生效（读页 / X） |

### 4.6 病因核验（2026-10-15 主人裁决「都做」后补跑；**已定因**）

**方法**：同 query 重复 3 次（定抖动 vs 构造）＋ 逐词加长（2→3→4→5 词）＋ 中英对照 ＋ 拆词对照（去掉末词）。全部为免费调用，共 15 次、约 30 积分。

**① 可重复性：不是抖动，是确定性行为**

| query | 第 1 次 | 第 2 次 | 第 3 次 |
|---|---|---|---|
| `AIGC aesthetic perception` | S2 5/22980 + PubMed 3 = **8** | S2 **3/22980** + PubMed 3 = **6** | （同左口径） |
| `AIGC intentionality aesthetic perception measurement` | **1**（不相关） | **1**（同一篇不相关） | 同 |
| `算法推荐 创作者 自主性 可见性 实证` | **0** | **0** | 同 |

**判据**：同一 query 三次给同一结果（含那篇 Jackson Pollock 绘画论文），**排除「API 抖动」**。同时暴露另一件事：**返回条数其实是被工具上限截断的**（`max_results_per_source` 设 5 → 返回 8；设 3 → 返回 6；总数也跟着变），所以**平台上限（22,980 / 322 / 1,860）与返回条数是两回事**——报告 v1 曾把「5/22980 条命中」写成召回量级，措辞不严，此处更正。

**② 逐词加长：**「加一个词」不是「收窄」，而是**换了一个语义重心**

| query（逐词加长） | 返回 |
|---|---|
| `AIGC aesthetic`（2 词） | 6 条：AIGC 品牌艺术拟人化的**受众审美接受机制**、AIGC 城市雕塑的**审美认知与艺术接受**（SEM + 视觉内容分析）、AIGC 助设计教育的**审美判断**……**全部命中主题** |
| `AIGC aesthetic perception`（3 词） | 8 条：视频质量评估、观众感知评估、审美教育装置……**仍全部命中** |
| `AIGC aesthetic perception intentionality`（4 词） | 3 条：命中，但已收窄到「感知/质量」一线 |
| `AIGC aesthetic perception measurement`（4 词，**换一个末词**） | 3 条 → **漂到牙科**：`10.5336/dentalsci.2023-96812`（上颌前牙数字图像对牙科学生与非专业者审美感知影响的**问卷调查**）、正畸面部侧貌审美偏好（330 名被调查者） |
| `AIGC intentionality aesthetic perception measurement`（5 词） | **1 条，完全不相关**（Jackson Pollock 绘画的「块茎」特征） |

**③ 中英对照（同义查询）：**

| 语言 | query | 返回 |
|---|---|---|
| 中文 | `算法推荐 创作者 自主性 可见性 实证`（5 词） | **0 条** |
| 中文 | `算法推荐 创作者`（2 词） | 3 条，但**漂离主题**：AI 个性化推荐对消费者冲动消费、AI 影视镜头创作、生成式 AI 对跨境电商购买意愿——**全部与「创作者—算法张力」不同轴** |
| **英文** | `platform algorithm content creator autonomy empirical study`（6 词） | **3 条，全部命中**：Reddit 算法内容治理实证（`10.1287/isre.2021.0036`，42 引）、音乐流媒体创作者绩效实证、战时创作者「矛盾可见性」（`10.1080/10304312.2025.2507777`） |
| 中文 | `人工智能 论文数量` | 5 条，**主题漂移**：命中「人工智能」，**丢弃「论文数量」**（返回「关于 AI 的**论文**」而非「AI 论文的**规模**」） |

**④ 定因（一句话）**：**`search_papers` 的返回是「整个 query 串的语义重心邻居」，而不是「逐词命中的交集」**。

- 判定依据：5 词中文串返回的是「AI 推荐/消费者/电商」这一簇（它只抓住 `算法推荐`）；4 词英文串因末词 `measurement` 把重心推向了「用问卷测量审美感知」的方法学簇（于是给了牙科问卷研究）；5 词英文串的重心漂到无法解释的位置（Pollock）。
- **推论（这才是要紧的）**：它**不会报错、不会告诉你「我丢词了」**。所以 **0 条 / 1 条结果与「该主题确无研究」在输出上不可区分**。
- **为什么这对论衡是真风险**：T1b 补扫与 T2 文献计量方向都点名它作正规入口；调用方拿到 0 条 → 按流程走到 `02-数据检索-data-scout.md:72` 的「全部源拿不到 → Permanent Gap」/ `01-…:35` 的「该子主题 Permanent Gap」→ **「缺角论点降级为观点」**。**（静默假阴性的完整链条）**

**⑤ 可操作的判据（已按此落地到接入面 §2.1，见 §10.5）**：

1. **query 越短越稳**：2–3 个词是本品的最佳区间（2 词与 3 词都全命中）。
2. **不要用「测量/实证/研究/综述」这类方法学词去凑**——它们权重高、会把重心从主题推向方法学邻域（牙科问卷那条就是活例）。
3. **中文概念组合不可靠**：中文多词串要么 0 条、要么漂移；**同样意思用英文写**（实测 6 词英文全命中，5 词中文 0 条）。
4. **拿到 0 条 / 极少条时，必须怀疑是查询而不是缺口**：改短、改英文、拆词各试一次再判 Permanent Gap。
5. **指标名（论文数量 / 被引 / h-index）不要放进 query**——见 §3.2c。
