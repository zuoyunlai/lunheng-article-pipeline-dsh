## 1. 核实与决策（先核后改；决策都带理由）

### 1.1 §4.1 的三问——本轮**逐条答复**（报告要求「先答再动」）

| 问 | 答复 | 理由 |
|---|---|---|
| ① 是否把技能来源唯一化 | **唯一化 = 包入口**（`ctx.skills.register()`） | 论衡技能必须对**任意会话**可用（面板 / 斜杠命令 / 4 个原生只读工具都挂在包入口的 `apply` 上）；把技能收进某个 preset 会让「切了预设才有论衡」成为默认体验 |
| ② `!!js` 在 preset 平面的**运行期求值**是否已实测 | **未实测**（如实标注）→ 故**不**依赖它做新设计；退路写进文件头 | 本机 `--dump-config` 只打印声明行（`cordis.patch.yml:91-93` 已记录同一观测限制）。`dsh headless` 需 LLM key，本机缺（`DSH-集成方案.md` §八 第 3 步已登记） |
| ③ 是否接受 250 压过 300 | **通过「preset 不携带技能」从根上避开**——不是接受，而是让冲突不发生 | 包入口注册走 **runtime rank 250**（`@deepseek-ai/dsh-skill` 的 `RUNTIME_RANK`），`customSkillDirs` 走 **300**；同名技能**低 rank 静默顶替** ⇒ preset 自带技能「看起来没生效」且两处正文会漂 |

**据此的落法**：preset **只承载作用域收窄**（三档 subagent 工具从 profile 全局沉到 preset 层），**不携带技能**。`baseUrl` 那条写法**不用**（故报告 §4.1(b) 的争议在本包不适用）。

### 1.2 「名字」这件事——原先的唯一不确定点已结案

- 官方判定依据实测 = `@deepseek-ai/dsh-agent-presets` 包的 `discovery.js`：`COMPOSITION_FILE = 'agent.cordis.yml'`；缺该文件的目录按官方诊断「the directory still occupies the id」（**占了 id 却加载不了**）。
- 故：v18.61.0 那份 `agent-tiered/cordis.yml` **名字不落在契约上** ⇒ v18.99.0 报告 N3 的「本目录不是 preset」判断当时**正确**；v19.0.0 **改名到契约名**后契约面闭合。
- **诚实边界**：`examples/preset/` 在 `node_modules` 内，**不会**被自动扫描（DSH 只扫它配置的 preset 根）——要**放进/软链到你的 preset 根**才生效；本包**不**自动注册预设根。这条写进了 README 与文件头。

### 1.3 `!!js` 在 preset 平面的状态（分级陈述，不夸大）

- ✅ **许可面成立**：preset 经 `Include` 挂载（`dsh-agent-presets` 的 `mount.js` 里 `class PresetTree extends Include`、`pathToFileURL(preset.path)`），嵌套行的 `!!js` 在该行自己的 fiber 惰性求值。
- ✅ **官方实例在场**：官方自带标准预设的 `agent.cordis.yml` **正在用** `!!js process.platform === 'win32'`——官方不会 ship 自己加载器拒绝的写法。
- ⚠️ **本机运行期求值仍未做对照实验**（同 1.1 ②）。退路现成：不写 `agentOptions`，改用会话内 `list_subagent_models` + per-call 选模型（即 `modelSelectionSettings: true` 的用途）。

## 2. 工作台：借鉴了什么、不借鉴什么（主人指定参照）

**读懂参照物**：把 `web.yily.top` 的 SPA bundle 解出来读了「新建项目」表单与提交流程（实测字段名，非推测）：`title / words / lang / author_name / genre / tone / backend / structure_gate / citation_style / citation_mode / min_literature / t9 / journal_match / quality_gate / rescan / target_journal / journal_requirements / charts / deadline / priority / research_brief / writing_notes / must_cite / exclude_refs / retrieval_scopes / interactive`；文类选项来自服务端 `GET /genres`（每个 preset 带 `tone/t9/journal_match/citation_style/structure_gate/min_literature/end_sections`，选中即回显摘要）；`create(start:false)` → `uploadSources(text/data)` → `startProject` 三段式；`localStorage` 存 `lunheng.last_project_cfg`（「↺ 填充上次配置」）与 `lunheng.recent_projects`。

| 借鉴 | 落到本包 |
|---|---|
| **字段完备性**（可直接当 Phase 0 的覆盖基线） | 开工台取其中与论衡机制对应的部分；**一一对得上机制**（文类→文类档案 11 项上位选择、T9→T9 决策树、期刊匹配→Top3 期刊、质量门→G14/QLT-6、补扫→Phase 1.5、结构门→M-Form、图件→SVG 链路） |
| **「文类 = 配置包」+ 选中回显摘要** | 论衡**已有等价真源**（`文类档案.md` 的 11 行表）；开工台内置**受钉派生副本**（见 §3） |
| **渐进披露 + 「跟随文类」为默认空值** | 五段式（基本 / 素材 / 检索与同意 / 高级 / 预览）；高级区一律「留空＝跟随文类」 |
| **「↺ 填充上次配置」** | `localStorage['lunheng.workbench.last_cfg']` |
| **三开关式检索范围**（默认全选，全关=只用投喂） | 保留为其可操作面；**同时保留论衡的明文「外发同意 4 选 1」必填项**（`01-任务简报.md` 头部的审计追溯不能丢） |
| **关键控件稳定标识** | 开工台控件带固定 `id`（`lunheng-workbench`）与可断言文案（桩渲染用例按文案定位按钮） |

| **不借鉴** | 原因 |
|---|---|
| 「运行后端」四选（standalone/openclaw/claude_code/langgraph） | 论衡是纯 skill，跑在 DSH 里；无此概念 |
| 直写 API（axios → `/api/*`） | **本机客户端服务目录里没有 `connection`**，插件调不到 CLI；照抄会挂死（报告 §4.2 的判断成立，本批实测确认） |
| 「启动 write →」提交即跑 | 论衡 Phase 0 是**人在环硬闸**（`SKILL.md` §触发：不得直接 spawn 或写文件）；开工台**只填草稿、永不 `submit()`** |
| 服务端 `GET /genres` | 浏览器读不到技能目录文件；本包用**受钉的内置副本**（见 §3），不新增 host 读面 |
| 「人在环（OOH）」开关 | 论衡四门（P0/P2.5/P3.5/P5）**不设可省任一门**，做成开关会诱导绕过 |

**论衡特有、参照物没有的两项**：**项目名**（`[\w\-一-鿿]{1,32}`——要建 `run/<项目名>/`，而参照物由服务端生成 id）与**工作区根**（复用面板已选根）。

**产物形态的关键选择（与参照物的根本差异）**：参照物把表单**直写**为 CLI 参数；论衡侧唯一通道是「把文本送进输入框」，故开工台产出**结构化 `- 键: 值` 块**（不是散文），目标是让主控**零歧义**照抄进 `阶段确认-Phase0.md` §6 与 `01-任务简报.md` 头部——散文式口述会丢字段，而每个字段下游都有机检。

### 顺带修复：hover 类样式从未生效（真 bug）

- **病灶**：`apply` 里注入的 CSS 把 `T(...)` 的**实参整体写成了字符串字面量**（拼接的是那段源码文本），注入结果是 `border-color:T(<token>, <兜底>) !important` —— **浏览器把整条声明丢弃** ⇒ 自 v18.92.0 起该 hover 微抬升**一次都没生效**（静默失效，正是本包最反感的那类）。
- **修法**：改为真调用；**回归钉**：注入的 CSS 必须含 `var(--dsw-alias-` 且**不含** `T(`。
- **附带**：这次修复也把「注释里的示例写法」纳入了同一约束（我第一次写的注释含单参 `T('…')` 与裸色值，被既有源码级扫描连红两次——已改成不含可疑字样的描述）。**这两次红是我自己的门抓的**，如实记档。
