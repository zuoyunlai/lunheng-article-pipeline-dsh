## 一、本批解决的真问题：人在环此前是**单向**的

审计（P2-2）的结论不是「缺两个命令」，而是一条结构性不对称：

| 方向 | 机械层 |
| --- | --- |
| 证明「主人同意过」 | 登记表 + A7 + 回执账本 + 会话日志，**四层** |
| 让主人**直接**推动流程 | **零层**——主人在对话里说话，主控转录成 §6 五字段与回执 |

转录这一步没有任何机械约束。实测中，项目里的 §6「主人原话」比主人真实发言更长、更顺、更像一个结论。这不是主控「作弊」，而是**缺少对照物**：没有一份独立的、主控改不了的原文。

于是本批把两种主人动作做成可核文件：

- `/lunheng -gate <项目> <Phase> --approve|--reject [--note "…"]`
- `/lunheng -abort <项目> [--reason "…"]`

机械层 = 新增的 `skills/lunheng-commands/scripts/owner-cli.mjs`（9,929 B），**只写两处**：

1. `run/<项目>/audits/gate-receipts.jsonl`——追加一行，`rawAnswer` 就是主人在命令行打的字；
2. `run/<项目>/audits/abort.json`——中止标记（含 `reason` / `abortedAt` / 首次中止时间）。

### 刻意不代劳的三件事

1. **不写 §6**：`-gate` 之后主控仍须把同一句 `rawAnswer` **逐字**回填 §6「主人原话」，否则 A7 报「不相容」。账本由主人写、§6 由主控写，**两者字面相等**才叫「未改写」——如果 `owner-cli` 顺手把 §6 也写了，这个脚本就变成了主控的第二支笔，机制白做。
2. **不改 `status.md`**：状态机是主控的独占写面（子代理都禁 edit，何况一个 CLI）。
3. **不删任何产物**：`-abort` 只落标记。中止 ≠ 回滚——删产物会让 A7 与账本对不上。

### 边界（如实声明）

- `-gate` **不校验主人是否真的看过产物**。它记录的是「谁在什么时候说了什么」，防的是「主控替主人写字」，**不防「主人不看就放行」**。后者是纪律，机器给不了保证——写进「未做」而不是假装解决了。
- `-abort` 不杀进程、不中断已提交的远端任务，它只落标记；主控必须在**下一个门边界**停下并如实告知。

## 二、为什么 `round` 与 `rawAnswer` 是承重字段

- `round`（同门第几轮）= 该门已有回执数 + 1，与 `handoff-check` 的 `_key = gate#round` 对齐。退化就会让「第二轮驳回」被记成第一轮，账本与 A7 的编号对不上，届时门会报「不相容」而没人知道是谁错了。
- `rawAnswer` 是 P2-2 的**全部价值所在**：它是唯一一份主控改不了的原文。E2E 测试直接断言它 `===` 主人打的字（含中文标点）。

## 三、两条纪律（我提的建议，主人批准）

### 1. 禁止 `git checkout -- <file>` 回滚未提交改动（写进 `AGENTS.md` §文件修改操作约束 第 2 条）

**事实依据（本会话实测）**：v19.27.7 批里我用 `git checkout -- docs/quick-facts.md` 撤一处自己刚改错的文字。该文件**未提交**，`checkout` 的语义是「回到上次提交」——直接把 19.27.4–19.27.6 三轮累积（主规则 42、版本头、㊷ 登记）一起抹掉。发现方式是重跑一致性门报出「41 类主规则」「版本 v19.27.3」。

**正确做法**：要撤单次改动，从 §1 的 `.bak` 恢复，或再写一次**反向精确 `edit`**。

**为什么值得写进手册**：这条纪律的失效是**静默的**——checkout 成功、无报错、文件看着「干净了」，只有在门报出口径漂移时才暴露。这类「看起来在缩小影响面、实际在扩大损失」的操作必须显式禁止。

### 2. 派生数字不要手抄：`scripts/budget-recalc.mjs`（只读）

**事实依据**：P2-4 批我在写预算理由文本时手工算过三样东西（实测字节 / 定案 ① 公式上限 / 余量），并且**算错过一次**——`DOC_BUDGET` 的条目形状是数组 `[上限, 长期目标, 理由]` 而不是数字，首版脚本写成 `v - n` 得出全 `NaN`；更早还混过一次量纲（「常驻集」走的是 `ALWAYS_RESIDENT` + `ALWAYS_LIMIT`，**与单文件上限不是同一把尺**）。

判据：**手抄的派生数字一定会漂——那就别手抄。**脚本口径与卫生门第 ⑨ 条严格同源，一条命令输出三数：

```
node scripts/budget-recalc.mjs          # 人读：常驻集 + 余量最小的 12 个文件
node scripts/budget-recalc.mjs --json   # 机读
```
