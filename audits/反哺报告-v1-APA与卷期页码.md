## 一、背景与动机

### 1.1 调研发现（Ai4Scholar 借鉴点）

Ai4Scholar v2.9.4–v2.9.5 连续两版强化引用元数据：

- **v2.9.4（2026-03-19）**：「📑 引用格式优化 — 文献自动标注引用输出包含完整的卷号、期号、页码信息」
- **v2.9.5（2026-04-07）**：「✏️ 写作编辑器增强 — 文献引用格式改为 APA 标准圆括号 `(Author et al., year)`」

这两点对学术投稿质量是**直接的高 ROI 改进**——审稿人最常挑刺的就是参考文献元数据不全。

### 1.2 论衡现状盘点

| 维度 | 论衡现状 | Ai4Scholar 对照 | 缺口 |
|------|---------|----------------|------|
| 引用格式选项 | GB/T 7714-2015（默认）/ APA / MLA / 内联 / 其他（v2.2.4） | APA（默认）/ IEEE / Vancouver / Nature / numbered（15 种） | 论衡已有 APA 选项，但默认是 GB/T |
| 卷/期/页码完整性 | 无强制要求；M-Form-2 只扫文末节存在性 | 强制完整（v2.9.4） | 论衡缺 |
| auto_cite 调用约定 | T5 写手派发话术自由发挥触发 | 标准化的 auto/manual 双模式 + IF/JCR 筛选 + 推荐数 | 论衡缺统一约定 |

### 1.3 改进目标

1. **统一 auto_cite 调用约定**——主控在 T5 派发话术中固定引用方式、字段、失败处理
2. **任务简报加 v2.5.x 选项**——主人可显式选择"APA 优先输出 + 卷期页码完整性强制"
3. **M-Form-2 扩展卷期页码分支**——机械门核验每条 `[Lxx]/[Dxx]/[Cxx]/[先NN]` 元数据完整性

## 何时调用
- **T5 写手 v1 完成后**：对每段引用做完整性检查，缺卷期页码 → 触发 Phase 1.5 补检索

## 调用参数（与 DSH 原生 auto_cite 工具对齐）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| field | "computer science" | 学术领域倾向（从任务简报 §论文类型 自动映射） |
| min_citations | 5 | 最小引用数（仅 auto 模式有效） |
| citation_style | 任务简报 §引用格式 默认值 | APA / IEEE / Vancouver / Nature / numbered |
| exclude_preprints | true | 排除预印本（投稿论文场景） |
| exclude_conferences | false | 不排除会议论文 |
| year_preference | (无) | 优先年份（如 2024） |

## 失败处理

- **API 积分不足** → 自动降级到自维护 [Dxx]/[Lxx] 库，不抛错；在交接报告标「⚠ auto_cite 降级」
- **找不到匹配文献** → 输出「⚠ 该论点无匹配真实文献」，T7 标 P1
- **部分引用有卷期页码，部分无** → 报告「差异覆盖率 X%」，T8 终检记录偏差
- **auto_cite 推荐的引用与已有 [Lxx] 重复** → 提示「已有相同文献 Lxx」，避免重复入卡

## 与论衡已有机制的对齐

- **引用模式锁定**（v2.2.10）：auto_cite 输出必须遵循任务简报 §引用模式（编号 / 内联）
- **数据信任级别**（v2.2.1）：auto_cite 推荐文献的信任级别由其数据源决定（Semantic Scholar = 已发布 / 二手转引 = 需回溯）
- **三角验证**（v2.3.7）：auto_cite 不替代 T1 文献检索；仅在 T5 v1 后做"补强"扫描

## 跨工具边界

auto_cite 调用 DSH 原生 AI4Scholar 工具（消耗积分），主控须在任务简报 §v2.5.0 可选项 显示预估积分成本。

## 四、风险与回滚

| 风险 | 缓解 | 回滚 |
|------|------|------|
| auto_cite 调用积分超支（每项目 ~50-100 积分） | 任务简报 §v2.5.0 显式标成本；主人勾选前知情 | 取消勾选 → auto_cite 不调用，T5 自行写卷期页码 |
| M-Form-2 v2 误报（正则太严） | T7/T8 显式声明证伪（v18.0.0 P0-2 双字段语义） | 删除 M-Form-2 v2 段，恢复 M-Form-2 v1 |
| auto_cite 与 T1 文献检索重复 | 主控 Phase 4.5 前显式声明"auto_cite 推荐 vs 已采纳" | 关闭 auto_cite，T1 检索仍有效 |
| 中文期刊卷期页码格式不规范 | 正则兼容 "vol.X (no.Y): p.Z-Z" 与 "卷X 期Y: Z-Z" 双格式 | 主人 apply 时手动扩正则 |
