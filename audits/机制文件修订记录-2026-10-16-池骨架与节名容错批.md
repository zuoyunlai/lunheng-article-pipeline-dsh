## 一、⭐ V5b：**甲案已试，并被回归网当场否决**（本批最该留档的一条）

### 1.1 病灶（来自验证记录 V5b）

`pool-query` 在池已有 46 条时仍打印「✅ 已创建素材池骨架」——与同一行的「（现有 46 条）」**互相打脸**（与审计 **P1-2** 同族）。

### 1.2 甲案（我先选的那条）与其**否决**

- **甲案**：让 `pool-extract` 落盘前调 `ensurePoolSkeleton(poolDir)` ⇒ 池结构（四个池 JSON + `raw/` + `transcripts/`）**一次成型**，后续 `pool-query` 的 `created` 自然为 false。
- **实测结果**：**被 `tests/scripts/pool-extract.test.mjs` 的 P1-3 用例否决**，`fail 1`。该用例明文钉：

  > `assert.equal(baksIn(poolOf(ws), 'literature.json').length, 0, '首次写盘目标不存在 → 无备份可做（如实，不是缺陷）')`

  甲案在**真正写盘之前**就把 `literature.json` 建成了**空池** ⇒ 随后 `writeWithSafety` 认为「目标已存在」⇒ **首次写盘也留 `.bak`** ⇒ 该断言由 0 变 1。
- **判据（本批最重要的结论）**：**「池结构不完整」是可自愈的正常中间态，不是缺陷**。为消灭它而**预建目标文件**，代价是**污染 P1-3 的「首次写盘」语义**——**得不偿失**。
- **处置**：甲案**整体回滚**（`pool-extract.mjs` 的代码已回到原状，`git diff` 只剩 **6 行注释**）；改用**乙案**（下节）。

### 1.3 乙案（落地）= 只改**消息判据**，不改数据面

- **改法**：`pool-query` 在调 `ensurePoolSkeleton` **之前**先判「池文件此前是否存在」，据此分两支——
  - `created && !poolExistedBefore` → 「✅ 已创建素材池骨架…」（**真·新建池**，原消息保留）
  - `created` → 「· **池结构此前不完整，已补齐缺失的池文件与目录**（raw/ · transcripts/ · 空池 JSON）——既有条目未受影响」
- **真实复现验证（复跑验证记录 V5b 的同一夹具）**：

  ```
  · 素材池: <…>（现有 46 条）
  · 池结构此前不完整，已补齐缺失的池文件与目录（raw/ · transcripts/ · 空池 JSON）——既有条目未受影响
  查池结果: 命中 4/46 条（关键词 ["威慑"]）
  ```

  ⇒ **矛盾读数消失**，且「补齐」这一动作**如实显形**（符合该仓「不静的降级」）。
- **乙案为什么够**：V5b 的**全部**病灶就是「消息声称 ≠ 池实况」；数据面（池里有哪些文件、何时建）**本来没有缺陷**。

## 二、V6c：M3 数据源列的**节名容错**

- **病灶**：`09-审稿` 的 M3 数据源列写「`analysis/分析大纲.md`「**识别策略与反事实**」段」，而真实项目（`台海可预测性边界`）里该内容叫 `## §6 分析框架与因果识别策略` / `### §6.2 因果识别策略` / `§9.1 反事实` / `§9.2 可证伪预测` ⇒ **按字面找不到节 → 可能误判「缺声明 → P1」= 假 P1**。
- **改法（两处消费面 + 一处判据护栏）**：

| 落点 | 改动 |
|---|---|
| `09-审稿` M3 **数据源列** | 「初稿方法节」→「初稿的**方法声明**（**可在方法节或引言段**）」；「大纲「识别策略与反事实」段」→「大纲中**声明识别策略的节**（**节名各项目不同**：常见「识别策略与反事实」/「分析框架与因果识别策略」/「因果识别策略」——**按内容定位，勿按字面节名**）」 |
| `09-审稿` §T9-m 的 M3 注记 | 追加「**⚠️ 数据源的节名容错**」：按字面找不到节 **≠ 缺声明**，须按内容再定位；确无才判 P1（**防假 P1**）；节名不统一属「契约 vs 实况」缺口，**不构成 P1** |
| `05-写作` §4 ① | 「输入取自 T4 大纲「识别策略与反事实」段」→「输入取自 T4 大纲中**声明识别策略的节**（**节名各项目不同**……**按内容定位**，勿按字面节名）」 |

> **为什么必须同时改 05 卡**：写手（T5）与审稿人（T9-m）是**同一份大纲的两个消费者**——只改一处会造成「审稿找得到、写手找不到」的第二处不一致。
