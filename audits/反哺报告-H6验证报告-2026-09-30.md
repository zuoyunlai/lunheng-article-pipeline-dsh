## §一、§八 第 1 步实测（**已成功**）

```yaml

# 验证 §八 D4 配方「普通行按 id 覆盖既有行」是否真生效
- id: tool-subagent-retrieval
  disabled: true
- id: tool-subagent-strong
```

| `tool-subagent-audit` 行出现次数 | 1 | 1 ✅ |

**结论**：**§八 第 1 步配方验证成功**——「profile 层按 id 覆盖既有行」是真生效的（patch 加载无语法错，三行都加上 `disabled: true`）。这正是 DSH-集成方案 §八 "普通行按 id 覆盖既有行" 的预期。

## §二、§八 第 2 步实测（**部分冗余，部分仍需仓库改动**）

### 2.1 实测问题

§八 第 2 步配方：在**新的 preset 目录**写 `cordis.yml`，三档 subagent 工具行加 `modelSelectionSettings: true`。**目的**：让该预设作用域内的会话能用 `list_subagent_models` 工具。

### 2.2 实测发现 — 关键事实

我跑了 `dsh --profile web --dump-config`，**全文搜 `modelSelectionSettings`**：

```
974:    modelSelectionSettings: true   ← dsh 自家 subagent 工具
1156:   modelSelectionSettings: true   ← dsh 自家 subagent-fork 工具
1420:   modelSelectionSettings: true   ← dsh 自家 subagent-codex 工具（disabled 状态）
1534:   toolName: subagent_retrieval   ← 论衡的子档（**无** modelSelectionSettings 字段）
```

**3 个 `modelSelectionSettings: true` 全部位于 dsh 自带的 subagent 工具**（`@deepseek-ai/dsh-tool-subagent` 包的默认配置）。**论衡的三档 subagent 工具（`subagent_retrieval` / `strong` / `audit`）完全没有 `modelSelectionSettings` 字段**。

### 2.3 这意味着什么？

| 期望 | 现状 | 评估 |
|---|---|---|
| dsh 自家 subagent（`@deepseek-ai/dsh-tool-subagent`）的工具 | 已有 `modelSelectionSettings: true` ✅ | dsh 0.1.7-rc.2 默认开 |
| 论衡 patch 行 `toolName: subagent_retrieval` 等（**真源 roles = T1 文献 / T2 数据 / T3 案例**）| **没有** `modelSelectionSettings` 字段 ❌ | **必须改仓库 patch 才会有 `list_subagent_models`** |

**关键结论**：
- dsh 0.1.7-rc.2 上**`list_subagent_models` 工具已经天然存在**（来自 dsh 自家 subagent 包）—— 这意味着 **§八 第 2 步配方（"开 `modelSelectionSettings:true`"）的目标在 dsh 0.1.7-rc.2 上已经冗余达成**。
- **但**：论衡的 `subagent_retrieval` / `strong` / `audit` 是**独立于 dsh 自家 subagent 的另一组工具**，且本机 patch 没给 modelSelectionSettings——它们**不会**自动启用 `list_subagent_models`。
- §八 第 2 步配方（在 preset cordis.yml 加 `modelSelectionSettings: true`）—— **目的让论衡三档工具继承 modelSelectionSettings**——这个目标**必须在论衡 cordis.patch.yml 改**（写新 preset 目录属于改动机制文件）。

### 2.4 因此

**§八 第 2 步配方没有"完全冗余"**——它确实能让"论衡的三档 subagent 工具在 preset 内启用 `list_subagent_models`"。**但这个改动属于仓库机制文件**（`examples/preset/<new-name>/cordis.yml`），按 AGENTS.md §机制文件写保护 需要主人**显式授权**才能落地。
