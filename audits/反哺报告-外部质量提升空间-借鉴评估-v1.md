## §零、结论摘要

外部文档是一份**质量纵深路线图**（7 大空间 + 优先级矩阵 + MVP + v4.0 愿景），其**问题诊断与我方高度同源**（方法透明 / 理论创新 / 跨学科 / 文献时效 / 多稿 / AI 披露 / 对抗评审），但它写于**另一条血脉**（OpenClaw 线 v2.12.74），与本地 DSH 线并非同一套路径、版本号与执行模型。

**总判定：只借鉴「诊断与判据」，不照抄「路径与形态」。**

| 类别 | 项数 | 一句话 |
|---|---|---|
| 采纳（真缺口，本地无对应物） | 3 | 理论贡献三层声明 / **质性研究的因果识别工具箱** / 人类决策链汇总 |
| 采纳-改写（有想法但形态不合本地架构） | 3 | AI 痕迹「按章定位表」替代密度热力图 / 投稿前最新进展补扫 / 跨学科融合点（可选字段） |
| 采纳（参谋性质、不入闸门） | 1 | 对抗性「立场 / 国际」审稿人可选视角 |
| 驳回 / Backlog | 4 | 多稿协同（架构冲突）/ 新增 6 份真源文档（与文档瘦身反向）/ v4.0 长期愿景（超插件边界）/ KPI 式验收（不可测量） |

**最高性价比三项**（详见 §三 A 档）：
1. **质性研究的因果识别工具箱**（process tracing / congruence / 反事实 / 最相似-最不同系统）——本地 `methodology-check.mjs` 的 7 参数是**定量向**（样本量/统计模型/随机种子），`structure-check --humanities` 更会**豁免 Methods 节**；而国关/政策/案例研究恰是论衡主战场 → **这是本地最实的缺口**，且它同时也补上外部文档的「反事实推理」与「失败条件/可证伪预测」。
2. **理论贡献三层声明（概念 / 机制 / 预测）+ L1-L4 层级判定**——本地只有「主人洞察的 理论贡献 vs 观点来源」分类与 G7「与先行者差异点」，**没有创新层级的判定标尺**。
3. **人类决策链汇总**——四张确认单 + `handoff-check --require-gates` 已把证据留在盘上，只差「汇总成一条链」写进交付说明。

## §三、采纳清单（含落地位置与成本）

### A 档 — 采纳（真缺口）

#### A1 质性研究的因果识别工具箱 + 反事实 + 可证伪预测
- **来源**：外部空间 1 的 D3（因果识别策略 4 选 1）+ M5/M6/M12 判据。
- **为什么是本地最实缺口**：本地 `methodology-check.mjs` 的方法节参数是**定量清单**（样本量 / 抽样方式 / 变量定义 / **统计模型** / 超参数 / **随机种子** / 软硬件环境，≥4 项）；`structure-check.mjs --humanities` **直接豁免 Methods 节**。而论衡的主战场（国际关系 / 政策 / 行业分析 / 案例型论文）大量使用案例研究法 → **方法节要么按定量清单硬套、要么整节免检**，两头都不对。
- **落地位置**（不新增文档）：
  1. `references/agents/09-审稿-peer-reviewer.md` §T9-m **M3「因果推断合法性」**增识别策略子项：`process tracing`（过程追踪）/ `congruence testing`（一致性检验）/ `counterfactual`（反事实）/ `most-similar / most-different system`（比较设计）/ 统计推断——**要求声明「用了哪一种」**；
  2. `references/agents/04-分析-analyst.md` §大纲模板「原创性声明」邻位增**「识别策略 + 反事实条件 + 可证伪预测（F1-Fn）」**三行（案例研究型项目必填）；
  3. `references/agents/05-写作-writer.md` 铁律：案例研究型论文须有**至少 1 处显式反事实推理**（「若无 X，则 Y 不会发生」）+ **≥1 条可证伪预测**；禁止把相关性写成因果（本地 `_lib/causal.mjs` 已做**三档因果词守恒**，此处是它的语义侧补充）；
  4. **可选机械化**：`structure-check.mjs` 增 `--qualitative` 档（自有命名空间前缀，如 `QS-`），在 `--humanities` 下也要求「研究设计段」在场——**须新开命名空间，不得复用 M 门编号**（本地已有 M-Form-12 撞号教训，见 `规范-机械门对照表` §命名空间）。
- **成本**：卡 + 大纲模板改动 ≈ 半天；若加 `--qualitative` 档 ≈ 1 天（含 tests）。

#### A2 理论贡献三层声明 + L1-L4 层级判定
- **来源**：外部空间 2 全文（概念层 / 机制层 / 预测层 + L1 应用 / L2 拓展 / L3 创新 / L4 范式）。
- **本地现状**：有「差异点」（是否重复）与「洞察分类」（贡献 vs 观点来源），但**没有「创新到哪一层」的标尺**。G7 只能回答「有没有抄」，不能回答「有没有创」。
- **落地位置**：
  1. `references/templates/任务简报-template.md`（+ lite）：主人洞察段增可选字段「**理论贡献层级自评**：L1/L2/L3/L4」；
  2. `references/agents/04-分析-analyst.md`：大纲「原创性声明」段增**理论贡献三层三问**（概念层：造了什么新词、精确定义、与既有概念边界？机制层：新因果链的变量 + 触发条件？预测层：什么会/不会发生、如何验证？）——**只要求集中一处**，不要求「每章末段」（后者会造八股，与本地「删优于改」纪律相悖，**此处对外部方案作降级处理**）；
  3. `references/agents/05-写作-writer.md` 铁律：禁止笼统「本文有创新」；承重章节须能指回三层中的具体一层；
  4. `references/agents/06-批判-critical-companion.md` **C3 理论假设审查**增「L1-L4 层级判定」攻击项；
  5. `references/agents/09-审稿-peer-reviewer.md` §1 原创性：**不动维度名与 1-5 制**，仅把 L1-L4 映射进既有锚点（3 = 应用/拓展既有框架；4 = 新概念或新机制；5 = 新研究范式）。

- **本地现状**：留痕**已有且已机械门化**——四张 `阶段确认-<阶段>.md` §6（主人回复原文 + 时间）+ `handoff-check --require-gates`（缺 → exit 20 / 字段不合 → exit 21）+ Phase 3.5 `[C-主NN]` 洞察条数与类型。**缺的只是「汇总」**。

#### B4 AI 痕迹「按章定位表」替代「段落级密度热力图」
- **来源**：外部空间 6 的 D1。
- **必须改写的原因**：外部方案给每章一个 `0.65` 式**密度分数**——① 该数字无测量基础（LLM 不具备校准的概率输出），② 与本地两条铁律直接冲突（「机械只做守恒、不做强度判定」的 `_lib/causal.mjs` 设计原则；M 门对「图上数字无出处」判 P2），③ 一旦写进**投稿版 AI 声明**，等于向审稿人提交不可复现的量化证据（伪精确，反成风险）。
- **本地形态**：`references/templates/G14检测报告-template.md` 增**「按章命中定位表」**：章名 ｜ 该章字数 ｜ 命中的 8 类中的哪几类 ｜ 命中条目 + 段落/行号。**只报可核查的事实，不出分数**。
- **成本**：≈ 1 小时。

## §四、与本地架构的冲突清单（照抄会踩的坑）

1. **六维契约是硬门**：`M-Exist-6` 逐字抓六维名 + `x/5` + 总评分 = 六维和。**外部「升 7 维 / 改 10 分制」= 直接 P0**（09 卡已记载：主控自创维度名曾被判「6 维 0/6」P0）。

4. **零 exec 不成立**：本地有 23 个随包脚本；外部「因零 exec 只能走 web_search 间接」的绕行方案在本地**既非必要也不最优**（见 §五）。
5. **参谋 vs 闸门的分野**：外部把「攻击清单 → 防御清单 → 通过率」当作可驱动修订的产物；本地已有明确教训（T9 判 major 不得被迫多跑一轮）——**对抗性产出只能进参谋区**。
