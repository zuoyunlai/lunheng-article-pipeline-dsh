## 三、要件：定了（并发现两处规范不等价）

**要件真源 = `01 卡 §卷期页码双写契约`（v18.9.0 实战反哺）**：

## 四、阈值：**刻意不设**（并说明为什么）

旧文档写的「卷期页码完整率 **≥90% / ≥95% = Pass**」（`audit-checklist-quickref.md` §G15）**从未标定**，且：

1. 实测完整率 **59% 缺字段**——95% 那条线会让**所有历史项目永久判红**；
2. 该比值同时受**两个自变量**影响：**契约新旧**（卷期页码契约自 v18.9.0 才有）与**模式开关**（全库 1/25 启用）。任何固定百分比都只是把这两个变量混在一起的一个数。

故本项的判级口径 = **只出候选清单**（逐条列出缺字段的 `[Lxx]` + 缺哪一项），严重度**只到 P2**；**完整率只作信息呈现**（`evidence.rate`，**分母只含类型可判条目**——判不出的不该被算成不合格），**不参与判级**。旧文档的 ≥90% / ≥95% 两处阈值**本批删除**。

**覆盖面的如实声明**：类型判不出的条目**不判罚**，并如实计入 `evidence.untyped`（不假装覆盖面完整）。

## 五、两次**实测返工**（本批最值钱的教训）

### ① 首版的模式判定在真实项目上产生了成组假阳性

首版按「简报里出现 `引用数量与质量控制` 或 `卷期页码完整`」放行。实测 `数字社交-关系重构` 的简报原文是：

> `- ☐ **APA 优先输出 + 卷期页码完整性**：默认关闭（保留 GB/T 7714-2015 为唯一引用格式）；若启用须主人二次确认`

**方框是未勾选的（☐）、明写「默认关闭」**，而字面匹配照样放行 → 对一个**从未启用该模式**的项目产出 **6 组 P2 候选**。

**判据：匹配到标签 ≠ 匹配到启用状态。** 这与本仓既有判据同族（「任何按字面扫描的门都会把『引述被纠正内容』的句子当成那内容本身」）；也与 `M-Exist-9` 刻意不判 G15 的理由一致（那道门看不到简报，判了就会对未启用的项目假阳性）。

**修法**：模式开关改为 **CLI 显式旗标 `--qlt`**（同 `structure-check --humanities` / `handoff-check --require-gates` 的先例）——由**读得到简报语义的调用方**（主控 / T7）显式传。未传 → `N/A`。

### ② `N/A` 与 `SKIP` 必须分清（否则 exit 0 不可达、质量分凭空漂移）

模式未启用时若沿用 `SKIP`（原语义：`checked: false` → 计入 `skipped` → **exit 3**），后果实测为：

- **全库 24/25 个项目**都会被推成「须人工复核」——噪声式假阳性；
- `g-audit-check` 的 **exit 0 事实上不可达**（本仓多处以 exit 0 为「全项合规」的断言会随之失效）；
- `quality-score.mjs` 的 G 项机检分量分母用 `cs.length` → **每个未启用该模式的项目凭空被扣 1/6 分**，且文案把 `N/A` 误报成「缺输入」——**质量分基线整体漂移**。

**修法**：新增语义 **`N/A`（`applicable: false`）= 按模式不适用**——**不进 `skipped`、不改变退出码**（独立计数 `overall.na`）；`quality-score` 的分母改为「适用项数」。**SKIP（适用但缺输入 → exit 3）与 N/A 的边界**写进 `SKILL.md` 脚本条目、`07 卡`、`quickref`、`审计报告-template`。

## 六、回归网 + 反向自证

`tests/g-audit-check.test.mjs`（13 → **18** 用例）新增 5 条：① 模式未启用 = N/A 且 exit 0（与 SKIP 分清）；② **「默认关闭」假阳性回归**；③ 传 `--qlt` 才真跑、缺字段判 P2、齐备判 PASS、完整率只作信息；④ **四种真实排版都要认**（含合并标签 → 类型不可判 → 不判罚）；⑤ 用**历史上真实出现过的缺字段写法**撞门（`[M]` 有 DOI 无 ISBN / 中文译著两缺）+ 传了 `--qlt` 却无卡 = SKIP。

**反向自证 5 个变异**（`%TEMP%\g41-reverse-proof.mjs`）：

| # | 破坏形态 | 结果 |
|---|---|---|
| RP1 | 模式开关退回「默认放行」（`qlt = true`） | **红**（两条用例） |
| RP2 | `N/A` 退回计入 `skipped` | **红**（两条用例） |
| RP3 | 类型推断去掉左边界守卫 | **未红 → 查明为「不可达变异」，见下** |
| RP4 | 候选严重度抬成 P1 | **红** |
| RP5 | 期刊 DOI 检查失效 | **红** |
| — | 每个变异后复原 | **逐字节一致**；复原后 18/18 绿 |

**RP3 未红的根因（已实证，不是推断）**：类型判定里 `LABEL_MIXED`（`出版X/期刊` 合并标签）在 `LABEL_J` **之前** `return null`，因此真实存在的那一种合并标签**根本走不到左边界那一步**。用**双变异**（同时去掉 `LABEL_MIXED`）证明守卫确实在挡（此时 `typeOf` 返回 `J`）。处置：把该条注释从「否则会被误命中」改写为**「纵深防御，不是承重规则」**，并把 RP3 登记为不可达变异。

> **新增的可迁移判据**：**变异不红时，除「门太弱」与「自证脚本写错」外还有第三种可能——变异不可达（被前序规则的优先级遮住）**。此时正确的动作是**改注释 + 登记**，而**不是**为了让自证好看而伪造一个可达的破坏形态。

## 八、边界（如实）

- **不判「字段对不对」，只判「字段在不在」**——引用真实性仍归 **G1**（T7 + 抽验规则）；本项只把「缺字段」的条目挑出来。
- **类型判不出就不判罚**（43/314 = 13.7%）：合并标签与无类型线索的条目**不进判罚面**，只如实计入 `evidence.untyped`。**覆盖面不假装完整**是这一项的设计前提。
- **本批未把 `--qlt` 接进 `quality-score`**：它读不到简报语义，故 G15 在该分量里恒为 N/A（按 5 项计分）——**这是有意的**，宁可少算一项，也不让模式判定退回到「按字面猜」。
- **语料仍是纸面契约的那一端**：`01 卡 §卷期页码双写契约` 的下游义务（T1 采集时写齐）没有运行时门，本项只在 T7 阶段**事后**把缺字段的条目挑出来。
