## 18.75.1 — 2026-10-04

> **性质**：**字体栈批（反哺报告-v7 **F-19 结案**）**。主人 2026-10-04 逐项裁定：选「**A. 只补跨平台衬线候选，不改调性**」＋「**单开小批**」＋ 范围「**图件 + 正文 `md2html` 同批改**」。
> **验证**：**全量 737/737 全绿**，六门全绿（`consistent` / `surface`(STRICT_WARN=1) / `hygiene` / `link` / `closeout` / `no-write`：5 步全 exit 0 且仓库 465 文件逐一哈希未变）；专项 `figure-template` **5/5** / `md2html` **5/5**。

**病根（F-19）**：模板字体栈写作 `-apple-system, 'PingFang SC', 'Noto Serif CJK SC', 'Source Han Serif SC', serif`，而本机实测（`%WINDIR%\Fonts` 829 个字体文件）——`-apple-system`/`PingFang SC` 为**苹果专有（Windows 恒无）**、`'Noto Serif CJK SC'` **未安装**、`'Source Han Serif SC'` **只有 Heavy 一个字重** → **前四个全落空，一路落到通用族 `serif`**。
> **真问题不是乱码**（中文照常显示、宋体也是衬线），而是：**「品牌调性 = 衬线」是被兜底族碰巧满足的，不是被它声明的字体满足的**——兜底若是 sans（某些 Linux 默认），规范**静默失效**，而 **`M-Form-9` 只核图位/图件/图上数字、不核字体 → 没有任何门会报**。

**改动（4 文件 / 12 处字体栈）**：

- **新栈**（唯一真源 = `templates/图表-SVG-template.md` 品牌视觉规范表）：`'Source Han Serif SC', 'Noto Serif CJK SC', STZhongsong, STSong, SimSun, serif`
  - **不碰品牌调性**：全是衬线族（`STSong` 华文宋体 / `STZhongsong` 其粗家族 / `SimSun` 宋体**均为宋体系**）→ **落点仍是宋体、与旧实况同族**；只把「声明」落到**实际存在**的名字上。`serif` 仍是**最后一项**（兜底保险不因换栈而失效）。
  - **版本步进 = patch 的判据**：本批**只改字体族名与文档说明**，**不改任何行为契约**（相位、字节预算、退出码、门项集合、判据语义全部不动）→ 属**纯文档/样式补丁**，故 `18.75.1` 而非 `18.76.0`（主人 2026-10-04 定案）。
- **`templates/图表-SVG-template.md`**：品牌视觉规范表「字体」行 + **5 个可落盘 `<svg>` 根**的 `font-family`（6 处），并把「说明」列改为「原栈 4 个字**本机一个都没有**、实际全靠 `serif` 兜底」的如实标注。
- **`scripts/md2html.mjs`**：`body` 栈由 `'Microsoft YaHei','SimSun',serif` → **与图件同一族链**。**这是本批顺带查出的第二处病灶**（原 F-19 未记）：旧正文栈首选**雅黑是无衬线** → **同一份交付物「图件衬线、正文无衬线」**；改后**图与正文实际生效族一致**。
- **`references/operations.md`**：§图件字体栈**整节重写**——判据保留，删去「⚠️ 待主人定夺」，新增「**✅ v18.75.1 定案**」（新栈 / 为什么 / 边界与未验证项）＋ 一条**核对义务**（改栈后须回模板品牌表**逐字核对**）。
- **`references/_shared/format-export.md`**：PDF 校验段由「Windows 自带 SimSun/微软雅黑即够」改为**同用衬线栈 + 指向真源 + 「该栈不经任何门校验」**的声明。

**如实声明的边界**：

- **字体没有门，本批也不新增门**（无法机械判定「某字体在目标读者机上是否存在」）→ **新栈是否被正确复制，靠人读、不靠门**；为此新增「与模板声明核对」义务。
- **本机实测边界**：确证**在** = `SimSun`(`simsun.ttc`) / `STSong`(`STSONG.TTF`)；`Source Han Serif SC` **仅 Heavy**；**`STZhongsong` 未单独验证**、**`'Noto Serif CJK SC'` 确证未装**——保留后两个只为**别的机器能命中**（**不存在的名字无害**：逐名尝试，全落空才走 `serif`）。
- **macOS 侧代价**：弃用 `-apple-system`/`PingFang SC` 后**不再由系统 UI 字打头**；当前栈在 macOS 的实际生效 = 系统 `serif` → `Songti SC`（衬线）。**未在栈首补 `'Songti SC'`**——已定案的栈是主人选定并批准的那一串，**不擅自扩写**。
- **无视觉回归保护**：本批**没有**「改前/改后渲染对比」（字体层无门、无快照）——正确性依据是「**名字存在性 + 全部衬线**」这条推理，不是渲染实测。如实登记。
- **历史记录不改**：`CHANGELOG.md` v18.73.0 段「未做：F-19 的字体栈仍待主人裁决」与 v18.75.0 段「不动 F-19 字体栈」**保持原样**——它们是**已发布版本的历史事实**，不是陈旧口径。
