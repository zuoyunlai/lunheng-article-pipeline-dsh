## 三、逐条落点

### 3.1 动议 C｜概念字段块

- **病灶**（反哺报告 F3）：**四个消费者碰术语，无一管「定义的唯一性」**——D6（核心术语首现是否给定义，只对正文）、M2（变量操作化，输入只列「数据卡」）、M-Fact-1 术语近形（治的是**别名混用**，P2 软提示）、`readability` 术语率（只管**密度**）。定义漂移在**任何产物里都没有落点**，只活在正文散文里。
- **改法**：`[Lxx]` 条目内加**五字段**（概念术语 / 本文采用的定义 / 并存竞争性定义及分歧点 / 本文操作化指标 → 对应 `[Dxx]` / 边界条件「不包含什么」）；触发真源 = 任务简报 / 大纲标出的**核心构念**；**D6 与 M2 的数据源列同步指向它**（否则判据有落点、数据源没有 —— 该仓既有教训「判据真源与机检指错门」同型）。
- **判据（T7 人工）**：概念**定义漂移**，或同一术语出现 ≥2 个在用定义而未显式标「竞争性定义」→ **P1**。

### 3.2 动议 D｜法规字段块

- **病灶**（反哺报告 F4）：`policy` 文类是**正式档**（`文类档案.md:22`），但法规文本在 L / D 两族**都不合身**——文献卡字段要「作者/期刊」（法规没有），数据卡要「数值+单位+口径」（条款不是数）。「生效日 / 失效日 / 效力层级 / **现行有效性**」四属性**在任何卡里都不存在**。
- **改法**：`[Lxx]` 条目的**类型标记**（法律法规 / 行政法规 / 部门规章 / 国家标准 / 行业标准）+ **四字段**（文书名与条款号 / 效力层级 / 发布-生效日 / 现行有效性）。
- **判据（T7 人工，**不挂机检门**）**：正文把它当**现行依据**引用而 `现行有效性` ≠ 「现行有效」→ **T7 判 P0**。
- **为什么判据归人工而不做机检**：字段**真伪**（该法规是否真的现有效）是语义判断；机械门只能查「字段填没填」——那会造出「**填了就算核过**」的假绿，与本仓对 M3 的既有裁定同型（`规范-机械门对照表.md` §三 已登记该理由）。**如实声明边界**：故「引用已废止条款」本批**仍是「可判红但未机械化」**，不是「已机械化」。报告 §3.4 称其「少数可机械判红的项」——**本批未采纳该乐观判断**，理由如上；若日后要机械化，正确形态是**候选清单**（照 `G15-VolIssue` 的「候选 P2 + 判级归 T7」），且须配套回归网，属独立一批。

### 3.3 为什么 C / D **都不新立编号族**（本批的核心设计判断）

`scripts/_lib/refs.mjs:28` 的 `REF_ID_TOKEN` 是**编号形态的唯一真源**：

```
'[LDC]\\d+|C-主\\d+|先\\d+|D-基-[A-Z]-\\d+'
```

**它不认 `[Kxx]` / `[L-法NN]`**。由此：

| 若新立族 | 后果 |
|---|---|
| 不动 `REF_ID_TOKEN` | 新族**不被任何门识别**——M-Form-10 索引对账、M-Exist-1 正文↔文末双向闭环、M-Form-1 文献数、M-Form-8 三角覆盖、证据包计数、素材池 type **全部看不见它** ⇒ 新族 = **零机械覆盖**，且与 `[Gnn]` / `[脚注-N]` 那类「游离于闭环之外」的旧缺口同型 |
| 扩 `REF_ID_TOKEN` 让它被认 | `[Kxx]` / `[L-法NN]` 会进入**正文 ↔ 文末五节**的双向闭环 → 但概念卡/法规块**不是文献条目、不该出现在参考文献节** ⇒ 只能**新增第 6 个文末节**，而 `M-Form-7` 的文末节白名单是**锁死的五节**（改它 = 动最核心的门 + 全部存量项目受影响） |

**故取「`[Lxx]` + 字段块」**：定义与法规本身**就是文献**（概念的定义来自文献、法规是文献类型之一），挂在 `[Lxx]` 上语义自洽，且**白拿全套覆盖**（索引对账 / 信任级别 / 引用闭环 / 证据包 / 素材池 L 类 / M-Form-11 加载闭环）。这与批次一「方法学字段块」是**同一判据的第二次应用**，不是巧合。

> **判据（可复用，已写入 01 卡与对照表）**：**加字段块 > 加子形态 > 加新族**。加新族前必须先回答「`REF_ID_TOKEN` 认不认它；不认则零覆盖，认则要不要动文末五节」。
