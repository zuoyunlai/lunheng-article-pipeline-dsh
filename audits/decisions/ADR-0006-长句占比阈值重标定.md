# ADR-0006 — 长句占比阈值重标定（`longRatioMax` 0.25 → 0.30）

- **Status**：Accepted（2026-10-04）
- **Date**：2026-10-04
- **Deciders**：主人（2026-10-04「按你的推荐来」授权执行）+ 主控 T0（测量与落盘）
- **Supersedes**：无（但**接管** `readability.test.mjs` 中登记的 **F-BD** 遗留项——原注「标定带对机制说明密集型哲学长文可能偏紧，**留待按新样本重新标定**」）

---

## Context

`scripts/_lib/readability.mjs` 的标定原则写明：**阈值取「明显异常」上界（略高于真实稿的极值）**。

**原标定**：21 份语料 → 长句占比（>60 汉字句占比）极值 **22.3%** → 阈值 **25%**（= 极值 + 2.7pp）。

**实测发现**（反哺报告 v7 §F-25，主控 2026-10-04 全量跑 `node --test` 时首次暴露）：

- 语料已从 21 份增至 **27 份**（`run/<项目>/final/定稿.md`；其中 4 份受控 A/B 实验产物按既有规则排除 → **参与标定 23 份**）。
- 重测四指标分布（仅参与标定的 23 份）：

  | 指标 | 实测范围 | 阈值 | 余量 |
  |---|---|---|---|
  | `sentenceLenStd` | 14.56 – 28.54 | ≥ 13 | 充足 |
  | **`longSentenceRatio`** | **0.0256 – 0.2764（极值 27.6%）** | ≤ **0.25** | **★ 超界** |
  | `termRatePer300` | 31.61 – 44.36 | ≤ 50 | 充足 |
  | `passiveRatio` | 0.0084 – 0.1866 | ≤ 0.22 | 充足 |

- **只有长句占比一维越界**，且**原阈值 25% 已低于当前极值 27.6%**。
- **这是「极值动了、阈值没跟着动」，不是「某篇稿子变差了」**——标定原则本身被打破。

---

## Decision

**`longRatioMax`：`0.25` → `0.30`**（其余三维阈值与判定档位「最高 P2」均不动）。

**取值依据**：在册极值 **27.6%** + 约 **2.4pp**，沿用原标定的同一量级（原为 22.3% + 2.7pp）。

---

## Alternatives considered（逐条给驳回理由）

| 备选 | 驳回理由 |
|---|---|
| **A. 保持 0.25，把《不能评估的忠诚》加入 `EXCLUDED_EXPERIMENTS`** | **先例理由不适用。** 该名单的立法理由是「**受控 A/B 实验产物**（实验操控 + 分档模型 + 主人授权多轮修订）」；《不能评估的忠诚》是**常规交付**。更关键：测试注释原文为「新增**实验项目**必须显式登记于此」——**它说的是实验项目**。硬加 = 把具名枚举变成"跑不过就登记"。 |
| **B. 保持 0.25，放宽容差（如 `下界×0.85` 那类）** | **放错维度。** 容差机制属候选**区间**判定（`g-audit-check`），本检测器是**单值上限**，没有容差可放。 |
| **C. 承认 27.6% 是真信号，判该稿文风异常** | **部分成立但不能据此结案。** 27.6% 确实偏高；但「是否异常」的判据本身就是**阈值**，而该阈值**已低于语料极值**——**用一个已被打破的界去判定，结论不可信**。先修标定，再谈该稿。 |
| **D. 按文类分档**（`academic-hum` 与实证类各一套界） | **本轮不做，但记录为后续候选。** 分档本身是对的（`methodology-check` 的 F-10 已确立"文类决定判据适用性"先例），但它需要**每类各自的语料规模**——当前 27 份里 `academic-hum` 占比不足以单独标定。**语料够了再做。** |
| **E. 不用阈值，改人评** | **与检测器存在理由冲突。** 本检测器立项目的就是"机检 + 最高只到 P2"，去掉阈值即去掉它。 |

---

## Consequences

**Positive**
- 标定原则恢复成立（阈值重新高于语料极值）。
- **F-BD 遗留项结案**：原注「留待按新样本重新标定」——现在有了新样本与新标定，且**第二个同族样本**（`AB-ai-content-farm-B` 30.1%）一并进入记录。
- 新增**双向校准守卫**（见下），使「标定是否仍成立」从**无人检查**变成**机械断言**。

**Negative（明确认赔）**
- **判定确实变松了 5 个百分点。** 长句占比落在 **25%–30%** 区间的稿子，**此前会被提示、现在不会**。
  - 如实说明：该区间**当前只有《不能评估的忠诚》（27.6%）一份**；`AB-ai-content-farm-B`（30.1%）仍在名单外且仍会被判（若未被排除）。
  - **认赔的是**：这是一个真实存在的"漏报面扩大"，换取的是"标定原则不被架空"。**若将来该区间的稿子变多，应回到备选 D（分档）。**
- 本次**不解决**「机制说明密集型长文是否应在读性上被要求更高」这一**文类问题**——它被显式登记为后续候选（备选 D）。

---

## Regression-proof anchor（成对测试）

**① 行为测** —— `tests/readability.test.mjs` 的「21 份真实定稿全部在标定界内（不误报）」用例（真跑 `evaluate`）。**并在本轮加了两条双向校准断言**：

```js
assert.ok(maxLong <= THRESHOLDS.longRatioMax, '极值已超阈值 → 标定原则被打破，请重新标定')
assert.ok(maxLong >  THRESHOLDS.longRatioMax * 0.85, '极值距阈值过远 → 阈值可能过松，请重新标定')
```
> 立法目的：此前该用例**只断言单向**（不误报），于是**阈值可以静默变松**而无人发现——本项目正是如此，直到主控实测才暴露。

**② 源码钉** —— `tests/readability.test.mjs` 的「长句占比阈值的**源码钉**」用例，直接断言源文件字面量：

```js
assert.match(src, /longRatioMax:\s*0\.30\b/, '必须逐字为 0.30；若确要再改，须同批更新本断言 + 标定注释 + audits/decisions/ 记录')
```

**二者缺一则重标定可被静默回退**：行为测在语料恰好都不越界时会通过（阈值调松看不出），源码钉则在有人改数时立刻点名。
