### ② 已实现 / 已给出可执行出口（8 条：F8 / F10 / F11 / F13 / F14 / F15 / F19 / F22 / F28）

这一类的共同形态是：**报告描述的「缺口」在代码或文档里已经有等价物**，只是报告按「应该有什么」推断，没有回读现场。
最典型的两条：

- **F10**：报告建议「`count-chars.mjs` 在 degraded=true 时**改 stdout 为 NaN**，强制主控识别」。
  实测该脚本**早已**把 `degraded: true` + `degradedReason` 写进 **stdout JSON**（`count-chars.mjs:226-231`），

- **F28**：报告建议「`m-gate-check` 自动落两表单空模板」。实测这条路**走不通也不该走**：
  ① M-Exist-5 要求「实据」列是**机械证据**（路径 / exit code / 命令），**空模板照样过不了**，P1 只是换个地方出现；

  ③ 既有路径完整：抄 `templates/闸门记录-template.md`（`pipeline-readme.md:275`）+ `refresh-gates.mjs` 刷指纹。
