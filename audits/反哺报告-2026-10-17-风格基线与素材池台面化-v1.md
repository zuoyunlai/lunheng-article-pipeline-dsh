## 一、实施摘要（先读这段）

三个「默认关/可选」能力（风格基线、素材池、检索档位）此前**机制已就绪、发现面断裂**——用户没有任何入口会主动撞见它们。本批三件事：

1. **风格基线 → 文类化 + auto**：从「每项目一次性投喂旧作」升级为「按文类持久语料 + 开工时抽取」——旧作按文类投一次，同文类所有项目复用；开关默认 **auto（目录非空即开）**。
2. **素材池 → 台面化**：开工台「素材与工作区」改名 + 加素材池注释 + 检索范围从两档细分到四档。
3. **开场白 ③④⑤ → 瘦身**：把「复述事实」降级为「指针 + 一句判据」，消除「同一事实三处维护必然漂」的隐患。

> 核心原则（贯穿本批）：**表单注释是给人看的，门是给人/系统兜底的，开场白是教 AI 执行的——三层缺一不可**；但开场白里「能靠指针按需读到的细节」不该全文复述。

## 二、风格基线：文类公共语料 + auto 复用

### 2.1 现状（问题）

现有风格基线是 **per-project 一次性投喂**：主人每个项目都要在任务简报勾选「风格基线」+ 投 1-2 篇旧作 → 主控写 `run/<项目>/style-baseline.md`。两个问题：① 每个项目重复投旧作（摩擦）；② 默认关 + 开关埋在模板里（发现面差）。

### 2.2 新设计

- **公共语料目录**：`~/.lunheng/style-baseline/<文类>/`（**用户级**、跨所有项目/工作区；路径可经插件 Config 覆盖，不硬编码）。文类键 = `文类档案.md` 的 code（`academic-cn` / `lit-review` / `kaiti` / …）。
  > 与素材池的层级**刻意不同**：素材池是「共享证据」= 工作区级（`<工作区根>/evidence-pool/`）；风格基线是「作者个人风格」= 人级（`~/.lunheng/`）。这是设计意图，非疏漏。
- **主人投旧作**：按文类放 **2-3 篇旧作**（或 3-5 句风格自述）进对应目录，**投一次**。
- **开工时抽取**：Phase 0 开工，主控读该文类目录（非空）→ 抽取句式/用词/节奏/口吻特征 → 写 `run/<项目>/style-baseline.md`。**消费链（T5 注入 / T6 漂移校验 / T7 抽查 / G14-G 判定，读项目内那份）完全不动**。
- **开关默认 auto**：开工台开关二态「**关 / 自动**」，默认自动。自动语义 = 该文类目录**非空则设基线**；**空 → 退回只按文风档位**，并在开关旁显示提示「请将主人旧文按文类存入 `~/.lunheng/style-baseline/<文类>/` 以便生成风格基线」。显式「关」= 即使有语料也不用（保留项目级控制）。
- **边界沿袭**（现 `style-baseline-template.md §0`）：旧作**仅用于文风对齐、不外发、不复制表达**；**只压文风不压内容**。抽取时首段自动写明「来源 = 公共语料目录」。

### 2.3 复用语义（已拍板）

**复用语料、不复用抽取结果**——语料是唯一真源；每个项目重新抽取（可随项目微调），避免「主人补投旧文后缓存不刷新」的失效问题。

## 四、开场白 ③④⑤ 瘦身

原则：**门是「罚」不是「教」**——A11 能在你留 `<…>` 时判硬 21，但不会告诉 AI `推理=` 该填「远程 provider 名」还是「本地 Ollama」；同理「停手三选一、不得代选」是纯程序判断，**没有任何门能查「AI 有没有代选」**。所以这两条「教学」删了就没东西在教了，门只会事后红。

但「能靠指针按需读到的细节」不该全文复述。逐段处置：

| 段 | 门能否替代 | 处置 |
|---|---|---|
| ③「`推理=` 填远程名/本地 Ollama、写到 01-任务简报 头部、不留尖括号」 | ❌ 门只核结构不核值 | **保留判据**；授权串格式真源 = `任务简报-template.md`，改指针 |
| ③「`脱敏=` 可由 `ETHICS=` 行承载」 | ⚠️ 半可核 | 保留 |
| ④「池位置 / A轨 raw/ / B轨 materials/ / 不外网≠零外发」 | ✅ 事实已在 `素材池.md §11` + 表单注释 | **指针化**：「档 B/仅池/仅项目 ⇒ 读 `素材池.md §11`」 |
| ⑤「停手三选一、不得代选」 | ❌ 门查不了代选 | **保留判据** |
| ⑤「按 §11.2 逐字话术追加」 | ✅ 话术真源在 `素材池.md §11.2` | **指针化**：「派 T1/T2/T3 时 ref-get 读 §11.2」 |
