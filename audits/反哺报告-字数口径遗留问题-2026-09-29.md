## §二、问题 B：字数分级真源**只判「超限」，不判「不足」**——而脚本对不足直接判 P0

**真源现状**（`字数判定表.md` §二）：表头是「**超限幅度** → 判定 → 处理」，表里只有两行：`≤5% → P2` / `>5% → P1`。**没有「不足」这一维**。

**但上下限确实存在且被脚本判级**：

| 站点 | 它做了什么 |
|---|---|
| `scripts/apply-revision-cycle.mjs:124` | `g5 = { floor: round(target*0.9), ceil: round(target*1.05) }` —— **下限 = −10%** |
| 同文件 `:125` | `post.body < g5.floor` → 输出「**低于阻塞线 N 字（P0，须扩写）**」 |
| `scripts/_lib/target-chars.mjs:16` | 注释：「错误的目标会产出**错误的 P0**」 |
| `templates/任务简报-template.md:86` | 「G5 硬阈 = **4950–5775（阻塞线）**」——把 −10% 与 +5% 并列成同一个「阻塞线」 |

**缺口**：一个稿子**写不够 −10%** 时，脚本说 **P0（须扩写）**，而**运行期文档里没有任何一处**给「不足」定级——T7 / T8 只能靠脚本输出或自行推断。**主控 2026-09-29 的裁定只覆盖「超限」**（原话：「字数**超限** 1–5%…」「字数**超限** 5% 以上…」），故**不足侧的档位仍在真空中**。

**为什么这次不自行补**：补一档就是**新增一条判级规则**，会影响修订轮次（要不要 spawn T5 v3？）与 T8 权限边界——属**主人的口径决定**，不是实现细节。

**待主人裁定**（建议选项，供直接采用或改写）：

| 选项 | 「不足」的判级 | 说明 |
|---|---|---|
| **① 与超限镜像**（推荐） | `≥ −5%` 记 **P2**（不强制）；`< −5%`（即不足 5% 以上）记 **P1 + 触发 T5 v3 扩写** | 与已定案的超限侧**同形**（5% 阈值一以贯之），改动最小、可预测 |
| ② 沿用脚本的 −10% 单点 | `< −10%` 记 **P0**；−5%~−10% 记 **P1** | 与脚本现状一致，但**凭空多出 P0 档**（该档刚从超限侧被裁定取消） |
| ③ 明示「不足不判罚」 | 不足一律 **P2 + T8 记录偏差**，不触发修订 | 语义最宽：长文宁可长不可短——**但会让「目标篇幅」实际只成为上限**，与 `pipeline-readme:706`「是**上限语义**，不是「至少写到」」的既有口径互相印证，故需主人明示接受 |

> **注意选项 ③ 的连带含义**：它把「篇幅目标」正式定义成**单侧约束（只限上、不限下）**——这与 v18.11.0 F-5'「上限语义」是一致的，但会**改掉脚本现有的 P0 行为**（须同批改 `apply-revision-cycle.mjs` 的判据与其测试）。

## §四、可迁移判据（本报告的方法学产出）

1. **「不传播」是一种可执行的中间处置**：当发现一处措辞有争议、但改名属主人的词汇决定时，可以在**自己新写的文本里用中性措辞**、并只改**已在自己编辑范围内的**站点——既不扩大错误措辞，也不越权改名。**判据：改名的权限边界 = 该词是否是主人既定词汇。**
2. **真源只覆盖一半维度时，脚本会替你做出另一半决定**——本报告 B 的最好证据：`字数判定表.md` 只写「超限幅度」，而 `apply-revision-cycle.mjs` 对「不足」直接给了 P0。**凡真源的表头是「X 幅度」，就该问一句：另一个方向的幅度谁在判？**
