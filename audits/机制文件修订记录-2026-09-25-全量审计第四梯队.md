## 二、本批改了什么

### 2.1 L-66 `consistency-check --fix --write` 的写盘安全

**问题（三项，同一处代码）**：
1. **固定名 `.bak-fix`** —— 连跑两次时，第一次的原始版本被第二次备份**同名覆盖**，回滚点丢失（`_lib/destructive-write.mjs` 头注释明文批判过这一形态）；
2. **非原子写** —— `writeFileSync` 直接覆写，进程中途被杀留半写文件；
3. **`--write` 单独给出被放行却静默空转** —— 只读模式跑完 `exit 0`，用户以为已修复。

**修法**：`--fix` 落盘改走 **`writeWithSafety(f, text, { inPlace: true })`**（时间戳 `.bak` + temp→rename 原子写 + `BAK_MAX` 回收），输出改为给出**真实回滚点路径**；新增 `--write 必须与 --fix 同用`（否则 exit 10）。

### 2.2 L-62 参数严格性（10 处入口）

审计查明 10 处入口绕过 `_lib/cli-args.mjs`。逐项核过后，**其中 6 处已有未知旗标守卫**（cite/structure/methodology/journal/meta 各带 `else if (a.startsWith('--'))` → exit 10；count-chars 亦已严判），真正的洞是**三类**：

| 类 | 修法 | 影响面 |
|---|---|---|
| **带值旗标缺值**静默：`--report` 是最后一个 token → 变量为 undefined → 末尾 `if (reportPath)` 跳过 → **不落盘却 exit 0** | 逐处补缺值守卫（值缺失或以 `-` 开头 → 打印用法 + **exit 10**） | `cite-coverage-check` / `structure-check` / `methodology-check` / `journal-fit`（`--project` 与 `--report`）/ `meta-synthesize`（`--trigger` 与 `--report`） |
| **下一个旗标被当值吃掉**：`handoff-check --report --summary` → `opt.report="--summary"` 且 `--summary` 消失 → **产物侧整段静默跳过**，exit 0 | 5 个带值旗标统一走 `needValue()` 守卫 | `handoff-check`（`--project/--role/--report/--report-file/--level`） |
| **未知旗标被静默丢弃**：`normalize-trust-level 卡.md --wrtie`（拼错）→ dry-run 跑完 **exit 0**（而它是**唯一改写素材卡的脚本**） | 加白名单严判（`--write` 之外的一律 exit 10） | `normalize-trust-level` |
| **多余参数被静默忽略** | 只接受 1 个位置参数，多余即 exit 10 | `pdfcheck` |
| **参数错与内容错撞码**：`consistency-check --nope` 给 **1**（1 同时用于「文档真漂移」） | 改 **10**（AGENTS.md 已明令「参数或路径错误一律 10」） | `consistency-check` |

### 2.3 L-28 G 清单口径 + gate 标签

**① G15 此前完全没有门在管**：`audit-checklist-quickref.md`（本项自称的真源）在 v18.8.0 已新增「G15 引用匹配度」，而 `G_MAIN` 只到 G14、`G_SUB9` 也不含它 → 不做也无门拦；同时 `SKILL.md:186`/`AGENTS.md`/`glossary.md:128` 仍写「G0-G14（15 项）」。
**处置（有意选择）**：G15 是**模式相关**项（仅在任务简报启用「§引用数量与质量控制」时适用），而本门看不到任务简报——
- **写了** → 与主项同口径校验结论与实据（缺结论/缺实据 → 软提示）；
- **没写** → 记 **note9（备注，可见、不改 pass）**，并写明「未启用该模式时属正常」。

> 为什么不做成软提示（P2）：回归实测——把「未写 G15」计入软提示后，**三份原有夹具即刻被判失败**（它们代表完全合规的审计报告）。那是对未启用该模式的报告造成假阳性，属过度收紧。**如实记备注**是此处能达到的最诚实形态；若主人要求「G15 必须写」，改动是 `note9.push` → `soft9.push`（一行）。

**② gate 标签过期**：`M-Form-2 文末四节存在性` → **`M-Form-2 文末必需五节存在性`**（标签是 M-Exist-5「模板行名逐字一致」与 `闸门记录-template.md` 的逐字真源；`audit-checklist-quickref.md` 的口径此前已在第一梯队同步为「必需五节」，本次把脚本标签补齐）。
