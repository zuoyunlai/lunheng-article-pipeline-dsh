## 2. P1 逐条判据与修法动议

### 2.1 tools.js:472（回报文本被路径化）

- **判据链**：参数描述（`:432`）「子代理回报原文」＝文本语义；脚本侧 `handoff-check.mjs:56`「`--report 回报原文`」；`resolveSessionPath`（`:62-66`）对非绝对路径一律 `resolve(base, p)`。三者合取 → 正常会话（有 session cwd）下文本必被污染。
- **为何测试没抓到**：测试环境取不到 `exec.agent.session.header.cwd` → `resolveSessionPath` 原样返回 → 用例绿。**这是「降级路径掩盖主路径 bug」的新样本**，建议登记进教训族（同族：v18.80.4 的「宿主 cwd ≠ 会话 cwd」）。
- **修法（可直接粘贴）**：

```js
if (args.report) argv.push('--report', args.report)            // 文本，不走路径解析
else if (args.reportFile) argv.push('--report-file', resolveReadablePath(exec, args.reportFile, 'reportFile'))
```

（`reportFile` 顺带从 `resolveSessionPath` 升级为 `resolveReadablePath`，与 v19.6.1 读围栏口径对齐。）
- **回归防线动议**：`tests/tools.test.mjs` 加一条「session cwd 存在时 `--report` 值必须逐字透传」的断言（可用假 exec 注入 cwd）。

### 2.2 index.js:362 / :438（ctx.effect 无守卫）

- **判据**：`:324` `try { ctx.effect?.(() => dPanel) } catch { /* 宿主无 effect → 退回宿主生命周期 */ }` 与 `:362`、`:438` 裸调用并存——同函数内三处两种口径。`:438` 抛错会穿透到 `:844-855` 外层 catch 并 rethrow → 工具/guard/命令整段不装。
- **修法**：两处统一 `ctx.effect?.(...)`；无 effect 时同步降级执行注册体（与 `:324` 注释声明的语义一致）。
- **回归防线动议**：`tests/entry.test.mjs` 加「ctx 无 effect 键时 apply 不抛」的最小 ctx 用例（pack-smoke 的假宿主可扩一档）。

### 2.3 client.js:961-970（copyText 谎报成功）

- **修法**：回调式——`copyText(txt, cb)`：clipboard 分支 `.then(() => cb(true)).catch(() => { execCommand 兜底; cb(…) })`；调用点（`:958` 等三处「复制→改文案」）改回调设置按钮文案。顺带收口 `doCopy`（`:2078-2084`）与 `copyText` 两套并存——Workbench 统一走 `copyText` 的兜底路径。

### 2.4 client.js:1448-1458（pollRoot 闭包旧根）

- **修法**：`pollRoot` 改 `useRef`（`pollTargetRef`），`startPoll` 读 ref；或 `connect` 的依赖数组补 `root`。**注意**：`useCallback` 系对该仓库的 mini-react 运行时是否按依赖数组做 memo 需先核实（若无 memo 行为则改 useRef 是唯一稳法）。

### 2.5 panel.mjs:883-931（心跳全量重算）

- **修法（分层）**：① 快照按 `dir` 做 mtime 指纹缓存（对齐 `loadDicts` 的既有做法），心跳只重发缓存；② `recentFiles` / `specs` walk / `processGroups` 三次遍历合并为一次 walk 产出三份视图；③ `01-任务简报.md` 双读去重（`:398` 与 `:519`）。
- **顺带**：`:795` `samePath` 补尾斜杠/分隔符归一（手输 URL 403 假阴性）；`:943-963` `/ping` 的 `packageVersion()` 读盘加 mtime 缓存。

### 2.6 run-path-fence.mjs:88-102（win32 大小写口径不一，主会话补报）

- **修法**：`isPathInsideRunDir` 的最终比较（`:101`）过 `norm()`——与 `isDirectChildOf`（`:68`）同口径。回归用例：同一目录的两种大小写形态（如盘符大写与小写）应判 inside 为 true。

- `r03-yaml.mjs:28-31`：括号配平不排除引号/注释内括号（`run: echo "arr[0]"` 会假红）——先剥引号/注释段再计数。**接近 P1，建议下批修**。

- `closeout-verify.mjs:54`：`opt()` 把 `--` 开头的值当缺失（`--audit --json` 静默落默认值）——参数错应 10 响亮；`:164` `L-\d{2}` 只认两位（L-123 漏）。
