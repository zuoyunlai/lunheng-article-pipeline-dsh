## 三、标定中抓到并修掉的两个**假绿**（都进了实现与用例）

1. **绑定过宽**（第一轮标定直接 FAIL）：复核报告头部同时列「被审正文」（v4 / `F267D06A…`）与「基线对照」（v3 / `193993010373…`）的 sha → 「指纹段内任意 hex 命中即绑定」的口径让 **v3 快照也绑上 v4 的复核报告** → v3 的闭合率变成 10/10 → **位移归零，而量尺会自称"已标定"**。修法：只认**被审对象**行（`被审正文/评审对象/评分对象`）或节标题含「指纹」的段内行，且**排除**含「基线/对照/旧稿/上一版/原稿/变更前/前一版/未触动」的行。
2. **窗口越块**：判定提取原用「该 id 首现处 +15 行」→ **下一个条件的「判定 | **未关闭**」落进上一个条件的窗口**，`return false` 把本该关闭的前一条也判掉（实测：三条条件全被判未关闭）。修法：**块内判定**（锚行 → 下一个标题行）＋**标题锚优先**（防判定正文里的交叉引用「与 P0/C2-1 同源」把别的条件拖进错误的块）。同源写法 `### 2.1 P0/C1-1 = P1/C7-2（同源）` 共用一块 → 两条同判 ✓（与 T7 实际写法对齐）。

**如实登记的三处边界**（进 `validity.boundary` / `CALIBRATION.caveat` / 对照表）：
① 无绑定裁定时 ② **保守计 0**（与 M-Exist-4「关闭真源 = 复核报告」同口径）——**该读数是低估方向**，此类臂**不可与他臂横比**（先看 `closureBasis`）；
② 标定样本**只 1 例**，**未给阈值、未声称跨项目可比**；
