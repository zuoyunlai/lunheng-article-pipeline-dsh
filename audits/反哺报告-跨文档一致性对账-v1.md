## §一、⭐ 方法教训：反向普查的 pattern 必须按「概念」构造（本次最重要产出）

**事实**：EXEC-1（sha256 实值化）我做了「全量普查」并宣称覆盖 **19 处 / 10 文件**，且断言「残留命中全部是已废止声明」。本次对账查出 **5 处漏网**，全部是**换了一种说法的同一事实**：

| 漏网站点 | 它的措辞 | 我当时的 pattern 有没有它 |
|---|---|---|
| `pipeline-readme.md:856` | 「sha256 指纹回填（**人类可选**；交付说明**占位符可保留**）」 | ❌ 我搜的是「待主人回填」 |
| `agents/08-终检-finalizer.md:14` | 「sha256 指纹回填（**人类可选**）」 | ❌ 同上——**且它与同文件 `:28`（我已修）直接对撞** |
| `templates/闸门记录-template.md:48` | 「证据包**哈希占位符**（**可选验证**）」 | ❌ 我搜的是「sha256 占位符」 |
| `templates/闸门记录-template.md:60` | 「证据包**指纹占位符**」 | ❌ 同上 |
| `M-Gate-Algorithm.md:854-855` | 「真正 sha256 由人类主人…**手动计算后回填**」「sha256 是**人类补填项**」 | ❌ 我搜的是「host shell 回填」 |

**根因**：我的 pattern 集合是 `哈希校验待主人回填|待主人回填|SHA256-PENDING|host shell 回填|agent 不执行 sha256|不能直接计算 sha256|sha256 占位符|占位符机制` —— **它是从「我已经读到的那些句子」倒推出来的**。按这种 pattern 扫，**你只能找到你已知的东西**（典型的「用答案构造检索」）。

**正确做法（本批已改用）**：先写清「**这条事实有几个维度**」，再为**每个维度**穷举同义表述。
例：sha256 这条事实的维度 = ①**谁写**（主人 / agent / 脚本 / 无人）②**写成什么**（实值 / 占位符 / 指针）③**占位符是否合规**（合规 / P1 / 可选验证）④**权威在哪**（manifest / 交付说明 / 无）。
按这四维穷举后，pattern 扩为 `人类可选|可选验证|占位符可保留|人类补填|待主人回填|主人回填|agent 不执行 sha256|不执行 sha256|不能直接计算 sha256|手动计算后回填|sha256 占位符|哈希占位符|指纹占位符|不另行计算|引用实值` —— **这才一次扫全**（并顺带确认 `mexist-gates.mjs:849` 是历史注释、无害）。

> **可迁移判据**：**「全量普查」这四个字只有在 pattern 是「按概念穷举」时才成立；按「已见措辞」构造的 pattern，其覆盖率是不可知的，宣称「全部覆盖」即为未经验证的断言。**
> 这正是本仓反复记录的那一类错误（「已修」只覆盖它当时盯住的那一处）——**只不过这次犯的是我自己**。

## §四、防复发：能不能机械化？（如实评估）

**结论：不能通用化，但可为「具体事实类」逐条立规——本仓已有此范式，本案宜加 1–2 条而非 14 条。**

- **为什么不能通用**：「任意两处陈述必须一致」是不可判定问题（自然语言等价性）。本仓现有 **29 条主规则 + 5 条子规则**全部是**具体事实类**（版本点位 / 白名单计数 / 阈值键 / 档位序列 …）。
- **本仓已有的「两处必须一致」范式**（可直接照抄形态）：
  - **规则 ⑯** 审计视图三方一致（pipeline-readme 声称 ↔ 角色卡 ↔ 生成脚本）
  - **规则 ㉓** 阈值总表自洽（文档表 ↔ `m-gate-check.mjs` 的 `THRESHOLDS`）
  - **规则 ㉔** Phase 序列自洽（流水线全景 ⊆ 启动速查表序列）
  - **规则 ⑩b** 脚本计数全库对账（**结构派生**：句子里出现 ≥3 个 `*.mjs` 名或「脚本/白名单」+数字 → 必须 == 磁盘真值）
- **本案可加的两条（建议，未擅自落地）**：
  1. **㉚ G14 口径一致**：断言全库**不得出现**「G14 四层」；且凡称 G14 防御层数的语句必须是「三层」——一如此类「已知错误措辞」的抓法（同规则 ⑥ 的形态）。
  2. **㉛ 高危事实单点真源**：把本案中**「会导致静默失效或重演已实测偏置」**的两条事实（**T1 主轮源面是否含 `web_search`**、**三档工具装载条件**）登记为「**单点真源 + 他处只留指针**」，并由规则断言「他处不得复述该事实的取值」。
     > **判据**：**凡「答错会让机制静默失效」的事实，都应当只有一处陈述**——重复陈述的收益（读起来方便）远低于它漂移后的代价。
- **⚠️ 落地成本与既有教训**：加规则须同步 `consistency-check.mjs` 头部的「N 类主规则 + M 个子规则」**手工计数**（该文件 L10-14 明写这处**不做派生、只人工同步**，且历史上已两次因「加规则忘改数字」被审计修复）。**故建议与规则本体同一次提交内一起改。**
