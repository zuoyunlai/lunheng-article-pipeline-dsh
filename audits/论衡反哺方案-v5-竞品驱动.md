| 项 | 内容 |
|---|---|
| **目标文件** | 新增 `scripts/self-check.mjs`（技能目录内，随包） |
| **改法** | 一个入口跑完**离线可跑的**全部门（`m-gate-check` 需项目目录，故排除；跑 `consistency-check` 的**只读模式**、`repo-hygiene-check` 若可移植、脚本 `node --check` 全量、五语 README 存在性、版本头一致性），输出**逐项 PASS/FAIL + 汇总 exit**（复用既有语义：`0/1/2/3/10/70`，**不得新造码**） |

- 论衡：`manifest.json` **清单哈希** + 靠 T7/G 审计的**语义判断**

| 项 | 内容 |
|---|---|
