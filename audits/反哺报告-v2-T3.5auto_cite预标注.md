## 一、背景与动机

### 1.1 调研发现（Ai4Scholar 借鉴点）

Ai4Scholar v2.9.1 起把「文献自动标注」做成产品核心杀手锏：

- **粘贴段落 → AI 自动识别可插入引用的位置 → 在 S2/PubMed/GS 上找真实文献 → 按 APA 格式插入**
- 提供 auto / manual 双模式（用户可标 `[CITE]` 控制插入点）
- 影响因子 / JCR 分区筛选
- AI 智能推荐引用数量
- 每条引用旁"替换"按钮

这一能力对应到论衡场景：**T5 写手 v1 完成后，T7 审计常发现"该引未引"或"该用强文献"**——若在 T1/T2/T3 检索后、T4 分析前加一个"T3.5 auto_cite 预标注"阶段，可提前标记"需补引用的论点"。

### 1.2 论衡现状盘点

| 维度 | 论衡现状 | 借鉴点 | 风险 |
|------|---------|--------|------|
| T1/T2/T3 检索阶段 | 已覆盖已发布学术 / 数据 / 案例 | — | — |
| T4 分析阶段 | 基于 T1/T2/T3 输出做三角验证 | auto_cite 不替代三角验证 | 不会破坏三角验证 |
| T5 写手 v1 后修订 | T7 审计发现 P0/P1 后才补 | **T3.5 预标注提前发现** | 不替代 T7 审计 |
| DSH auto_cite 工具 | 已可用（消耗积分） | 复用 | 积分成本 |

### 1.3 改进目标

新增 **T3.5 auto_cite 预标注阶段**（可选，主人 Phase 0 显式开启）：

```
Phase 0 → Phase 1（T1∥T2∥T3 并行）→ [新增 T3.5 auto_cite（可选）] → Phase 2（T4）→ Phase 2.5（主人确认大纲）
```

**关键边界**：
- T3.5 **不产数据卡/案例卡**，只产 `literature/auto_cite-补充.md`（仅"标记哪些论点需要补引用"的预清单）
- T4 分析员在出大纲时参考 T3.5 输出，但**不被强制采纳**
- Phase 2.5 主人可显式关闭 T3.5（任务简报 §v2.5.0 可选项）
