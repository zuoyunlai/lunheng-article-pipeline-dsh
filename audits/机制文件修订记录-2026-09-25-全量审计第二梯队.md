## 二、本批改了什么

### 2.1 M-Exist-5 的五条空洞（L-02 / L-03 / L-22 / L-54 / L-10）——**同批修，缺一无效**

M-Exist-5 是两道主控闸门（T2.5 / T7.5）**唯一**的机械检查项。审计查明它对 T7.5 实际是**空转**，由五条互不重叠的空洞构成：

| # | 空洞 | 修法（落点） |
|---|---|---|
| ① **L-54** | 模板解析循环在 T2.5 表末写 `break` → 退出**整个**扫描 → `required['T7.5']` **恒为空数组**，「逐项都要有行」在空列表上空转（把 T7.5 记录写成一行自造项也能 pass） | 改「按节」语义：引入 `tableDone5`，非表格行只结束**本节**收集（`mexist-gates.mjs`） |
| ② **L-22/L-03** | 实据列只做**语法匹配**（`/[\\/]|exit \d|…/`）——15 行全填伪造 `exit 0` 也判「实据为机械证据」；结论词**不与实据对账**——用 `exit=2` 的实据标 ✓ 照样过 | 新增**逐行绑定**：✓ 行的实据里 `exit N` 必须 == 报告 `script_exit_raw`（不等 → **P0**）；M 门**有效裁定值**必须为 0（非 0 → **P0**）；涉及 `handoff` 的行必须给 exit ∈ {0,20,21,22}（缺 → **P1**）；实据引用的项目内路径必须真实存在（缺 → P2） |
| ③ **L-02** | 整段对账被 `resPass === rows5.length`（**全行皆 ✓**）守卫——而模板本身允许 ✗ / N/A → **三个真实项目全部绕过** | 删掉「全 ✓」前置，改为对**每个 ✓ 行**逐行对账 |
| ④ **L-04** | 字段名契约漂移：文档/门读 `true_p0`，实战产物写 `true_p0_count` → 门永远读不到裁定 | 两种写法都认（`t8.true_p0 ?? t8.true_p0_count`） |
| ⑤ **L-10** | 「不写 handoff exit = 判 P1」的规则**从未被检查**（20 个真实项目只有 1 个真跑过） | **按行**：提到 handoff 却无 exit → **P1**；两份记录**都没提** → **信息性备注**（不计 pass，见 §五 未做项） |

### 2.2 F-1 硬 P0 红线实装（L-44）

`m-gate-check.mjs` 的注释声明「红线检查在 `exit` 判定时强制重审」，而紧随其后的 `exitCode` 表达式里**一行红线判定都没有** → 四条最关键的缺陷仍可被一纸 `_t8_conclusion` 放行（审计夹具实测：删掉 `## 案例来源` 的稿子机械 `exit=2`，写入裁定段后落盘报告即变 `exit=0`）。

**落到三处**：
1. `m-gate-check.mjs` 在 `exit` 判定时收集 **`hard_red_line_hits`**（M-Form-2 / M-Form-7 / M-Exist-1 / M-Integrity-1 中任一 `pass=false`）并写入报告；
2. 落盘时**拒绝采纳**既有 T8 裁定值（`sameDraft && hardRedLineHits.length === 0` 才保留），置 `verdict_stale=true` 并打印 `⛔ 硬 P0 红线命中`；
3. `M-Exist-5` 的放行分支加前置 `hard_red_line_hits?.length === 0`。

**判据升级**：从「文档承诺」变为「机器保证」——`hard_red_line_hits` 非空 ⇒ 任何 LLM 裁定都不被采信。

### 2.3 门「静默消失」留痕（L-23）

`analysis/分析大纲.md` 不存在时，旧版**整块跳过**承重墙检查 → `wallBit` 为空串 → 从 detail 看不出这道门根本没跑（实测：把大纲改名后 M-Form-8 报「3 段：0 段缺 L」**通过**，总 `exit=0`）。同一动作还让 M-Exist-10 退成 N/A 通过 —— **移动一个文件即关掉两道门**。

**修法**：`wall8.degraded` 显式留痕，detail 无条件带出「承重墙**未检**（不是「通过」）」；M-Exist-10 的 N/A 文案改为「N/A 且**未检**」并指向 `SKILL.md` 的连带规则。
**有意选择**：**不改 `pass`**（避免对「本就没有大纲的档位/夹具」造成大面积假 exit≠0）——保证**可见性**成立，阻断性留给主人的连带规则（L-18）。
