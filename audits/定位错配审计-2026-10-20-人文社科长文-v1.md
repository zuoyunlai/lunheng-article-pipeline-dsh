# 定位错配审计 · 2026-10-20 · 「人文社科深度长文」× 论衡 v19.21.0

> 审计对象：论衡 v19.21.0 机制的**判据形态**（结构门 / 字数口径 / 引用模式 / 文献下限 / 素材卡 / 期刊库 / 一手材料链），不是某个项目。
> 审计口径：定位 = **DSH 开源插件 · 人文社科深度长文写作**（非商业产品、非理工论文、非营销软文）。
> 方法：**只读**。① 机制面读源码与档案（行号为准）；② 合成 4 组探针稿实测脚本退出码；③ 拿本工作区 5 份真实人文稿做只读复跑（不改任何 `run/` 产物）。
> 结论一句话：**机制内核是「社科实证形状」（IMRaD＋讨论节＋编号引用），人文长文的三种常规体例（结语式、章节式、页下注式）目前会被判成缺陷**——不是作者写错，是判据不认。

## 一、实测证据（先看数，再看判断）

### E1 结构门：`--humanities` 不认「结语」，且缺「讨论」直接 P0

对 5 份真实人文稿只读复跑 `structure-check.mjs --humanities`：

| 稿 | 章节形态 | 今日复跑 |
|---|---|---|
| `善行的制度成本` | 摘要 / 引言 / **第一章…第五章** / **结语** | **exit 2**（P0） |
| `论艺术中的丑` | 引言 / 一…五 / **结语** | **exit 2**（P0） |
| `guannian-yu-linian` | 摘要 / 一、引言：问题的提出 / 二…五 / 六、结语 | **exit 2**（P0） |
| `不能评估的忠诚` | 0 引言 / … / **5 讨论** / **6 结论** | exit 0 |
| `台海可预测性边界` | 1 引言 / … / **7 讨论与局限** / **8 结论** | exit 0 |

三份被判 P0 的稿，缺的是**「讨论」与「结论」两个字面标题**——它们写的是「结语」。而 `S-Discussion-4` 的判据是「取『讨论』节正文再扫四要素」（`scripts/structure-check.mjs:147`），取不到 ⇒ `discussionText=''` ⇒ 四要素全缺 ⇒ **P0**（`:174`）。同一份稿补一个「讨论」节后：

```
无「讨论」节 → exit 2（S-IMRaD P1 / funnel P1 / disc P0）
加「讨论」节 → exit 1（S-IMRaD PASS / funnel P1 / disc P2）
```

**判据形态问题（不是内容问题）**：门用**三个字面标题**（引言/讨论/结论）代表「人文结构」，而人文长文的常规体例是**章节式论证 + 结语**；实证论文才把「讨论」单列。实测 5 份中 3 份撞上，比例 60%。

> ⚠️ 审计纪律：这 3 份是**历史项目**，本审计**不主张重跑或改稿**（按主人既定口径：不动 `run/`）。它们在这里只作**判据形态的样本**——同样的写法出现在任何新人文项目上，今日仍会得到同一个 exit 2。

### E2 引言漏斗：词表收的是实证写法，人文写法判缺

`论艺术中的丑` 的 S-Intro-Funnel = **P1，缺「知识缺口」**（其余项在）。它的引言写的是「问题的提出 + 既有观点梳理」——语义上有缺口，但**不在关键词表里**（`scripts/structure-check.mjs:129` 收「不足/缺乏/尚未/尚无/鲜有…」，不收「问题的提出/既有研究多集中于/学界长期…」）。

这与 v18.73.0 已登记过的假阳性同源（当时的修法是补词面，判据写在 `:119-125`：「关键词表是语义的近似，近似不足时应补词面，不应让作者迁就词表」）。**同一判据今天对人文引言仍然成立**。

### E3 文献下限：`academic-hum` = 3，深度长文里形同虚设

`scripts/_lib/mgate-gates/mform-gates.mjs:92-99` 的 `GENRE_MIN_L`：`academic-hum: 3`（`kaiti` 反而是 10）。实测三份人文稿的唯一 `[Lxx]` 数为 **22 / 23 / 17**——下限 3 等于不设防，`M-Form-1` 的「文献充分」在这一档只剩「有引用就行」。

对「深度长文（1–2 万字）」，下限应当**随篇幅或文献综述节走**，而不是一个与 `course` 同档的常数。

### E4 脚注 / 页下注：机制只留了「扩展编号」一条缝，且不计字数

- `count-chars.mjs:12`、`字数判定表.md:19`：正文区**不含脚注**；
- `mexist-gates.mjs:109-131`：`[脚注-N]` 被归为**扩展编号**，允许但须与文末「数据来源」节内的 `### 脚注` 子节双向闭环（`mexist-gates.mjs:164`）；
- 全库 `页下注` 命中 **0**，`注释体例` 命中 **0**。

**但要说实话**：实测这 3 份人文稿的「脚注」命中数均为 **0**（它们用的是编号 + 参考文献）。所以这不是「已发生的事故」，而是**潜伏错配**：一旦作者按《历史研究》《文学评论》的页下注体例来写（文史哲主流），① 脚注文字不进字数口径；② 交付形态没有页下注渲染档（`文类档案.md` 引用模式只有「编号 / 内联」两档）。等级按「潜伏」记 P1，不按 P0。

### E5 期刊库：人文核心刊只有 6 行 / 28 行

`references/_shared/期刊数据库.md` 中文 28 行按类别分布：管理学 4、高等教育 2、设计学 2、综合社科 2、经济学 2、新闻传播 2、教育技术 2、公共管理 2、产业经济 2，**文学 / 历史学 / 哲学 / 艺术学各 1**（《文学评论》《历史研究》《哲学研究》《文艺研究》），另加《中国社会科学》《学术月刊》。

够用（没有缺席），但**广度与「人文社科」定位不匹配**：28 行里 21 行是社科实证/经管/教育向。人文作者拿到的 Top 3 推荐容易跑到「综合社科」去。

### E6 素材卡：有 L/D/C，没有「史料 / 文本」卡

三卡体系 = 文献卡（L）/ 数据卡（D）/ 案例卡（C）+ 先行者清单（先）。`案例卡-template-lite.md` 的必填字段是「时间窗口 / 事件状态 / 来源独立性」——**事件型**语义。人文的「史料 / 文本 / 档案」既非数据也非事件案例，只能塞进 L 卡（伪装成文献）或 C 卡（伪装成案例），编号语义 (`[Cxx]`) 会与正文的「案例」叙述错位。

### E7 结构件：讨论四要素是实证形状；差异点矩阵反而适配

- `S-Discussion-4` 四要素（主要发现重述 / 与既有研究比较 / 机制解释 / 局限与未来方向）——**实证论文的讨论节模板**。人文的对应物散在「结语 + 各章过渡」里，门只看「讨论」节，故既容易 P0（无讨论节，见 E1）也容易空转（有讨论节但写的是别的）。
- 反倒是 T4 的**差异点矩阵**（一致 / 扩展 / 修正 / 反驳 / 全新，`04-分析-analyst.md:149`）对人文的**谱系定位**很合适——这条是适配项，不是错配。

### E8 一手材料链：已具备，是优势不是缺口

`任务简报-template.md:143` 有「一手数据（走主人投喂清单）」勾选、`:145` 有 `ETHICS=off|basic|strict` 与 `lunheng_ethics_sanitize`、`:154` 有 A/B 两轨素材（`evidence-pool/raw/transcripts` 与 `run/<项目>/materials`），外加 `伦理审批声明` 模板。**田野 / 口述史 / 档案类人文研究刚需的这条链，理工向工具普遍没有**——这在定位上是资产，但当前没有任何一处把它写成「人文社科的能力面」。

### E9 G14 中文 AI 痕迹：未实测，列为待测

人文稿引文密集、长句、文言词多，是否触发 G14 的 C 类套话，**本审计未裁定**（没有可对照的「真人文 vs AI 人文」样本）。验证方法写在 §五。

## 二、逐维判定（适配 / 需参数 / 需新档）

| 维度 | 人文社科深度长文的常态 | 机制现状 | 判定 |
|---|---|---|---|
| 章节结构 | 章节式（一、二、三…）+ 结语 | 只认 引言/讨论/结论 | 🔴 **需新档**（体例档） |
| 引言写法 | 问题的提出 + 既有观点梳理 | 实证三要素词表 | 🟡 需参数（补词面） |
| 结论 / 讨论 | 常合并为「结语」 | 讨论四要素机检 | 🔴 需新档（结语同义 + 四要素可选） |
| 引用形态 | 编号（部分刊）+ 页下注（文史哲主流） | 编号 / 内联；`[脚注-N]` 仅扩展编号 | 🟡 需参数（脚注档 + 双字数口径） |
| 文献量 | 40–80 条（1–2 万字） | 下限 3 | 🟡 需参数（按下限×篇幅） |
| 一手材料 | 访谈 / 田野 / 档案 | 有脱敏 + 伦理 + 投喂，未卡片化 | 🟢 适配（待显性化） |
| 史料 / 文本单元 | 需独立编号与出处（版本/卷次/页码） | 无卡型 | 🔴 需新档（史料卡） |
| 期刊推荐 | 文史哲各 1 行 | 6/28 行覆盖人文 | 🟡 需参数（扩库） |
| 文末节 | 多数刊只要求参考文献 + 作者信息 | 五节必需 / 九节可选 | 🟢 适配 |
| 字数口径 | 正文 + 注释双读数 | 只读正文（不含脚注） | 🟡 需参数（双读数） |

## 四、结论

1. 机制与定位的错配**不在「文类数量」**（`academic-hum` 早就登记了），而在**判据的字面形态**：中文人文长文的主流体例（章节式 + 结语、页下注、大文献量）在现行门里没有对应表达。
2. 最贵的一条不是加功能，而是 **B1**：今日一份完全合规的人文长文，只要写「结语」不写「讨论 / 结论」，就会被判 **exit 2**。这是「机器把对的判成错的」，比「漏判」更伤——作者会学着为过门而改标题。
3. 反过来，**一手材料链（脱敏 / 伦理 / 投喂 / A-B 轨）是现成的差异化能力**，只差在文档里显性化——成本近乎零。
4. 本审计**不动任何 `run/` 产物、不改任何机制文件**；B1–B6 逐批落地时按 `maintainers.md` §14.1 五步走（备份 / `edit` / 验证 / 可回滚 / 如实标注）。
