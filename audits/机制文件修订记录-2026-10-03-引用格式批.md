## 五、拿真卡打靶抓出的 5 个 bug（已修 + 已入用例）

1. **索引段被后文另一张 `| [Lxx] | … |` 表覆盖** → 16 处假阳性。判据：**表格语义由表头决定，不由行形状决定**。
2. **JS 正则没有 `\Z`**（当字面 `Z`）→ 无后继 `##` 的卡片索引段静默为空 → 对账**全部假通过**。改为按 `##` 切块。
3. 题名去作者词后**留孤引号**。剥引号须两侧都剥、去作者词后再剥一次。
4. URL 吃进**全角括号**；[M] 把卡片散文括注/页数注入著录串。
5. **`期刊版本待核验` 被当刊名** → 违反本仓既有铁律（`文献卡-template.md:110` 禁「待核」占位）。修法：**「待核/待补/未知/未检索到/TBD」类占位值一律当缺字段**。

> **工程教训**：pwsh `Set-Content -Encoding UTF8`（PS 5.1）会给 UTF-8 脚本**写 BOM** → shebang 前多一字符 → `node --check` 报 `Invalid or unexpected token`。`AGENTS.md:§7` 只管读侧编码；**写侧用 `edit` 工具**，必要时用 node 去 BOM。

## 六、未做 / 边界（如实）

1. **不做串 → 串转换**（§二）；**不做 CNKI/BibTeX/RIS 导入**（属摄取，归 `_shared/材料摄取.md`）；**不做投稿系统版面级排版**。
2. **IEEE 未支持**：任何文档不得声称支持；要支持须补齐四件（模板/类型映射/作者规则/成对测试）。
3. **字段值取到行末**（多行字段只取首行）；卡片著录类字段本就单行。
4. **索引段对账是提示不是判错**——两边可能都对（原作者 vs 译者），机器不做责任者判定。
5. **逐条真伪仍是人工**：本器只保证「按字段拼得对」，不保证「字段本身是真的」（归 T1 落卡自检 + T7 `G1` 抽查）。
6. **常驻集余量已薄**（`SKILL.md + AGENTS.md` = 68.6/69.0 KB）：本批 `SKILL.md` 再增长即需先瘦身或同批抬 `ALWAYS_LIMIT`（已在 `DOC_BUDGET` 条目内写明）。
