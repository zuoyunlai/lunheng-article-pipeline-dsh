## 四、Q-claim 答案（**带证据**）

### Q1：M3 对未声明识别策略的稿能否稳定判 P1？  → **是**

**证据**（落盘实测）：

| 稿 | M3 路径选择 | 5 项最低要求（a 证据链 / b 替代解释 / c 反事实 / d 可证伪 / e 不可接受声明）| **M3 最终判定** |
|---|---|---|---|
| A 实验组（process tracing + 4 反事实 + F1-F3）| 质性路径（定量自排）| ✓ / ✓ / ✓ / ✓ / ✓ | **pass** |
| B 对照组（无识别策略、无反事实、无 F1-Fn）| 未声明（§2「单一案例研究路径」是 04 §13 禁写实例）| 部分 / ✗ / ✗ / ✗ / 部分 | **P1** |

**判别力 = 1 档（pass vs P1）**。5 项最低要求**逐项**呈差异，不是偶然。

### Q2：T4 04 §13 字段能否被填出实质内容？  → **是**

**证据**：
- A 稿大纲 `analysis/分析大纲.md` §13.1 选定 process tracing + 给出五选一排除法（含自排 quantitative inference 的理由：「单案无随机样本不可外推」）；
- §13.2 反事实条件 4 条（每条均「若无 X，则 Y 不会发生」格式，覆盖 4 个承重论点）；
- §13.3 F1-F3 三条可证伪预测，每条带（验证内容 / 验证方式 / 验证窗口 ≤ 2027-01-01 / 命中-不命中反方处置）四要素；
- §13.5 显式声明「不可接受写法已回避」；
- M3 内文证据逐条对照 5 项最低要求**全部满足**。

**A1 字段不是抄五选一口号**——变量命名（东盟中心性的具体议程保护 / 协商前置于专家组 / ASEAN+1 FTA 模板等）都给出具体所指。

### Q3：M3 输出质量是否值得机械化（`structure-check --qualitative` 档）？  → **试点建议不动脚本**

**为什么不动**：
1. T9-m 报告的结构化**本身**就是有内文证据可复算的——逐项对照 5 项最低要求 + 显式排除「见到策略名 → pass」假绿 + 防污染原则写在报告首段。
2. **机械化的最大风险是假绿**：正则会因「本文采用案例研究法」一句就判合规，而识别策略的**质量**（证据链可追溯 / 替代解释真被排除）不可机械判。这是 04 §13 字段设计的**根本初衷**（不抄成口号就要防「仅见名词即通过」）。
3. **新增脚本须新开 `QS-` 命名空间**（`M-Form-12` 撞号教训）——成本（命名空间登记 + 测试用例 + 文档）与收益（仅有 1 档判别力的卡层已够用）**不划算**。
4. 批 2 修订记录 §六-6 已经预设「试点后再定是否加脚本」——试点答案 = 不加。

> **建议**：**保持卡层判据**（04 §13 + 05 铁律 4 + 09 M3），**不**写 `structure-check --qualitative` 档。**6 个月 / 2 个真实项目**后再评估——若卡层在 2 个新项目上仍能稳定判别，则结论固化；若出现新增的判别失败模式，再考虑开 `QS-` 命名空间的新门。

### E（附带验证）：05 铁律 4 强度纪律是否真让作者少用强档因果词？

**证据**（落盘实测）：

|---|---|---|---|
| 导致 / 引起 | 0 / 0 | 3 / 0 | B 远高于 A |
| 证明 / 证实 | 0 / 0 | 0 / 1 | B 远高于 A |

| 相关 / 提示 | 0 / 1 | 0 / 0 | A 用了「提示」（弱档）符合强度纪律 |

**05 铁律 4 实测生效**。B 组 8 处强档因果词全部**无识别策略可回链**——这就是 T9-m 报告 line 100「B 稿 5 项最低要求多数未满足，且强档因果词密度极高但无识别策略框架可回链」的物质基础。

## 六、试点限制（如实声明）

1. **样本量 N=2**：本试点仅两个写手、一道题（一个 case study）、三个审稿人——结论是**可行性证据**，不是统计证明。建议至少**再跑 1 个案例研究型项目**（不同主题，例如「RTA 文本的深度比较」）与 1 个**非案例研究型项目**（例如「行业评论」）作为**反例**，验证 04 §13 / M3 在非质性论文上的边界（应该 N/A）。
2. **T9-m 仅审计初稿 v1**：未跑 v2 / v3 修订轮——本试点只验证「判定机制」是否有效，不验证「修订闭环」是否正常。
3. **任务简报 §四笔误（第二十章 → 第十九章）**：写手-A 独立查证后按事实写"第十九章"，与正式中文本 + Lando 2022 等对齐。**主控的派发失误被诚实纠正**——这是试点的一个正向信号（写手优先事实，不替代规匹配简报）。
4. **写手-B 重写**：原稿被覆盖后按记忆复现，理论上存在「不完全等于原稿」的风险——但判别词实测 0/0/0 与重写前声明的对照组规范一致，**对照组性质成立**。
5. **AI4Scholar credits**：本会话累计消耗 ~49 credits（写手-A ~15 + T9-i ~10 + T9-v ~24），剩余 ~295-305 credits。
6. **试点不替代论衡全流水线**：省去 T4 分析员（写手-A 合并）、T6 批判、T7 审计、T8 终检——试点只验证 04 §13 + M3 + B1 这三个机制点，不涉及 G 闸门 / M 门 / 修订回环 / 字数软档 / 期刊匹配等其他维度。
