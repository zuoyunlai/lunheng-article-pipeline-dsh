## 一、实施摘要（先读这段）

对方是一个 1432 行单文件 host 插件，把「一条参考文献是否真实存在」做成**可复跑的确定性动作**（Crossref / OpenAlex / arXiv 三源，逐条四态，附 best 记录）。论衡的对应能力是 **G1 引用真实性**——**纯 LLM 抽验，无脚本、无产物、比例不可自证**。

我没看 README 就下结论：把它的 `host.mjs` 下载下来，用替代 `ctx` 跑它的 `apply()` 注册出**真工具**，喂论衡 `run/` 下 **3 份已交付定稿的真实参考文献节**实跑。结果一句话：

> **算法与"判定从紧"的诚实口径值得借；产物形态（四态 + 逐源状态 + best）值得借；但它的格式生成器、中文覆盖、条目切分不能搬。**

分三档处置：

| 档 | 内容 | 处置 |
|---|---|---|
| **可直接借** | 四态判定 + 逐源 `ok/error/candidates` 上报 + `found` 从紧阈值 + 工程参数（并发/超时/429/truncated） | R1 / R6 |
| **改造后借** | DOI-first 回填、年份口径（`published-print` vs `issued`）、四档替代"404 即禁卡"、外部服务面收敛 | R2 / R3 / R4 / R5 |
| **明确不借** | 8 样式格式生成器（双真源）、中文 `not_found` 当判据、整插件当门 | N1–N4 |

> **主人两问先答（v1.1）**：
> ① **收益大吗**——**中大但不均匀**：R2/R4 是纯文档改动，却挡住 **44.5% 条目**的误杀面；R1/R3 是"低频高损"（标识符级缺陷历史 **5/36 项目**，但一次命中即一轮打回）。
> ② **会阻塞吗**——按 §四 的分级实现 **不阻塞**（T7 多 8.4 s + 一次网络；缺 JSON 退回现状）；**只有**把它做成 `M-Exist` 新项或塞进 `g-audit-check` 才阻塞。

## 二、实测底稿（可复现）

### 2.1 三份真实定稿

```
node _audit_tmp/refcheck-compare/extract.mjs <定稿.md> refs-x.md   # 抽「## 参考文献」节
node _audit_tmp/refcheck-compare/harness.mjs refs-x.md            # 用其 apply() 起真工具跑
```

| 输入 | 条数/格式 | 结果 |
|---|---|---|
| `run/AB-ai-content-farm-A` | 10 条英文，`- [Lxx]` + 大量 `[J/OL]` | **只解析出 5 条**（10→5 合并）；4 `found` / 1 `not_found`，该 `not_found` **是假阴性**（arXiv 2303.13408 真实存在） |
| `run/gen-ai-academic-integrity` | 15 条，`[Lxx]` 无 bullet，多为 `[J]` | 12 `found` / 3 `not_found`；3 条全为中文文献 |
| `run/教师减负政策落地效果` | 12 条中文 GB/T `[n]` | **0 `found` / 12 `not_found`**；`best` 候选全是无关中文论文（「小学数学教学中的素质教育」等） |

规模参照：`run/` 下 39 份定稿中 **8 个项目用到 `[J/OL]`（44 处）**——即"论衡自己的主要著录形态，恰是对方解析不了的形态"。

### 2.2 请求层失败（三次运行合计）

Crossref `429` ×5、OpenAlex `HTTP 400` ×5、arXiv `429`/`timeout` ×10。并发 4、15s 超时、UA 无 `mailto`（`host.mjs:48-51`、`:47`）。

### 2.3 对方 5 个缺陷（定位到行，均直接命中论衡）

| # | 缺陷 | 代码位置 | 后果 |
|---|---|---|---|
| 1 | **`[J/OL]` 不在 GB 标记表**（只有 `EB/OL`） | `host.mjs:941`（`detectLineFormat` 首行正则） | 退 `plain` → 标题被猜成**作者块**（`[L03] KRISHNA K, SONG Y, …`）→ 真文献判 `not_found` |
| 2 | **`- [Lxx]` 前缀 = 条目边界失效** | `:480`（`isEntryStart`）、`:492`（`cleanRefLine` 只剥 `[1]`/`(1)`/`1.`） | 10 条并成 5 条（论衡定稿默认写法） |
| 3 | **DOI 不进直查**：`lineToRef` 只抽 `year`/`firstAuthor`；`crossrefUrl` 只有 `query.title` / `query.bibliographic` | `:496`、`:670` | 论衡文献卡的 DOI 字段（结构化优势）用不上 |
| 4 | **只取 `issued`**，忽略 `published-print` | `:752` | 实测 DOI `10.1080/14703297.2023.2190148`：`issued`=2023（online）、`published-print`=2024 → 其 `corrected` 会把「2024」改成「2023」（GB/T 用出版年 = **方向正确的错误更正**） |
| 5 | **中文 DOI ≠ Crossref** | —（数据面） | `10.13718/j.cnki.xdsk.2023.05.014` 在 Crossref 直接 404 → 「DOI 404」不能当编造信号 |

> 第 1、2 条不是"对方的 bug 值得同情"，而是**判据**：任何"参考文献真实性核验器"若不能吃**论衡自己的著录形态**，它的 `not_found` 就不是证据。

### 2.4 收益量化（分母 + 历史证据，v1.1 新增）

分母（`run/` 下有参考文献节的 **36** 个已交付项目）：

| 指标 | 数值 |
|---|---|
| 文献条目 | **560** |
| 中文题名 | **249（44.5%）** |
| 带 DOI | 126（22.5%） |

历史证据——`run/AB-共锁-A/agents-log.md` 记录的一次真实 P0（原文摘录）：

- `[L01]` DOI `10.1093/0195128791.001.0001` → Crossref **HTTP 404**；且期刊名与 SEP / Springer *J Ethics* / Wiley 均不符
- `[L12]` 作者**张冠李戴**：DOI → **HTTP 200**，但 `author = Louis Mosar`、`title = Slavery with extra steps: conceptualising impersonal market domination`
- 根因原文：「两处**均非 T5 引入**——`literature/文献卡.md` 原样携带 → 缺陷在 **T1 检索环节**；而 **M 门与 G 机检均不核「卡片自身标识符的可解析性」**」
- 代价：T7 打回 + **A 轨一轮修订环**

这类标识符级问题出现于 **5/36 项目（14%）**。

> **判据**：该缺陷的特征是**低频（少数条目）但高损（一次即一轮）**——正是"机械核验"该管的区间。而 T7 现在的比例抽验（A ≥10% / B ≥50% / C 100%）对"14% 的项目里那 1–2 条"命中率不低，但**不可复现**（这次抽到、下次抽不到，换个人又不一样）。

## 三、动议（R1–R6）

### R1【P0】G1 从「抽验比例」升级为「可复跑清单」

> **来源**：`audit-checklist-quickref.md` G1 段（C 100% / B ≥50% / A ≥10%）+ `g-audit-check.mjs:35`（G1 明确"维持 LLM 判定"）+ 实测
> **痛点**：G1 只在 T7 的推理里跑，**无脚本、无产物、无输入**。交接报告写「已抽验 10 条」，M 门与主控都无法复核这 10 条是否真跑、跑的是哪 10 条。「抽到一条假的 → 提到 100%」这条升级规则更是纯依赖人。
> **改动**：
> 1. 新增 `scripts/ref-verify.mjs`（第 37 个白名单脚本，计数以 `SKILL.md:49` 现值为准）→ 输出 `final/引用核验.json`：每条约 `status ∈ {found, partial, not_found, unverified, error}` + `sources[]`（每源 `ok/error/candidates`）+ `best{title,year,venue,volume,issue,pages,doi}`。
> 2. `07-审计-auditor.md` G1 段加一句：**有 JSON 时实据 = `final/引用核验.json`；无 JSON 时退回现状（人工抽验），不得因"无 JSON"判任何 P 级**。
>    > ⚠️ **不要写成「缺失记 SKIP」**（v1 原稿写法，**v1.1 修正**）：论衡里 `SKIP ≠ 通过`（`07-审计-auditor.md:164-165`），在 `M-Exist-9` 的实据口径下会被读成「缺实据 → P2 起」——**等于把网络可用性变成交付前提**。正确口径 = **有无 JSON 只改「实据形态」，不改「判级门槛」**。
>    > 另：`M-Exist-9` 已接受「带量词的数字」（如 `抽验 12 条`）作为实据 ⇒ **现状本身不违规**；JSON 只是把该量词换成可复核对象。
> 3. `audit-checklist-quickref.md` G1 段加「抽验比例仍是人工抽样，但**抽样清单**可由 JSON 反查」。
> **影响**：G1 从"比例自述"变成"清单 + T7 定性"；抽验比例不再可被含糊覆盖。
> **验证**：`node --test tests/scripts/ref-verify.test.mjs`（离线夹具）；`g-audit-check` 不改一个字节（判级仍归 T7）。
> **exit 语义（刻意如此）**：`0` 清单完整落盘（**不判结论分布**）/ `3` 存在 `unverified`/`error`（须人工复核）/ `10` / `70`——**不设 `1`**。依据 `AGENTS.md` 既有判据：「只要脚本不做内容判定，它的 1 就一定是撞码」。

### R2【P0】T1 落卡硬闸「404/无命中 → 禁止落卡」改四档

> **来源**：`01-文献检索-literature-scout.md:136`（现文）+ 实测 2.1/2.3
> **痛点**：**这条现行规则会误杀真文献**。Crossref 对中文期刊覆盖差；CNKI/万方自有 DOI 在 Crossref 404。按字面执行 → 合法中文文献被禁卡 → T1 只有两条路：丢文献，或**造一个能命中的条目**（后者是灾难）。实测 12 条中文文献 0 命中，其中多条带真实 DOI。
> **改动**：`01-文献检索` §发布即核验硬闸 改为四档，并把 `核验：` 字段值域固定：
>
> | 档 | 判据 | 处置 |
> |---|---|---|
> | `Crossref ✅` | DOI 命中且标题/作者匹配 | 落卡 |
> | `标题 ✅` | 标题强重合（±1 年） | 落卡 |
> | `未收录 ⓘ` | 三源无命中，但无编造信号 | **登记落卡**，交接报告记条数 |
> | `编造 ⛔` | 占位 DOI（`1234567/…`）、作者/年份与记录冲突、URL 无同名页 | **禁止落卡** |
>
> **影响**：中文项目不再被系统性挡住；同时**编造面反而收紧**——因为「未收录」与「编造」分开了，T7 有词可查（现在是"没命中"一律禁，等于把两件事压成一个含糊动作）。
> **验证**：以 `run/教师减负政策落地效果` 的 12 条中文文献为回归夹具：应全部落 `未收录 ⓘ`、0 条 `编造 ⛔`。

### R3【P1】卷期页码回填机制化（DOI-first）

> **来源**：`01-文献检索:152`（「首轮即回填」，提示词级）+ `g-audit-check.mjs:308-460`（G15-VolIssue 只核"字段在不在"）
> **痛点**：字段在不在有机检、**对不对没有**；回填靠 agent 手拼 `web_fetch` Crossref，实测教训是「15 条中 6 条留待补 → 再派一轮补检索（1 agent + 8 分钟）」。
> **改动**：`ref-verify.mjs` 对每条带 DOI 的卡直接 `/works/<doi>` 取 `volume/issue/page` → 输出 `backfill` 建议段（**只建议，不改卡**）；`G15-VolIssue` 报告增列「Crossref 可回填」，P2 清单一分为二（可机械补齐 / 需人工）。
> **影响**：G15 P2 里"可机械消除"那部分从人工变一条命令。
> **验证**：对 `run/` 下 10 个项目的文献卡跑，统计 G15 命中条目的可回填率并记入当批报告。

### R4【P1】年份口径：GB/T 优先 `published-print`

> **来源**：实测 2.3 第 4 条
> **痛点**：若照搬对方的 `corrected`，会把对的出版年改成错的（在线优先年 vs 纸本年）。这是**自动更正类事故里最难发现的一种**——输出看着更"规范"。
> **改动**：`引用格式.md` 增一条取值优先级：`published-print` > `journal-issue.published-print` > `issued` > `published-online`；写进 `ref-verify.mjs`，并在 `cite-format.mjs` 的卡字段消费处标注该口径（生成器本身不动）。
> **影响**：消除一类"方向正确的错误更正"。
> **验证**：夹具两例（online-first / print），断言**不会**把 print 年改写为 online 年。

### R5【P0】外部服务面：三条书目 API 进 A11 约束

> **来源**：`任务简报-template.md:145-146`（A11 三段式授权串）+ `外部检索源接入面.md`
> **痛点**：授权串是 `检索=<全网检索|仅本地素材|仅项目素材|仅素材池>`。**脚本不经 A11**——主人选「仅本地素材」时，脚本照样打 Crossref，这是真实越权外发面（虽只发标题）。
> **改动**：① `ref-verify.mjs` 读简报授权串：`检索` ≠ 全网检索 → **拒跑**，全条 `unverified` + exit 3；② `外部检索源接入面.md` 增一行「Crossref / OpenAlex / arXiv = 检索侧外部服务，受 A11 约束」；③ `SKILL.md` 外部服务声明表补三项（与既有 `model-routing.mjs` 的网络先例同类，可查）。
> **影响**：堵一个"门绿但越权"的面（A11 只查简报串，不查脚本行为）。
> **验证**：造 `检索=仅本地素材` 简报 → 脚本 exit 3 且**零网络请求**（`--dry-run` 断言调用计数为 0）。

### R6【P2】工程纪律三条（照抄）

> **来源**：对方 `host.mjs:48-51` + CI 分层（offline smoke / online e2e）
> **痛点**：论衡若加网络脚本，`node --test` 里的网络用例会让 CI 红/不稳；429 预算现在是"运气"。
> **改动**：① 网络用例单列 `tests/network/`（默认跳过，`REFVERIFY_ONLINE=1` 才跑）；② 脚本内 4 并发 / 15s 超时 / 429 重试一次 / `truncated` 显式标记；③ 所有 Crossref 请求带 `mailto`（polite pool）。
> **影响**：CI 稳定；429 从"运气"变"参数"。
> **验证**：断网跑全量 → 全 `unverified` + exit 3，**绝不假绿**。

## 四、推进分级与阻塞判据（v1.1 新增）

### 4.1 三种实现的阻塞后果

| 实现方式 | 阻塞？ | 证据 |
|---|---|---|
| ① **T7 的输入材料**（缺 → 退回现状） | **不阻塞** | 实测 18 条 = **8.4 s**（含 4 次源级 429/400）；断网 → 全 `unverified`，G1 照旧人工；`08-终检-finalizer.md` 终检 15 项**不含 G1**，`g-audit-check` 25 项也不含 |
| ② **`M-Exist` 新项**（缺 JSON = P1） | **阻塞** | `M-Exist-9` 是硬项；断网 / 429 / 中文全 `not_found` 都会卡交付 |
| ③ 塞进 **`g-audit-check`** | **阻塞且污染** | 该门 25 项目前**零网络**、exit 语义稳定；加网络 = 让确定性门依赖外部 API |
| ④ 新增第 37 个白名单脚本 | 只挡**发版**，不挡运行 | 需同批改 `SKILL.md:49` 计数 + `self-check` 双向对账 + `consistency-check` ⑩b + tests |

> **判据一句话**：**只要 `ref-verify` 的缺席不改变任何既有判级，它就不阻塞；一旦它出现在 M-Exist / G 判定里，它就把「网络可用」变成「交付前提」。**

### 4.2 分批（按"不阻塞优先"）

| 批 | 内容 | 网络 | 新脚本 | 风险面 |
|---|---|---|---|---|
| **第 0 批** | R2 四档 + R4 年份口径 + R5 文案 | 无 | 无 | 纯文档，只跑 `consistency-check` |
| **第 1 批** | R3 DOI 回填（只读、只建议、不在任何门里） | 有 | 1 | 低 |
| **第 2 批** | R1 清单 + T7 引用 | 有 | 同上 | 中（只改实据形态，不改判级） |

> **顺序不可交换**：**R2 必须先于 R1/R3**。44.5% 的条目是中文题名——先上脚本而不改规则，报告里近一半是 `not_found`，这份报告被读两次就会被忽略，**比没有更糟**。

## 五、明确不采纳（N1–N4）

| # | 不采纳什么 | 为什么 |
|---|---|---|
| N1 | **它的 8 样式格式生成器**（`formatCitation`，`host.mjs:1036`） | 论衡 `cite-format.mjs` 是 11 类型 + `⟨缺 …⟩` 占位 + 索引段对账的**单一真源**。再引一份 = 双真源，必漂（`AGENTS.md`：「同一事实两处维护必然再漂」）。**只借 `best` 真值，格式仍由 `cite-format.mjs` 出。** |
| N2 | **中文覆盖当判据** | 实测 12/12 `not_found`、`best` 全是无关论文 = 噪声。中文文献只能登记「未收录」，**永不进判级**。 |
| N3 | **整插件当闸门** | 对方 README 自陈 `not_found ≠ 造假`；当 P0 判据 = 大面积误杀（论衡主力是中文）。 |
| N4 | **丢掉论衡已有的三件** | 上下文匹配核验（防张冠李戴）、存在性/数字级两档、信任级别与首发媒体三要素——对方**一件都不做**，别在对齐时顺手简化掉。 |
