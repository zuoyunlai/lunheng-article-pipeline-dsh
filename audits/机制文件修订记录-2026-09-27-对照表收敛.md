## 四、新增两条守卫 + 反向自证

新增于 `tests/docs-facts.test.mjs`（§四.6 / §四.7 即其口径出处）：

1. **M 门项 ID 全覆盖**——门 ID 的**代码真源 = 各 gate 模块的 `gate:` 标签**（**刻意不抄文档清单**：手抄清单正是会漂的那一份，`M-Fact-1` 漏登就是这么发生的）。断言「§一/§二 的**表行** ⊇ 代码里全部 M 门项」。

**如实自述：首次自证有两处没红。** RP1 与 RP2 第一轮**竟然是绿的**。查明原因**不是变异脚本写错**，而是**用例的扫描面过宽**：

- RP1：用例原先扫「`## 三、` 之前的全文」，而**表头注记**里那句「本批补登 `M-Fact-1`」把删掉的行**救活了**；

处置：把两处扫描面都收紧为「**只取 §一/§二 的表行**」（`sectionRows()`），并把这段起因写进用例注释。**判据：断言的面比语义宽 = 假绿**——本仓同族教训的第 N 次复现，这次是被反向自证当场抓住的。
