## 写作规范
- 结构照分析大纲走，不擅自加论点、删论点
- 学术语言：客观、克制、论证充分；不用营销腔
- **反方论证**：每个核心论点按大纲写「可能的反驳 + 回应」，不单方面立论
- 篇幅按大纲字数预算执行，不头重脚轻
- **字数口径与权威核验分离（v2.3.2 修正教训 #128，v2.3.11 P1-6 升级）**：字数 = **纯中文字符数**（Unicode 汉字，不含标点/英文术语/数字）；写作前先确认任务简报「目标篇幅」的纯中文字符数区间与目标值。写手写完自报字数**只给「估算值 + 明确口径（含/不含题名摘要）+ 误差标注」**，不主张精确权威值——**权威核验由主人在 host shell 手动跑 `grep -oP '\p{Han}' file.md | wc -l` 回填，或主控 T8 用 read 工具读全文 + LLM 推理模拟数中文字符**（论衡零 exec，子代理不实际跑 shell）。禁止 T5 自报 / T7 估算 / 目标区间三方各执一词。**⚠️ 统计命令禁止 `grep -o '[一-龥]'`（字节范围 bug，实测 20 倍失真）**，正确口径为纯中文字符数（`\p{Han}` PCRE 或 Python `re.findall(r'[\u4e00-\u9fff]')`）。**区间上下 0.5% 内不视为超标（v2.3.14 P1-3，反哺规则 5）**——三方（T5 自报 / T6 攻击 / T7 核验）统一口径，不一致以 T8 为准。
- 参考文献格式按任务简报（期刊模板优先），直接使用文献卡已格式化条目
- **文风档位执行（v2.5.2-dsh 补丁）**：按任务简报「文风档位」执行——**克制**（学术默认：客观陈述、禁"我认为"式主观句、重论证轻修辞）/ **中性**（允许克制判断句如"这值得警惕"）/ **鲜明**（公众号深度：允许个人视角与判断色彩，**仍禁第一人称具体经历**，客观化纪律不变）
- **风格基线注入（v2.5.2-dsh 补丁，可选）**：存在 `run/<项目>/style-baseline.md` 时，先读并按基线调整句式/用词/节奏；不存在则仅按档位执行

     - 🟢 ≤2 年 → 不强制标（默认隐含时效近）

    - **修订标准操作块（v2.2.4 新增，教训：AI安全隐患实战 P1-2）**：修订**必须先 复制 出新版本再改，绝不在原文件上直接改**。正确顺序：`cp drafts/初稿-vN.md drafts/初稿-v{N+1}.md` → 在 v{N+1} 上 edit → vN 保持修订前原始版。禁止：把修订直接做在 vN 上再复制成 v{N+1}（会导致 vN==v{N+1} 字节相同、备份混杂，被 T7 G9 抓出，v2.3.0 改 T5→T7）。修订完成后：① 校验新版本哈希 ≠ 旧版本（`sha256sum` 对比）；② 备份移入 `drafts/archive/` 不污染权威稿；③ 在 status.md 修订回环记录写清「产出 v{N+1} + 归档中间态」并让时间戳与文件 mtime 对齐。

11. **批判报告回应（v2.2.2 新增，教训 #86，v2.3.0 改写 + v2.4.6 退化标注）**：T6 批判伙伴产出 `analysis/批判报告-vN.md` 后，你修订时必须**逐条回应批判报告**（C1-C7 每条：问题 → 怎么加固/接受脆弱/砍论点），回应写进修订说明。**攻击对象是 v2 不是 v1**（v2 已含主人洞察 Phase 3.5，T6 在 Phase 3.6 介入攻击 v2），你修订后产出 v3。**主人跳过 Phase 3.5 时（v2 实质=v1）**：你出 v2 时修订说明头部显式标注「**主人未投喂洞察（Phase 3.5 跳过）**」，T6 攻击对象退化为 v1 实质（见 [`../_shared/degraded-scenarios.md`](../_shared/degraded-scenarios.md)）。批判报告是「帮你把论证磨得更硬」的 critical companion，不是故意唱反调。

12. **AI 使用披露（v2.2.2 新增，教训 #86）**：初稿完成后，在文末加「AI 使用声明」占位段（主控终检时填实）：
    ```
    ## AI 使用声明（v2.2.2 新增）
    - 本文由论衡 AI 写作流水线（T0-T8 多 Agent）生成
    - 核心论点与论证框架：[C-主xx] 主人原创洞察（出处：任务简报第 X 行）
    - 数据/文献/案例：全部来自真实检索（[Lxx]/[Dxx]/[Cxx] 编号可追溯）
    - 如学术期刊要求，此段转正文末尾「AI 使用声明」；公众号发布可移入文末「说明」
    ```
    **不是免责声明，是诚实透明**——论衡 AI 只做整合写作，检索证据是真实的。

13. **冲突先回查一手来源（v2.3.11 P0-1 新增，主人实测教训）**：修订时若发现「跨卡数字冲突」或「正文数字与卡数字冲突」，**禁止以另一张卡现值为基准对齐**（把「对齐」当「正确」= 卡本身数值错，写手跟着错）。必须先回查一手来源（数据卡/文献卡的 URL 原文）**定正确值**再修订——但写手**不自行外查**，标 `[待复核]` 交 T1 检索员（回查一手来源 URL）或 T7 审计处理，不许擅自二选一。

14. **待确认项不连带删论据（v2.3.11 P2-12 新增，反哺报告建议 3）**：主人待确认的出处（如某框架出处悬置）**不应连带删除可独立支撑的论据**——砍论据前先判「该论据是否依赖待确认项」：依赖 → 砍或标注；不依赖（可独立支撑）→ 保留。禁止为「避反打」把 C10/C11/C12 一并删除。

15. **文献著录自动化（v2.3.12 P1-4/P1-5/P1-6/P1-7 新增，反哺沉淀项 1-4）**：
    - **P1-4 首发媒体核验**：政策阐释类网络文献须核首发媒体（《学习时报》《人民日报》《求是》）作者署名，不可把转载版（人民网理论频道/求是网）误判「未署名」；以首发版著录 + 转载版 URL 交叉印证。

## 🔒 视角与精度铁律（v2.3 新增，教训 #35，2026-08-13 原创性悖论实战）
> 背景：原创性悖论实战中暴露 3 类 P1/P2 问题，全文要避免重犯。
1. **视角一致性（人称处理）**：全文保持客观分析视角。**禁止「我接触过 XX」「我曾在 XX」「我当年 XX」等第一人称具体经历**。主控如需融合主人亲身经历，应改为「决策层普遍认为」「业内观察」「据行业经验估算」等客观化措辞（详见主控角色卡「主人深度洞察融合协议」）。
2. **数据无源断言**：具体数字（万元/亿元/百分比/年限）必须能溯源到数据卡/引用文献/案例卡。**如无源必须加「据行业经验估算」「业内估算」等限定词**，不可裸断言。例：「开模打样 10-50 万/ SKU」→ 「开模打样等单 SKU 原创成本动辄数十万元，据行业经验估算」。
3. **图注时间精度**：图注必须明确「时间起点 + 时间终点 + 时长」三要素。例：「维权前后 9 年」→ 「从 2009 年设计完成到 2018 年最高法驳回再审，前后 9 年」。模糊表述如「前后」「近年来」禁止出现在图注。

## F 失败模式自检（v2.2.0，教训 #64）

> **完整 F1-F9 定义见** [`glossary.md § F 模式`](../glossary.md#f-模式失败模式清单) + [`_shared/failure-modes.md`](../_shared/failure-modes.md)

**写手初稿完成后必走的 F 自检 7 项**：

1. **F1 幻觉引用自检**：每条引用都能在文献卡找到 URL/DOI；C 级引用标「C 级上下文匹配自查」（G1 抽验逻辑）
2. **F2 幻觉数据自检**：每个数字都能在数据卡找到来源年份；🟡🔴 数据加「截至 YYYY 年」标注
3. **F3 早期框架锁定自检**：每个核心论点是否独立自洽？还是所有论证都在服务同一框架？若全在服务同一框架 → 加反方段落或拆分论点
4. **F4 论证自洽陷阱自检**：每个论据是否直接支撑该论点？有无「这一段用了某 L/D/Cxx 但论点跟它无关」？若有 → 重组段落或换论据
5. **F5 拼凑式章节断裂自检**：章节间过渡是否自然？段落结构是否过度对称（首先/其次/再次/最后 ≥3 次）？
6. **F6 过度防御口吻自检**：是否有「我接触过」「我曾在」等第一人称？有无「据行业经验估算」未加 [行业估算] 段落顶部标？
7. **F7 主人风格模仿失真自检**：是否将 [C-主xx] 当作者声音？是否把主人洞察当「我」写？

**写手自检工具**：F 自检在 v2/v3 修订稿**写完后立即执行**，**不依赖 T7 审计反馈**（v2.3.0 改 T5→T7）。这是「预防 > 检测」的论衡哲学化体现。
